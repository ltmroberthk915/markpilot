# MarkPilot for DeepSeek Harness

**人与 AI 在同一张编辑面上写 Markdown。**

在 DSH 右侧栏里打开一个真正的所见即所得 Markdown 编辑器：你打字，AI 落笔，同一份文档、同一次保存、同一步撤销。写文档不再是「把内容粘贴给 AI、等它吐回来、再手动合并」——AI 的每一次修改都直接出现在你眼前的编辑面里，看得见、可撤销。

## 你能得到什么

- **Typora 级的书写手感**：即时渲染的 Markdown（标题、加粗、列表、行内公式、代码块、引用），行内公式点击即回源码，光标进入公式区间自动展开编辑。
- **AI 同面协作**：任何 DSH 会话里的 AI 都能通过 `markpilot` 工具直接编辑你打开的文档——改动以版本守卫落盘（永不盲目覆盖你的未保存输入），编辑面毫秒级可见，`Ctrl+Z` 一步撤销。
- **双引擎随切**：`vditor` 整装引擎（成熟稳定）与 `CM6` 原生引擎（新一代，大文档性能代差）一键切换，编辑面顶栏的引擎胶囊即点即换。
- **对话里引用文档**：在输入框打 `@mp`，把你打开的文档作为引用插入对话，AI 直接知道你在写什么。
- **主题随宿主**：编辑面明暗跟随 DSH 主题实时切换，克制配色，公式/代码/复选框在两种模式下都清晰。

## 安装

```bash
dsh plugin --profile <你的 profile> add dsh-markpilot
```

（本地开发：`dsh plugin --profile web add <本仓库路径>`，然后 `dsh web`。）

## 使用

1. 右侧栏「＋」→ **工作区文件** → 点开任意 `.md` 文件，即进入 MarkPilot 编辑面。
2. 直接打字：自动保存（防抖 1.5s，版本守卫，冲突绝不覆盖）。
3. 让 AI 改文档：对话里让模型调用 `markpilot` 工具（`read` 读全文，`edit` 字面替换）——你会在编辑面里实时看到它的每一笔。
4. `@mp` 引用：输入框里输入 `@mp` 选择当前打开的文档。
5. 引擎切换：点编辑面顶栏右侧的引擎胶囊。

## 引擎怎么选

| | vditor 引擎 | CM6 引擎（v3 方向） |
|---|---|---|
| 大文档（25 万字符）键入 | ~64ms/键 | **~10ms/键** |
| 滚动卡顿 | 偶发 1.8s 长帧 | **零卡顿** |
| AI 改动可见延迟 | ~2.1s | **~80ms** |
| 打开到可编辑 | ~1.4s | **~0.5s** |
| 内存占用（同文档） | 基线 | **再省 1/3** |
| 功能面 | 全量（表格编辑/导出/主题…） | 快速成长（列表/复选框/公式投影/表格跳格已备） |

日常写作推荐 CM6 引擎；需要导出 Word/PDF 等重功能时切回 vditor。

## 已知边界（如实）

- CM6 引擎的表格操作尚在成长（Tab 跳格/行尾续行已支持；`Shift+Tab` 在 iframe 内受浏览器限制，待宿主级键转发）。
- 桌面端若自定义了与编辑器冲突的快捷键，DSH 的原生快捷键优先（详见 DSH 快捷键设置）。
- 粘贴图片等富操作当前在 vditor 引擎侧。

## 卸载

```bash
dsh plugin --profile <你的 profile> remove dsh-markpilot
```
