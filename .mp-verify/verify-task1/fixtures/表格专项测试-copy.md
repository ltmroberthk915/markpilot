## 6. 快捷键（表内）

【期望】逐条试：
- `Ctrl+Enter` → **下方插入一行**（不劈表）
- `Ctrl+Shift+Enter` → 上方插入一行
- `Ctrl+Alt+←` / `Ctrl+Alt+→` → 左/右插入一列
- `Alt+↑↓←→` → 上/下移行、左/右移列
- 最后一格按 `Tab` 或 `Enter` → **追加一行**（列数＝表头列数）
- `Tab` / `Shift+Tab` → 下一格 / 上一格，跨行**跳过分隔行**
- 分隔行按 `Shift+Enter` → 底部状态栏提示「分隔行不能插入换行」
- `Ctrl+E` → 选整格；连按 `Ctrl+A` → 格 → 行 → 列 → 整表 → 文档
