这一章解决什么卡点

大多数人学概率论时，"随机变量"就是"一个随机变化的数"，拿到这个图像就能算题。但到了随机微积分和金融定价，这个图像会悄悄坑你两次：

第一次是在测度变换（第 11–12 章）——同一支股票、同一批可能的世界状态，把概率重新分配一下，"随机行为"就全变了。这时你必须分清楚：变的是什么？没变的是什么？答案藏在"随机变量 = 样本空间上的可测函数"这个更深的图像里。

第二次是在信息（第 2–3 章）——定价的本质是"在部分信息下做最优预测"。要谈"部分信息"，就得先把"信息"本身数学化，而这个数学化用的材料——σ-代数——正是可测性定义的原材料。

所以本章把初等概率论的地基重砌一遍：可测空间、可测函数、诱导测度、勒贝格积分。每一步都不难，但每一步都是为了后面某处的"哦，原来那时候是在用这个"

1.1 随机变量

1.1.1 Def 底层样本空间

(1) 设 Ω 为底层样本空间（underlying sample space）：其中每一个元素 ω∈Ω 表示每一种可能发生的底层状态。

(2) 设 Ω 上有 σ-代数 F，则定义 (Ω,F) 为底层可测空间：F 表示所有可能将会得知的信息集合，F 的每一个元素子集 E∈F 称为事件；事件通过可列并、补运算得到的集合 F∈F，即仍为事件。

严格定义：F 为由"基本事件"通过某些集合运算建立的满足一定性质的集族（对可列并、补运算封闭，且 Ω∈F）。其中的元素为可测集 E∈F。

严格性注记（省略了什么）：σ-代数的存在性与"生成"运算（由任意集族 E 生成最小 σ-代数 σ(E)，即所有包含 E 的 σ-代数之交）这里当作已知；测度的构造（Carathéodory 扩张定理）在第 3 章需要时会现场补一笔。系统补课可看任何一本实变函数教材，本书不展开——我们要尽快到达有意思的地方。

理解：为什么"信息"要用 σ-代数装？因为如果你能判断事件 E 发生与否、也能判断 F 发生与否，那你自动就能判断 Ec（"没发生"）和 E∪F（"至少一个发生"）——可数的并和补是"信息"封闭运算的自然边界（可数交由 De Morgan 律白送）。所以一个 σ-代数恰好是"一套自洽的、可以整体得知的问答集"。

1.1.2 Def 观测样本可测空间

(Rk,B(Rk)) 其中 B(Rk) 为 Rk 上的 Borel σ-代数（由所有 k 维开矩体生成的最小 σ-代数），称为观测样本可测空间。

理解：数值观测的落点空间。我们最终关心的量（价格、利率、波动率）都活在这里；Borel 结构保证了"开矩体"这类最朴素的观测问题（"价格落在 100 到 101 之间吗"）都是合法事件。

1.1.3 Thm-Def X 的诱导 σ-代数

设 X:(Ω,F)→(Rk,B(Rk))。记

σ(X):={X−1(B)​B∈B(Rk)}

则 σ(X) 是 Ω 上的 σ-代数（注意 X−1(B)∈F 要求 X 可测，见下），称为 X 诱导的 σ-域（σ-field induced by random vector X）。

证：完全由集合与函数逆像的性质可得。由于 B(Rk) 为 σ-域：

(1) E∈σ(X)⇔∃B∈B, s.t. E=X−1(B) ⟹Bc∈B​ Ec=X−1(Bc)∈σ(X)；

(2){En​}∞⊂σ(X)⇔∃{Bn​}∞⊂B, s.t. En​=X−1(Bn​) ⟹∪n​Bn​∈B​ ⋃n∞​En​=X−1(⋃n∞​Bn​)∈σ(X)。

（另需 Ω=X−1(Rk)∈σ(X)，显然。）

理解：X:Ω→Rk 是对底层样本空间在数值上的映射汇总（numerical mapping summary of the underlying sample space），而汇总一般仅保留部分信息（除非一一对应）。σ(X) 已经是通过 X 能回溯的最多的信息：只看 X 的取值，你能分辨的世界，最细就细到 X 的原像，再细就分不出了。

1.1.4 Def F-可测随机向量

X:Ω→Rk 为 (Ω,F) 上的随机变量（random variable / random vector） ⇔def X 为 (Ω,F) 上的 F-可测函数，即

∀B∈B(Rk),X−1(B)∈F

或等价地 σ(X)⊂F：σ(X) 为 F 的子 σ-代数。

理解：可测性意味着随机变量取值已知——F 中包含的事件足以遍历 X 的所有取值问题。不可测时，说明可知信息 F 无法消除 X 的随机性，只能提供部分条件信息（这正是第 2 章条件期望的出发点）。此外，可测性保证了后续可通过在 F 上定义概率测度来对 X 定义概率分布。

1.2 概率测度、诱导概率测度与概率分布

1.2.1 Def 概率测度 P

在可测空间 (Ω,F) 上定义测度 P 使得 P(Ω)=1（且 P(E)≥0、可列可加），则称 P 为概率测度（probability measure），(Ω,F,P) 称为概率空间（probability space）。

1.2.2 Thm-Def X 诱导概率测度 PX​

设 (Ω,F,P) 上随机变量 X:(Ω,F)→(Rk,B)。则一定可在 (Rk,B) 上定义概率测度 PX​：

∀B∈B,PX​(B):=P(X−1(B))

称 PX​ 为 "P 经 X 诱导到 (Rk,B) 上的概率测度"。

证（完全由逆像性质使得测度性质被继承）：

(1) 集函数 PX​ 显然继承 P 的非负性。

(2) 可列可加性：∀ 两两无交的集列 {Bn​}∞⊂B，

PX​(⋃∞​Bn​)=P(X−1(⋃∞​Bn​))=P(⋃∞​(X−1(Bn​)))=P的可列可加∑∞​P(X−1(Bn​))=∑∞​PX​(Bn​).

(3) 归一性：X−1(Rk)=Ω（因 Rk⊃X(Ω)⇒X−1(Rk)⊃X−1(X(Ω))⊃Ω，而反包含显然），故 PX​(Rk)=P(Ω)=1。

至此，对随机变量的理解有三层：

  • Simplest：一个随机变化的数——"看山是山"；

1.2.4 Remark 随机机制、随机变量的作用

(1) 随机机制与概率测度：我们只能通过确定性来模拟不确定性：可测空间 (Ω,F) 作为底层样本空间，包含 ex-post 所有可明确是否发生了的事件；再通过在 (Ω,F) 上建立概率测度 P，将 F 所能表示的各事件映射到发生的可能性大小，从而构建定量的随机机制 (Ω,F,P)。

(2) 诱导概率测度的作用：底层概率测度 P 或隐藏、或为主观赋予的先验信息，而现实观测中只能通过 X 的取值行为——即观测诱导概率测度空间 (Rk,B,PX​)——来间接分析：P↔XPX​。

(3) 诱导概率测度 PX​ 由两个要素决定：一是底层测度 P，二是随机变量 X 对底层样本的赋值规则。随后章节我们会分析：对同一 X，不同 P 会被诱导成不同的观测空间测度——测度变换（第 11 章）。

1.3 勒贝格积分（Lebesgue Integral）

勒贝格积分的起源：

(1) 为了在一般抽象空间 (Ω,F) 上建立"体积"（测度），进而对定义在该空间上的函数 f 进行积分，只能通过对 f 的值域切分：寻找函数值对应的原像 X−1(B) 的测度，再作乘积求和。

(2) 黎曼（Riemann）可积性要求被积函数（integrand）满足"过高"的连续性，因而需要将 integrand 扩充到更广泛的函数类——比如随机过程中大量出现的、只在可测意义上良好的函数。

1.3.1 Def 简单函数（simple function）

设 (Ω,F) 上的一个 partition P:={A1​,…,An​}⊂F（Ai​ 两两不交且并起来是 Ω）。设 B:={b1​,…,bn​}，B 中各项为互不相同的实数。则

f(ω):=i=1∑n​bi​1Ai​​(ω)

称为 (Ω,σ(P)) 上的简单函数。

1.3.2 Lemma 逐点收敛（point-wise convergence）

若 f 为 (Ω,F) 上非负可测函数 ⇒ 存在一列由非负简单函数构成的函数列 {fn​}n=1∞​，s.t. ∀ω∈Ω, limn→∞​fn​(ω)=f(ω)。

（标准构造：fn​(ω)=∑k=0n2n−1​2nk​1{2nk​≤f<2nk+1​}​(ω)+n1{f≥n}​(ω)，它对每个 ω 单调不减地爬向 f(ω)。记住这个"网眼逐层加密"的构造，第 7、8 章构造伊藤积分时用的简单过程逼近是同一个思路。）

1.3.2+ 注 逐点收敛的含义、构造与它为何是地基

(1) 字面含义：逐点收敛是指固定一个 ω 不动，看数列 f1​(ω),f2​(ω),… 是否收敛到 f(ω)：

∀ω∈Ω, ∀ε>0, ∃N=N(ω,ε), s.t. n>N⇒∣fn​(ω)−f(ω)∣<ε.

注意 N 依赖 ω：同一个精度 ε，在 ω1​ 处可能第 10 项就达标，在 ω2​ 处要等到第 10000 项。作为对比，一致收敛（uniform convergence）要求

∀ε>0, ∃N=N(ε), ∀ω∈Ω, n>N⇒∣fn​(ω)−f(ω)∣<ε,

即"所有点同时达标"。一致收敛 ⇒ 逐点收敛，反之不成立。本书只要逐点（及后文的几乎必然、L2），因为一致收敛太奢侈——伊藤积分里的简单过程逼近根本做不到一致，而勒贝格理论的魅力恰在于把收敛要求压到最低，再靠单调性或控制函数把极限搬进积分号。

(2) 它在文中的位置：本节顺序是 1.3.1 简单函数 → 1.3.2 逐点收敛引理 → 1.3.3 勒贝格积分。这个顺序不是随意的：1.3.3 的正式定义 ∫fdμ:=sup{fs​≤f 的简单函数积分} 正确但不好用——既算不出具体值，也无法直接证明收敛定理。真正干活的是另一条路：造一列简单函数 {fn​} 逼近 f，然后取 ∫fdμ=limn​∫fn​dμ。1.3.2 正是保证这列简单函数一定存在；没有它，1.3.3 就是一座没有楼梯的塔。

(3) 构造公式在做什么：拆成三件事。

  • 值域切分（横切，不是竖切）：把值域 [0,n) 以步长 1/2n 切成 n2n 个横条，f 落在第 k 条中的 ω 组成集合 {2nk​≤f<2nk+1​}，令其取左端点值 2nk​。该集合因 f 可测而属于 F，故是合法简单函数；又因取左端点而恒有 fn​≤f（在 f 线下）。这正对应 1.3.5 所说的 Lebesgue 横切："按函数值分堆称重"。
  • 高处截断：f≥n 的部分用常数 n 顶上——简单函数必须取有限个值，而 f 可能无界；这个"天花板"随 n→∞ 升到无穷，不损失极限。
  • 网格加密：n 增大时步长 1/2n→0、截断阈值 n→∞，两者共同保证 0≤fn​(ω)↗f(ω)（单调不减地爬向 f）。对任意固定 ω，误差不超过当前网格宽度，故 fn​(ω)→f(ω)——这就是逐点收敛。

直观：像给一张照片逐级提高分辨率，每个像素点 ω 的颜色值越来越接近真值；但各像素达标所需"级数"可以不同，故是"逐点"而非"一致"。

例：取 Ω=[0,1]、f(ω)=ω。n=1 时 f1​ 在 [0,0.5) 上取 0、在 [0.5,1) 上取 0.5；n=2 时步长变 1/4，f2​ 在四个等分区间上分别取 0,0.25,0.5,0.75。阶梯函数从下方一层层贴合对角线，网格越来越细，每个点最终被"压"到对角线上。

(4) 为什么"逐点"这个弱条件够用——控制收敛定理在等它：紧接的 1.3.4 的假设正是①逐点收敛（1.3.2 提供）与②存在可积控制函数 g，两者合起来才能把极限搬进积分号。为什么必须补控制函数？ 光有逐点收敛会翻车：取 Ω=(0,1)、fn​=n1(0,1/n)​，则 ∀ω>0，只要 n>1/ω 就有 fn​(ω)=0，故 fn​→0 逐点；但 ∫fn​dμ=n⋅n1​=1 恒为 1。于是

1=n→∞lim​∫fn​dμ=∫(n→∞lim​fn​)dμ=0,

"极限和积分闹了分家"。病根在于这列函数没有可积控制函数：质量被挤进一个越来越窄、越来越高的尖峰里跑掉了。（该反例因不单调而排除了单调收敛定理；若 {fn​} 单调不减，则"单调性"与"控制函数"是两条互补的通行证，勒贝格理论中几乎所有换序都靠这两张牌。）

(5) 往后看：同一套"网格加密 + 逼近"的思路在第 7、8 章会以简单过程逼近的形式重现，用来定义 ∫HdW：

1.3.5 Prop Riemann 与 Lebesgue 积分的异同

(1) 区别：

Riemann–Darboux 方法——先划分定义域为 {Δxi​}，再取 Δxi​→dx。过程中利用（针对连续函数的）中值定理取中间函数值 f∗∈[finf,fsup]，上、下达布和双向夹逼收敛

i∑​fiinf​⋅Δxi​ → ∫fdx ← i∑​fisup​⋅Δxi​.
Lebesgue 方法——先在值域上取一组点 {fk​}，生成定义域 Ω 的 partition（每个元素可以不连通）：$\{\omega\,\,f_{k-1}\le f(\omega)< f_k\}_k，得到简单函数的线下面积\sum_{k}f_k\cdot\mu(f_{k-1}\le f<f_k)。不断增加分点、让网眼加密，\sum_{k}f_k\cdot\mu(f_{k-1}\le f<f_k)\rightarrow\int f(\omega)\,\mu(d\omega)$。

(2) 共性：两者均以"单一函数值 × 自变量小区间（测度） = 小矩形面积"来逼近积分收敛值。

1.4 期望与概率密度函数

1.4.1 Def 随机变量的数学期望

EP​[X]:=∫Ω​XdP

理解：取 X:=1E​，则

EP​[1E​]=∫1E​dP=∫E​dP=P(E)

——测度可由积分定义、表示（示性函数是桥梁）。期望 EP​[X] 即以 P(ω) 对 X(ω) 的不同取值按概率进行加权平均；从图像上应按 CDF 的图像做垂直截线理解（对分布"竖着切片"），而非上一节图中的水平截线。

1.4.2 Prop 概率密度函数与 RN 导数

考察由 X 诱导的概率测度 PX​：由于测度可由积分表示，PX​(B)≡∫B​1(x)dPX​(x)。相较于 Rk 上平凡的勒贝格测度 L(B)=∫B​1(x)dL(x)，在非常不严格的意义上，

PX​(B)=∫B​1(x)dPX​(x)=∫B​1(x)(dL(x)dPX​(x)​)dL(x)

即 PX​ 对体积 L 进行了伸缩变换，而 dL(x)dPX​(x)​ 代表伸缩变换（测度变换）遵循的"密度"规律。

注意这种伸缩变换完全由 PX​ 决定：既取决于随机变量 X 对底层事件的汇总方式，又取决于底层概率测度 P。在测度 P 不变的情况下，可通过 dL(x)dPX​(x)​ 研究 X 的汇总（映射）方式的性质。

而由 PX​(⋅) 与 FX​(x) 一一对应，在符号形式上：

dxdFX​(x)​=dL(x)dPX​(x)​

可见概率密度正是观测样本空间 (Rk,B) 上，诱导概率测度 PX​ 对平凡勒贝格测度 L 的 Radon–Nikodym 导数。

（记住这个视角。第 11 章会把"密度 = 测度间的导数"从直觉升格为定理，测度变换的全部技术都从它出发；终章 Heston 里 Girsanov 换测度时用的指数密度，就是它在路径空间上的直接后裔。）
