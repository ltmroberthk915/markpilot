# 图表验收：请你亲手试这几件事

这份文档是给你手动验收用的。下面四种图型 + 一处坏语法，覆盖了 MVP 的全部路径。

## 一、流程图：试着在源码里改一个节点名

把下面的 `执行动作` 改成 `执行动作（改过了）`，**图应当立刻跟着变**。

```mermaid
flowchart TD
  A[开始] --> B{判断条件}
  B -->|满足| C[执行动作]
  B -->|不满足| D[记录日志]
  C --> E[结束]
  D --> E
```

## 二、时序图：中文参与者名

```mermaid
sequenceDiagram
  participant 用户
  participant 编辑器
  participant 渲染器
  用户->>编辑器: 粘贴 mermaid 代码
  编辑器->>渲染器: 请求渲染
  渲染器-->>编辑器: 返回 SVG
  编辑器-->>用户: 显示图表
```

## 三、甘特图

```mermaid
gantt
  title 迭代计划
  dateFormat YYYY-MM-DD
  section 设计
  需求梳理: a1, 2026-01-05, 5d
  交互稿: after a1, 4d
  section 开发
  编码: 2026-01-14, 10d
  联调: after 8d, 5d
```

## 四、饼图（中英文混排）

```mermaid
pie title 时间都去哪了
  "写代码" : 45
  "读代码" : 25
  "开会" : 20
  "摸鱼" : 10
```

## 五、坏语法：应当**可读地报错**，不是白屏

```mermaid
flowchart TD
  A[忘了闭合 --> B
```

## 请你重点试这几条

1. **↑ / ↓ 穿过图表块**：光标放在图上面一行按 ↓、下面一行按 ↑，
   看是不是"进块落在图里的内容行、再按一下越过围栏出块"，而且**列位置不丢**。
2. **在块内改内容**：把 `A[开始]` 改成别的，看**图会不会跟着更新**（这是修过的一个坑）。
3. **导出 PDF**（更多 → 导出 → PDF）：看图表有没有**渲染成图**、白纸黑字是否正常。
4. **导出 HTML** / **复制为知乎格式**：看贴到白底文章里图是否正常。
5. **主题**：在深色主题下导出，看**图是不是仍然用浅色**（纸面是白的，图不该是黑块）。
