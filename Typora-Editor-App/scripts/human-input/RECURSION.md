# 递归测试协议（RECURSION）——发现一个问题，就向这个方向再挖一层

> 原则（用户 2026-09-23 定）：测试策略必须有**递归性**——一旦发现问题，立刻准备好向这个方向
> 延伸，并把延伸结论**反哺**回套件。发现不是终点，是下一轮测试的输入。

## 循环

```
      ┌──────────────────────────────────────────────────────────┐
      │  ① 跑套件（120-134 固定网 + 15x 递归产物）                    │
      │  ② 红灯 → FINDINGS.md 记一条（读数/堆栈/种子/复现命令）        │
      │  ③ 归类 → 在本文件登记"延伸方向"                              │
      │  ④ 写 15x 递归场景：定点复现（缩到单变量）或矩阵（把单点拉成族）  │
      │  ⑤ 递归场景再红 → 重复 ③④（矩阵升维：位置×手势×状态×节奏）      │
      │  ⑥ 产品修复 → 递归场景转绿 → 反哺：                            │
      │      · 移植进 scripts/acceptance/scenarios/ 成为正式 gate；   │
      │      · 把"独立口径"固化成断言（防突变验证：注掉修复必须变红）；    │
      │      · FINDINGS.md 标记 ✅ 已收编。                            │
      └──────────────────────────────────────────────────────────┘
```

## 编号约定

- `120-134`：首轮固定网（快门/组合键/词动/缩进/导航/选区家族/连发/点击矩阵/侧栏/混沌/形态矩阵/空白带/巡走）。
- `135-149`：**递归产物段**——每条已确认发现占一个号，标题注明反哺自哪条 FINDING（`F#`）。
- 递归场景的断言口径必须"用户可见 + 独立几何/磁盘/进程"，不许引用产品内部函数。

## 反哺检查单（每次修复后过一遍）

1. 突变验证：把修复注掉，对应场景**必须**变红（场景已进正式 gate 时自动生效）。
2. 同类扫射：修复点的"同族位置"（其它块型/其它手势/连发版）有没有对应断言？没有就补。
3. 台账：FINDINGS.md 状态改"已收编 + gate 场景号"；RECURSION 登记表同步。
4. 大素材：递归场景用小素材定性后，至少跑一遍真素材副本（混沌场景 131 已内置）。
