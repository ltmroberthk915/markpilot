# MarkPilot CM6 3.0.4 — 更舒服的阅读宽度，更懂引用区的排版

MarkPilot CM6 3.0.4 把「一屏到底看多少字」交回给你，并且把引用区里的公式与表格修回它们该有的样子。

## 页面宽度：想宽就宽，想窄就窄

正文再也不会铺满整块窗口。「更多 → 设置 → 版式」里新增**页面宽度**滑杆（40%–100%），拖动即时生效、自动记住：

- 默认贴合常见的阅读版心，长段落一眼能读完一行，眼睛不用来回扫；
- 只收窄**正文内容**：工具栏、状态栏、大纲面板都不受影响，窗口再大也不会让文字散开。

## 内容缩放与工具栏各管各的

- `Ctrl+=` 放大、`Ctrl+-` 缩小、`Ctrl+0` 回到 100%，也可以按住 `Ctrl` 滚滚轮；
- 缩放**只作用在正文**：字号、行高、公式、表格一起变大变小；
- **工具栏按钮的大小单独调**（设置 → 版式 → 工具岛尺寸，80%–140%），放大正文不会把工具栏一起撑大。

## 底部状态栏，右下角直接输数字

窗口底部新增一条状态栏：当前行/列、选中字数、全文字数一目了然。右下角的百分比可以直接点开输入：

- 输入 `100` 回车就是 100%，输入 `130` 就是 130%，比反复按键精确；
- 状态栏只在内容真正变化时才更新文字，打字过程零额外开销，长篇文档也不会因此变卡。

## 引用区：公式、表格、选中高亮一起修

- **引用区里的表格**现在正常渲染成表格，左侧引用竖条与缩进都在，公式照常显示，点格即可编辑，复制到 Excel/Word 也是干净表格（不会带上引用记号）；
- **引用区里的单行块公式**（`> $\begin{cases} … \end{cases}$`、`align`、`aligned`、`array`，单行或跨行、一层或嵌套引用）都能正确渲染成公式；
- **引用区的选中高亮**改为覆盖整段引用：从左侧竖条一直连到行尾，不再出现"少一块、多一块"的断口；隐藏的 `>` 记号不再占据选区宽度。

## 安装

| 文件 | 说明 |
|---|---|
| `markpilot-cm6-3.0.4-portable.exe` | 免安装，双击即用（可放 U 盘） |
| `markpilot-cm6-Setup-3.0.4.exe` | 安装版，可选安装目录、建快捷方式 |

两个包出自同一次构建，功能完全一致。

## 小贴士

- 设置项都在「更多（⋯）→ 设置」里，改完立即生效并自动记住；
- 想回到默认：设置面板底部「恢复默认」一次清空页面宽度、缩放、工具岛尺寸与透明度设置；
- `Ctrl+0` 任何时候都能把内容缩放拉回 100%。
