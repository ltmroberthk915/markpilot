# MarkPilot 2.1.25

**光标落得更准，浮层收得更快。**

## 标题左边点得住

标题露出的 `#` 不是装饰，光标能停在它左边。点在井号左边的空白处，光标就留在那儿，不再被弹到标题文字前面；井号不会闪掉，整行也不会被推来推去。想改标题级别，点井号本身、或用方向键走进去，照旧。

## 块首退格不再吃掉井号

光标停在 `#` 之前按退格，是「块首删除」：上一段是正文时合并上去，上一段是表格、代码块、公式这类接不住正文的块时什么也不做。不会再出现「井号被删掉、标题降级成普通段落」。

## 浮层菜单收得干净

编辑模式、标题这类菜单点开之后，指针一离开工具栏就收起来，不再压着正文不走。界面文字、正文、菜单三者的层级也不再互相叠着。

## 工具栏更干净

桌面版工具栏去掉「使用vscode默认编辑器」：桌面端的编辑能力都在 MarkPilot 里，不需要跳出去。插件版保留该入口——在 VS Code 里它就是回到 VS Code 自己的文本编辑器。

⋮ 菜单里两个不生效的主题下拉（代码块主题预览 / 内容主题预览）已移除，点了没反应的下拉不会再出现。编辑器配色用工具栏一级的「主题」和「阅读调色盘」。

## 安装

- **Windows 桌面版**：`markpilot-Setup-2.1.25.exe`（免安装：`markpilot-v2.1.25-portable.exe`）
- **VS Code / Trae 插件**：`markpilot-2.1.25.vsix` —— 扩展面板 → 右上 ⋯ → 从 VSIX 安装…
- **校验**：`SHA256SUMS.txt`

## 修复

- 点标题里 `#` 左侧的空白处：光标不再跳到正文开头，就停在井号左边。
- 光标在 `#` 之前按退格：不再删掉井号、不再把标题和后面那段并成一行；上一段是正文时照旧合并上去。
- 点开的编辑模式 / 标题菜单：指针移开工具栏即收起，不再持续停在正文上。
- 桌面版工具栏：移除「使用vscode默认编辑器」按钮。
- ⋮ 菜单：移除点了没有反应的「代码块主题预览」「内容主题预览」。
