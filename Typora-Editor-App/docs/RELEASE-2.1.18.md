# MarkPilot 2.1.18 发布说明（私版）

这一版只改你目测到的那一处：**候选框里漏出了「同一类（字体）」这样的内部分组字眼**。

## 你看到的

> 「等会 我在测试中目测到怎么候选框还有"同一类"这种工程字眼漏出来了」

是的，那是我 2.1.17 加同类补全时顺手写在说明栏里的标注——本意是让你知道"这条为什么也被列出来了"，
但它本质上是**内部实现的分组名**，不该出现在界面上。你说得对。

## 改法

`render/js/completion-sources.js`：说明栏**只放命令自己的中文解释**（`detail: title`），
分组只留在代码里用于挑同族兄弟。同族候选**照旧一起给**（`\mathbb` → `\mathbf`/`\mathcal`/`\mathscr`/…），
只是不再标注"为什么在这儿"。

修后（`probe-cands.cjs` 实测的候选栏文案）：

```
\mathbb → \mathbb 黑板粗体（ℝ）   \mathbf 数学粗体   \mathcal 花体   \mathrm 正体   \text 公式内文字
          \mathscr 手写体   \mathfrak 哥特体   \mathsf 无衬线   \mathtt 等宽   \mathit 斜体
          \boldsymbol 粗斜体（希腊字母也能加粗）   \mathnormal 默认数学体
```

**回归门**（场景 90，现在 11/11）：把"说明栏里不许出现分组/工程字眼"**写成断言**
（正则 `同一类|同一组|分类：|·`，命中即红）；同族是否带出来、`\mathbb` 首条是不是它自己、
`\frac`/`\sum` 的同族、只敲 `\` 时前四条仍是 `\frac,\sqrt,\sum,\int`、`\m` 时不做同族填充、
以及"选一条按 Tab 真的插进公式源码"，都照旧断着。
