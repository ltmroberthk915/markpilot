# MarkPilot 2.2.10

这一版让"点公式"这件事更顺手，顺带把中文斜体的字号调大一档。

## 点公式：源码展开之后，光标落在你点的那个字上

- 以前点一条**已经渲染好的行内公式**，源码会展开，但光标总是跳到公式源码的**开头或末尾**
  （跟点在哪个字上无关）——现在按你点的横坐标就近落点，点"40"就停在"40"那里。
- 渲染态、源码态都用同一套规则：点公式**里面**＝进源码编辑并精确定位；点公式**外面**＝照旧落在正文。

## 中文斜体（楷体）字号调大一档

- 中文的斜体走楷体字面。实测同一字号下**楷体与宋体的字面几乎一样大，但楷体笔画更细**，
  看上去偏小偏淡；这一版把斜体字号从 1.06 倍提到 **1.12 倍**，在保持等宽的前提下补回观感。
- 内置主题与随附的 Typora 主题（宋体-朙 / 宋体-暗）取同一个值，两处看起来一致。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.10.exe`；便携版 `markpilot-v2.2.10-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.10.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.9 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。
