# MarkPilot CM6 3.0.6 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

## 这一版你能得到什么

**图片**
- 复制一张图，粘到聊天工具或网页对话框里就是**真图片**（不再是 `<img src="data:…">` 源码）。
- `![](图片/相对路径.png)` 会按**文档所在目录**解析，换一个目录的文档不会串图。
- 外链图片（http/https）正常显示；离线或被墙时显示为空白。
- `<img width height>` 的宽高都生效；行内代码里的图片写法保持字面，不再被画成图。

**表格与公式**
- 单元格里 `Shift+Enter` 是**软换行**：屏幕上换行，导出 HTML/PDF 与复制到 Excel 也是真换行。
- 分隔行上按 `Shift+Enter` 时，底部状态栏会提示「分隔行不能插入换行」。
- 普通表格不会再被套上引用区的竖条与底色。
- 表格快捷键：`Ctrl+Enter` 下方插入行、`Ctrl+Shift+Enter` 上方插入行、`Ctrl+Alt+←/→` 左右插入列、`Alt+↑↓←→` 移动行列。

**界面**
- 设置里的**页面宽度 / 内容缩放 / 工具岛尺寸**三根滑杆真正生效（此前被一段旧代码静默接管，拖动无反应）；放大后「更多」菜单不再跑到屏幕外。
- 工具栏：「更多」移到最右；**界面透明度**与**阅读模式**收进「更多」菜单（不再各占一个按钮）；双开分屏与阅读模式换成两个一眼可辨的图标；明暗切换改为太阳/月亮并紧跟主题按钮。

**文件**
- 应用图标右键（任务栏/开始菜单跳转列表）能看到**最近使用的文件**；应用内「文件 → 最近打开」含清除记录，文件被删/改名会灰显。
- 修复 `Ctrl+Shift+S`（另存为）此前不落盘的问题。

## 说明

- 本版是独立桌面应用，与 VS Code 扩展版各自演进，本次不更新扩展。
- 文档里的外链图片会被加载（离线或被墙时显示为空白）。
- 已知未完成项：引用区里的列表圆点/围栏代码块、自动链接、HTML 注释的投影仍按源码显示。
