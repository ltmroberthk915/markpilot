## 一 这一版修的是什么

用户第 4 份手验报告（原文）：

> 双dollar符的还是没有实现我想要的效果, 光标插入(2)之前, 按退格键, 会直接删除$$...$$内部的公式 而非删除$符本身

对着**装好的 2.1.2**（CDP 真鼠标/真键盘 + 磁盘字节 + 独立几何量测）把这一下复现出来，量到三个真实机制：

| # | 机制 | 实测证据（安装版 2.1.2） |
|---|---|---|
| 1 | 点公式块下方"留白"其实点进了**隐藏的公式源码**里（折叠时源码 `pre` 是 `0×0` 的壳）；同一片留白靠左得到源码末尾 `TEXT@70`、中间得到 `TEXT@0`、更靠外得到 `pre@27`（预览子树里的元素级位置） | 点一下再退格：`x+y=1` → `x+y=`（删掉公式里一个字符）；验收场景 74 的"在尾 `$$` 上按退格"断言 |
| 2 | 段落贴边的保护只找**同级兄弟**；素材里 `> $$ … $$` 后是一行不带 `>` 的空行、再跟 `> (2)`，两者分处两个 blockquote，于是没有任何保护 | `> (2)` → `(2)`、`> 证:` → `> 证:(1)`（整段引用块的 `>` 前缀被削掉） |
| 3 | 点 `$$` 会把人塞进源码里（2.1.2 的设计），所见非所得；紧接着按退格又是删源码 | 点前 `$$` 落到 `code[math-block]@0`、点尾 `$$` 落到源码末尾 |

## 二 改成什么

- **折叠态的鼠标落点按几何归位**：点空白留白 → 光标落到公式块**之前/之后**（按点在上下半），公式不展开、绝不落进隐藏源码；点渲染结果 → 照旧交给 Vditor（点公式 = 展开源码并进源码编辑）；展开态点围栏 → 光标**就停在 `$$` 上**（`$` 前／两个 `$` 之间／`$` 后，按横向位置）。带修饰键的点击与双击/三连击不接管（拖选、选词不受影响）。
- **段落贴边沿祖先链找相邻公式**：同级兄弟没有就往上找，父级兄弟的**末尾/开头**是块公式同样拦下。
- **贴边/围栏位置只做两件事，文档一个字节都不改**：光标停在看不见的位置（零宽 `$` 标记、owner 缝隙）才挪到最近的可见文字位；已经站在看得见的位置（围栏、相邻段落首尾、预览子树）就原地不动，只弹一句说明。
- **围栏上打字/粘贴/输入法**：字符进源码的对应一端，围栏与 markdown 都不会被写坏；块公式的 `$$` 标记不再可能持有游离字符。
- **一次性说明气泡**（复用既有 `.typora-context-toast` 样式，2.6s）：围栏上退格 → "`$$` 是渲染生成的围栏，删不掉单个 `$`，逐字符改围栏请切源码视图"；紧贴公式块退格 → "会把公式拆散，已拦下，要删整条请先选中它"。

## 四 一条如实说明（"删掉一个 `$`"为什么仍然做不到）

用户把"源码编辑只会删掉最后一个 dollar 符"当期望。本轮把代价量清楚了（三条都是实测）：

1. 直接改围栏 span 的文本（`$$`→`$`、`$$`→`$$$$`）后 `getValue()` **一个字节都不变**——围栏是 Lute 每次重排生成的标记，不参与序列化。
2. 真去改 markdown（闭合围栏写成 `$`）会让 Lute **重新配对围栏**：实测紧随其后的 `> (2)` 那一行被**吞进公式源码**（`code.textContent` 末尾出现 `(2)`）；开场围栏少一个 `$` 则把**下一条公式的开场 `$$` 拉上来**当自己的闭合围栏。
3. 改 markdown 只能整篇重排：2 万字 **24ms**；49 万字（348K 字符 / 5634 条公式）**2.0–2.2s**，且前后**不是逐字节相同**（Lute 会顺带规范化别处的内容）。

所以本版给的是：**围栏成为真实可站的光标位置**（"光标自由插到 dollar 符位置"做到了），围栏上按退格**不改文档**并**当场说明原因与正路**（源码视图里 `$$` 就是文本）。要删整条公式：选中它再按 `Backspace`/`Delete`。

## 六 等你手验的点（三分钟）

1. 打开 `排版测试-数理逻辑1(1).md`，把光标**点在该文件里 `(2)` 这一行的左边**（或点公式块下方那片空带），按一次退格：**公式与引用块一个字节都不该变**；如果落在围栏/贴边处，会看到一句说明气泡。
2. 点一下块公式（源码展开），再点**前 `$$`** 或**后 `$$`**：光标应该就停在 `$$` 上（`$` 前／两个 `$` 之间／`$` 后都能站）；在那里打字，字符应落进公式源码对应的一端（围栏不被写坏）。
3. 在 `$$` 上按退格：文档不变 + 弹出说明；想看"逐字符删围栏"，用工具栏「切换源码视图」，那里 `$$` 是普通文本。
