# MarkPilot 2.1.28

**工具栏可以收起来了。收窄窗口时，标题左边的级别角标也不再贴边。**

## 工具栏收成一个小按钮

工具栏最右边多了一个按钮。点一下，整条工具栏收起来，只在编辑区右上角留一个小按钮，正文随即上移，把原先被占住的那块高度还给文字；再点一下，工具栏原样回来。

- 收起状态会记住：关掉程序再打开，它还是收着的。
- 收起之后，工具栏上的菜单、提示不会突然冒出来打扰你；贴到窗口顶部也不会弹回来。
- 展开/收起是滑进滑出的，不像开关那样"啪"地跳一下。

写法、读长文、只想看字的时候，把它收起来就是一块完整安静的页面。

## 窄窗口下标题级别角标不再贴边

窗口缩窄到一定宽度后，标题左边的 `H1` / `H2` 级别角标会被挤到写作区最边上、左边一点留白都不剩（右边照旧有）。现在它左边始终留着一圈空白，与右侧观感一致。宽窗口下的版心居中完全没变。

## 安装

- **Windows 桌面版**：`markpilot-Setup-2.1.28.exe`（免安装：`markpilot-v2.1.28-portable.exe`）
- **VS Code / Trae 插件**：`markpilot-2.1.28.vsix` —— 扩展面板 → 右上 ⋯ → 从 VSIX 安装…
- **校验**：`SHA256SUMS.txt`

## 修复

- 窗口缩窄后，标题级别角标（`H1`…`H6`）左侧的留白消失、角标贴到编辑区边缘。
- 工具栏在窄窗口里会换行占掉好几行高度，此前只能任它占着；现在可以一键收起。
