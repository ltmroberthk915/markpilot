## 性能：冷启动大幅提速

定位到的真凶不是"编辑器需要预热"，而是内部静态资源服务的实现缺陷：打包后资源位于
`app.asar` 内，而 Electron 对归档内路径的 `open()` 会**把整个文件先复制到临时目录**
（3.8 MB 的 `lute.min.js` 要 1161 ms，约 4 MB/s）。改为整读回写后：

| 指标（安装版实测） | 2.0.17 | 2.0.18 | 变化 |
|---|---|---|---|
| 小文档：从启动到内容上屏 | 1538 ms | **546 ms** | **−1001 ms** |
| 中等文档 | 1600 ms | **637 ms** | −963 ms |
| 大文档（约 21 万字符） | 1918 ms | **914 ms** | −1004 ms |
| 编辑器页内耗时（小/中/大） | 1234 / 1323 / 1630 ms | **259 / 344 / 635 ms** | 约 −980 ms |
| 换文档（热打开） | 127 ms | 127 ms | 持平 |
| 滚动帧间隔 / 掉帧 | 16.7 ms / 0 | 16.7 ms / 0 | 持平 |
| 阅读位置还原误差 | 4 px | 3 px | 持平 |

## 改进

- 每键重解析收窄：编辑时不再整篇扫描公式节点，改为只处理光标所在与上一键展开过的块。
- 构建链路离线化：出包不再依赖外部下载（此前在受限网络下会挂满 600 秒后失败）。
- 新增 4 组打包产物验收场景（表格单元格内公式编辑与行列增删、行内公式往返字节保真、大文档
  滚轮到底与文末编辑、查找替换/粘贴/剪切撤销），验收总数 8 → 12 组。

## 安装

1. **桌面版**：运行 `markpilot-Setup-2.0.18.exe`（或直接用便携版）。升级安装会保留你的设置、
   最近文件与阅读位置。
2. **插件**：VS Code / Trae → 命令面板 → `Extensions: Install from VSIX...` → 选 `markpilot-2.0.18.vsix`
   （或把解包目录放到 `~/.vscode/extensions/markpilot.markpilot-2.0.18/` 后重启 IDE）。

## Bug 修复

- **右键菜单「剪切」只复制、不删正文**：在 Electron 中 `document.execCommand('cut')` 会返回成功
  并把文字写进剪贴板，却不删除正文，导致点「剪切」看起来没反应、再粘贴会出现重复内容
  （同一选区按 `Ctrl+X` 是正常的）。现已改为以"选区是否真的被删除"为准，必要时自行删除。
- **含表格文档存盘后表格被重排**：保存时表格会按列宽对齐（列宽补空格、分隔行破折号数按列宽重算）。
  经复核**重新打开后行/列/单元格内容完全一致**，属排版归一而非数据损坏；本版未改变该行为，
  仅补充了"表格语义往返"的自动化验收，避免其被误判为回归。
- **含内嵌图片文档的复制图片失败**（上一版修复项，本版复核仍正常）：复制的图片在打包产物中
  可正确写入系统剪贴板（字节级校验通过），可粘贴到微信/Word/Excel。
