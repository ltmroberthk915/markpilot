# MarkPilot 2.2.16

这一版把图片的两处手感补齐：连点图片总能展开源码；点图片右侧的空白，光标就落在图片后面，
回车在图片下方新起一行。

## 连点图片，源码一定展开

双击图片（或快速连点）以前时而展开、时而又收回去——同一张图，点得快慢不同结果不同。
现在连点几次都一样：源码展开、光标落在图片源码里（路径那一格），直接就能改。

## 点图片右侧的空白，光标落在图片后面

文档以图片结尾时，以前想接着往下写，得先展开图片源码、再用键鼠把光标挪到末尾。现在只要
点图片右侧那一片空白，光标就落在**图片之后**，按回车就在图片下方新起一行。

正文里直接写 `<img …>` 的图片同样照顾到：点它右侧空白会展开源码行、光标停在源码末尾，
回车在图片下方新起一行，打字不会再跑进标签里面。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.16.exe`；便携版 `markpilot-v2.2.16-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.16.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.15 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。

## Bug 修复

- **快速连点图片时，源码时而展不开**：以前每次点击都会先把已展开的源码收起来、再按这次点击的
  落点决定是否重新展开，点得快时第 3 下常常落在图片外面，于是刚展开又被收回去（点几次能不能
  展开，全看次数是奇是偶）。现在连点图片一律展开，连点落在已经展开的源码行上也不会再折回去。
- **点图片右侧空白，光标有时落在图片前面**：那条空白以前交给浏览器就近判断，落点在图片前后
  之间摇摆。现在点图片右侧（或下方）的空白，光标一定落在图片之后，回车就在图片下方新起一行。
- **正文里直接写的 `<img …>`，点它右侧空白后打字会跑进标签里**：以前光标被放进隐藏的源码开头
  （也就是图片**前面**），接着打字就打进标签内部。现在会展开源码行、光标停在源码末尾，回车即
  在图片下方新起一行。
- **整栏宽的截图，点图片右下那一带打字会丢**：那一小片区域以前会把光标放到编辑器外面，输入
  直接丢失。现在同样落在图片之后的可用位置。
- **单击、Alt+单击、从图片旁边拖拽**：这三种既有手势保持不变（选中 / 展开源码 / 原生拖选）。
