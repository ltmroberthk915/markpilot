# MarkPilot CM6 3.0.3 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

这一版修的是图片：**编辑面能看见图了**，含内联图片的大文档不再变成一屏乱码。

---

## 这一版你能得到什么

**图片在写作面上直接显示**

- `![说明](图片地址)` 与从网页/Word 复制过来的 `<img src="…">` 两种写法，写作面上都渲染成**真图**，不再是"一行标记"或一个孤零零的 `!`。
- 只加载你看得见的那几张：滚到哪儿解码到哪儿，几十张插图的长文打开也不卡。

**带内联图片的大文档不再"坏掉"**

- 有些工具会把图片直接嵌进文档（一行的长度可能几十万字符）。此前这类文档在写作面上会被当成**纯文本**铺出来——满屏乱码、文档被撑到几十万像素高、图片一张都看不到；旧版 v2 能正常打开，3.0.0–3.0.2 会坏。
- 现在这类图片同样渲染成真图：一份 8.13 MB、含 24 张内联图的文档，打开后正文渲染字符从 11,129 降到 **432**，文档高度从 **282,779 px** 回到 **5,954 px**。

**大文档存得回去**

- 通过插件面板编辑时，超过 8 MB 的文档此前会被服务端以"体积过大"拒收（能打开、存不回去）；上限已提到 **64 MB**。

## 说明

- 本版是**独立桌面应用**，与 VS Code 扩展版各自独立演进，本次不更新扩展（VSIX）。
- 编辑内核为 CodeMirror 6 + KaTeX，应用内为纯本地渲染，不需要联网。
- **超长图片地址的编辑方式**：为避免把几十万字符重新铺回写作面，内联大图的地址不在写作面上展开；要改地址用「编辑源码」或把光标放到该行按行首/行尾方向键绕开图片后手动修改。
- 超过 2 万字符的单行不再做加粗/斜体/链接的"所见即所得"投影（这类行通常是机器生成的图片数据），以免每次按键都要重扫全文。
- 写作面里一张大图刚滚入视口时会有极短的一瞬空白，属正常的按需解码。

## 本次更新

**图片**

- 写作面支持 `![说明](地址)` 与 `<img src="…">` 两种写法的真图渲染。
- 内联图片（data URI）不再被当成文本排版：满屏乱码、文档被撑高的问题解决。
- 图片按视口解码；超长地址不会被"光标进入即展开"重新铺回写作面。
- 懒加载写法（`data-src`）、`srcset`、属性值里带 `>`、地址里带括号的图片都能取到正确地址。

**表格**

- 点某一格时，光标落在你点的那个位置（此前一律跳到格尾）。
- 行内格子数少于表头的表格，点空白格不再显示成别的格的内容。

**稳定性**

- 修复一处会让图片与链接扫描越界的问题（该问题会让编辑器无法加载文档）。
- 插件面板保存上限由 8 MB 提升到 64 MB。
