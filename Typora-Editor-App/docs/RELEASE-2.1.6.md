# MarkPilot 2.1.6

## ✦ 文件树里新建/重命名，名字输入框会自己接住键盘了

在侧边栏点「新建 Markdown」或按 F2 重命名时，输入框以前**不会自动获得焦点**：你直接打字，字会丢掉；
先点一下输入框再打，光标又落在名字末尾，于是文件名被接成「未命名.md我的笔记.md」。现在点完按钮
（或按 F2）就能直接打字，主名会被替换、扩展名保留。

## ✦ 用 Windows 工具编辑过的文件，行尾不再被改掉

带 CRLF 换行的 Markdown 文件，改一个字保存后就**整篇变成了 LF**：记事本里会显示成一大行，
git 里也会显示「整个文件都被改了」。现在保存会按文件原本的行尾还原（CRLF 还是 CRLF，
末尾没有换行的文件也不会被补一个换行）。

## ✦ 内容缩放的快捷键回来了

`Ctrl+=` 放大、`Ctrl+-` 缩小、`Ctrl+0` 回到 100% —— 桌面版里这三个键以前**完全没反应**
（只有 `Ctrl+滚轮` 能动）。现在都好了，右下角的比例徽章会跟着变。

## ✦ 用别的工具写好的 Markdown，改一个字保存后不再变形

有些写法在编辑器的内部结构里"没有位置"，于是保存时会被悄悄丢掉——你只是改了一个字，文件里却少了东西：

- 行尾的**两个空格**（Markdown 的硬换行）没了 → 本该换行的地方不再换行
- 行尾的**反斜杠**（另一种硬换行写法）没了 → 同上
- **四个空格缩进的代码块**被拉平成了普通正文 → 代码变成散文
- 代码围栏后面的说明（```js {1,3-5}、```python title="示例"）被截断，只剩语言名
- 引用式链接定义里的**标题**（`[doc]: https://… "标题"`）丢失

这些现在都会原样保留；上面五种情况在 **CRLF 行尾的文件**里也一样成立（这一条最初漏了，已补上并写进回归）。

## 修复

- **文件树的新建/重命名输入框拿不到焦点**：点「新建 Markdown」后直接打字会丢字；先点一下输入框再打，
  光标落在末尾，文件名被接长成「未命名.md我的笔记.md」。现在输入框会自动获得焦点并预先选中主名
  （扩展名保留），直接打字即可替换。
- **CRLF 文件保存后被整篇换成 LF**：Windows 上记事本打开会变成一行、git 显示整篇改动。现在按文件
  原本的行尾还原；顺带保证「末尾没有换行的文件」不会被补上换行、带 BOM 的文件 BOM 不丢。
- **桌面版内容缩放快捷键失效**：`Ctrl+=` / `Ctrl+-` / `Ctrl+0` 之前完全没反应（只有 `Ctrl+滚轮` 有效），
  现在三个键都按预期缩放，比例徽章同步更新。
