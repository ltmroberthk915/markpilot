## 二 把"图片"这条钉死

1. `probe-u3-image / -image2 / -image3`（用户原文档副本）：
   - 点图片→`typora-img-selected` 有、`getSelection()` **塌**（`selCollapsed: true, selLen: 0`）；
   - 按 Delete：源码差异 `{at: 2, removed: "第"}`——**吃掉了标题里的一个"第"**，图片还在（`htmlImgs` 不变）；
   - 按 Backspace：差异 `{at: 0, removed: "# "}`——把标题标记吃了；
   - 两种键之后**光标都在标题 H1 上**（`chain: ["H1.vditor-ir__node ..."]`）。
2. `probe-u3-dom`：这些图片是 **HTML 图片**，DOM 结构是
   `IMG → PRE.vditor-ir__preview → DIV[data-type="html-block"].vditor-ir__node`，源码在块内的 `CODE` 里。
3. `probe-u3-api`：直接调产品自己的 `vditor.__media.removeImage(img)` —— **它能正确删掉**
   （差异恰好是那段 `<img …>`，光标落在删除点，一次撤销复原）。→ 说明"算不出源码范围"不是病因，
   **病因是按键守卫**：旧判据要求 `!selection.isCollapsed && range.intersectsNode(selectedImage)`，
   而 HTML 图片点选后选区是塌的 → 判定"不算选中"→ 放弃删除、**把这次按键让给浏览器** →
   浏览器按"删光标左边那个字"处理（光标停在标题上，就删标题的字）。
4. 修法（`js/media-tools.js`，keydown 守卫）：按 Delete/退格时**以点选状态为准**，
   `if (selectedImage?.isConnected) elements.unshift(selectedImage);`，不再看 DOM 选区。
   `selectedImage` 只由"点在图片上"这一次设置，点到别处/按 Esc 会清掉，所以不会误删。
5. 复查（你的原文档副本 + 2.1.12 打包产物）：两种键都**只删掉那段 `<img …>`**（含紧随的空行），
   **别处零改动**，光标落在删除点的正文里，**一次** Ctrl+Z 复原（字节逐字节相同）。
6. 场景 82 新增第 ⑤/③b 组（HTML 图片：点选→Delete→源码逐字节对比→别处零改动→光标位置→一次撤销），
   共 **22 条断言 / 13 证人**，开发树与打包 2.1.12 都 22/22。

## 四 真实键鼠注入工具（本轮补齐）

- `scripts/acceptance/win-sendinput.ps1`：
  - 新增 `drag` 动作（move → LEFTDOWN → N 步 MOVE → LEFTUP，带 `-Steps`/`-Hold`）；
  - 新增 `-TargetPid`（先按 PID 找窗口，找不到再退回按进程名）——**参数不能叫 `-Pid`**：
    PowerShell 的 `$PID` 是只读自动变量，同名参数会直接报错（踩过）；
  - 文件保持**纯 ASCII**（PowerShell 5.1 用 ANSI 读无 BOM 脚本）。
- 探针侧注意三点（都踩过）：
  1. **DPI 不感知进程的坐标是虚拟 96dpi 空间**：PowerShell 拿到的 `ClientToScreen`/`SendInput`
     坐标与页面里的 `devicePixelRatio`（这台机器是 1.5）不是一个空间，换算要 1:1，乘 dpr 会把点送到窗外；
  2. `GetClientRect` 与页面 `innerWidth` 一致（1166），可用来校对；
  3. 被测 exe 复制成唯一名字 **`MarkPilotProbe.exe`** 再启动：`-Name MarkPilot` 会匹配到用户正在用的实例，
     那是绝不能碰的。
- 实测真实点击能进到界面：iframe 内事件日志收到 `mouseup {x:737,y:372}`（= 我瞄准的那个字符右缘，
  iframe 相对坐标）——**应用确实收到了我的真实点击**。同一时刻 `document.hasFocus()` 为 false
  （另有程序在抢前台，`foregroundAfter=AppProxySwi`），所以这次真实点击没有落下光标；
  这是本机环境干扰，不是产品问题（合成输入那条路上光标一切正常）。
