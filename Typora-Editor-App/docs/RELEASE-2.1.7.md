# MarkPilot 2.1.7（自用版）

> 面向已经装过 2.1.6 的用户：这一版修的是**日常操作里那几处"点了没反应"**，以及两处会让人丢内容的地方。

## 一句话

开始界面上的「打开文件夹」以前可能什么都不做；关掉应用再打开，上次的窗口不会回来；文件树里删文件
永远删不掉；文档里的小节链接点不动；Ctrl 多选几张图片之后按删除没反应；公式提示框会盖住你正在写的那一行、
还会盖住鼠标。这一版把这些全部修好。

## 修了什么

| 你遇到的现象 | 现在 |
| --- | --- |
| 开始界面上点「打开文件夹」屏幕上没变化 | 侧栏自动展开、文件树摆出来，欢迎页提示"从左侧文件树选择" |
| 关掉应用再打开，昨天的窗口和文件都没了 | 按原来的文件、位置、尺寸原样恢复（含关掉最后一个窗口那次） |
| 文件树右键「删除（回收站）」点了没反应 | 先问一句，确认后进回收站可恢复；取消则什么都不做 |
| 新建/重命名文件失败时没有提示 | 侧栏里出现红色错误条 |
| 菜单「在此窗口打开文件…」却开了新窗口 | 就在当前窗口里替换文档（有未保存修改会先问） |
| 点文档里的 `[跳到第三节](#第三节)` 没反应 | 滚到那一节并高亮一下 |
| Ctrl 多选几张图后按退格/Delete 没反应 | 一次整批删掉，撤销能回来（而且键盘焦点不再丢） |
| 公式/片段提示框盖住正在编辑的那一行和鼠标 | 只在那一行的上/下方、整体留在窗口内，绝不压住那一行与鼠标 |

## 值得单独说的两条

**「关掉应用再打开，什么都没了」。** 这不是玄学：正常退出时程序把"上次开着哪些窗口"这份记录
一条一条清空了（所以崩溃或被强杀反而能恢复）。现在正常退出与关最后一个窗口都会把这份记录留住。

**「多选图片后按删除没反应」。** 除了删除本身没处理多选，还有一个更隐蔽的原因：Ctrl 点选之后
编辑区**丢掉了键盘焦点**——从那一刻起，键盘输入根本没进文档。所以这一条不只是"删不掉"，
而是"那之后打字也进不去"。两处都修了。
