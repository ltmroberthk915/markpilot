# 1.0.4 / VSIX 0.1.11-local

2026-09-06，两端使用同一份渲染器。

## 本轮改动

1. 工具栏前部新增可见的 **主题** 文字按钮，点击选择默认浅色/深色或 Konayuki Light/Dark。桌面另有 **查看 → 主题（含 Konayuki）…**。提示显示当前主题，原有主题选择持久化继续生效。
2. 正文粗体字重由 700 提高为 900，并增加 0.015em 描边，使只有一种粗体字形的中文字体也有明显变化。生成的公式预览不继承描边。
3. 大纲从编辑器顶部延伸到底部，填满工具栏左侧原有空白。右边界支持鼠标/触屏拖动，保存宽度；双击恢复默认，键盘左右箭头也可调节。拖动范围为正常窗口下 160–640 CSS 像素，窄窗口进一步收窄，至少尽量给正文保留 240 像素。正文缩放不会使拖动距离失准。Vditor 源码模式原有的大纲隐藏行为保留。
4. 查找面板增加 **查找 / 替换** 两个模式按钮。切换保留查找内容、替换内容、大小写选项和当前命中位置；没有命中或搜索仍在进行时也能切换。
5. **Esc** 可从查找框、替换框、按钮或正文关闭查找面板，并释放 Worker 和高亮。焦点已经回到正文时保留正文光标。输入法组合输入期间不拦截 Esc；打开主题等模态对话框时先关闭前景对话框。

## 布局与能效

大纲仍使用原有 DOM 节点及原生导航逻辑，只通过负上边距填补工具栏左侧空白。布局使用 ResizeObserver、有限属性观察和按帧合并的拖动更新，没有空闲轮询，也不重新解析文档或公式。

CSSOM 会对小数像素取整；宽度更新使用数值容差，避免把取整后的序列化差异当作新变化而产生持续动画帧。150% 正文缩放、带小数坐标的拖动后，空闲观察窗口中大纲样式变更次数为 0。
