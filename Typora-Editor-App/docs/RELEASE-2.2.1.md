# MarkPilot 2.2.1

公式围栏这一次按"能直接编辑"重做了，另外修掉三处让光标和内容不听话的地方。

## 围栏可以直接编辑

- **行内公式的 `$` 就是普通字符。** 在公式外侧按退格，删掉的就是那一个 `$`，公式随之变回普通文本——
  `$a$` 变成 `$a`，内容一个字符都不会少。光标停在 `$` 上按退格或删除，效果完全相同。
- **块公式里按退格/删除，改的是公式源码。** `$$` 只是公式的外壳，光标本来就在源码里：每按一次删掉
  一个字符，源码删空之后整条公式移除。不会再出现"按下去像是没反应"。
- **贴着公式块按退格**：公式展开成源码并整条选中，确认之后再按一次删除即可。
- 行内公式里的内容被删空时，不会再变成另一种公式（过去会突变成块公式围栏）。

## 空公式看得见、删得掉

`$$` 空块过去在页面上是一块什么字都没有的空白：既看不到，也点不进去，更删不掉。现在它会显示一枚
**"空公式"占位**，点进去就能编辑，在里面按退格或删除会整条移除，文件里也不会留下多余字符。

## 光标移动

- **上下方向键**：整行只有一条行内公式时，光标会落在那一行（过去会整行跳过）。
- **Shift + 方向键**：在公式源码里按住 Shift 连按方向键，选区一路平稳地长起来，不会选一半又塌回去。
- 点公式块周围的空白、点渲染出来的公式本体，落点行为与上一版一致。

## 安装

- 桌面版：运行 `markpilot-Setup-2.2.1.exe` 按向导安装；也可以直接用免安装的
  `markpilot-v2.2.1-portable.exe`。
- 编辑器扩展：在 VS Code / Trae 里安装 `markpilot-2.2.1.vsix`（扩展面板 → 从 VSIX 安装，或
  命令行 `code --install-extension markpilot-2.2.1.vsix`）。

上一版的内容（EXE 与 VSIX 同版本发行、空列表项与表格公式的手感修复等）全部保留。
