## v2.0.18 更新

### ✦ 冷启动快了一秒

这一版最大的一件事，是把一个隐蔽到几乎不可能靠手感定位的实现缺陷挖了出来：打包后编辑器要用的
3.8 MB 核心脚本，在读取时被系统先整份复制了一遍临时文件（同一份文件实测要 1161 ms）。改成直接
整读之后，**小文档从启动到内容上屏：1538 ms → 546 ms**，中等文档 1600 → 637 ms，二十万字的大
文档 1918 → 914 ms。换文档（热打开）本来就很快，这版保持在 127 ms；滚动、位置还原也都没退化。

### ✦ 表格里的公式，真的能改

单元格里的行内公式现在被单独验到字节级：点进去即展开源码，改完立刻重排；上方插入行、下方插入行、
左侧插入列、右侧插入列、删除当前行/列都走真实右键菜单，并且**加了再删要回到一字不差的磁盘原文**
才算了账。表格里的公式改写之后，表格之外的正文一个字符都不动。

### ✦ 保真：不动的地方，存盘就该一个字节都不变

新增"往返保真"验收：只敲一个字再退格（内容回到原文）之后保存，磁盘文件必须与原始**逐字节相同**——
零宽脚手架、公式重排、转义改写这类"悄悄改了你的文件"的问题都会在这里现形。

### ✦ 边缘用例扩到 12 组

验收从 8 组扩到 12 组（共 180 条断言），新增：表格单元格内的公式编辑与行列增删、行内公式的往返
字节保真、二十万字文档滚轮到底 + 文末编辑 + 文档切换、查找替换与粘贴/剪切/撤销的混合编辑。
全部跑在**打包好的安装版产物**上，并且每条判据都必须来自代码之外的通道（系统剪贴板读回、磁盘
字节、独立进程、几何量测），产品自己"说成功了"不算数。

## 修复

- **右键菜单「剪切」只复制、不删正文**：在某些环境下，系统提供的剪切命令会返回成功并把文字放进
  剪贴板，却不真的删除选中的文字，导致点「剪切」看起来没反应、接着粘贴还会出现重复内容（同一
  选区按 `Ctrl+X` 是正常的）。现在改为以"选区是否真的被删除"为准，必要时自己完成删除。
- **表格保存后会重排排版**：保存时表格会按列宽对齐（列宽补空格、分隔行的破折号按列宽重算）。
  复核结论：**重新打开后行、列、单元格内容完全一致**，属于排版归一而不是数据损坏；这一版没有
  改变该行为，只是补上了"表格语义往返"的自动验收，避免它被误判成回归。
- **含内嵌图片的文档复制图片失败**（上一版修复项，本版复核依然正常）：在打包产物中，复制出的图片
  能正确写入系统剪贴板（字节级校验），可直接粘贴到微信、Word、Excel。
