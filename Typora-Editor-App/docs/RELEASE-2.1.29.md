# MarkPilot 2.1.29

**打字时光标不再乱跑：软换行、行内公式都归位了。**

## 软换行后用输入法打字

在某一行行尾按 Shift+Enter 换到新行，接着用中文输入法打字，光标会跳回上一行、字落在段落开头（素材标题下那一行"路边等间隔种树…"就是这么被顶掉的）。现在字老老实实落在新行上。

## 公式内外，光标各归各位

- **行内公式（Ctrl+Shift+E）后面接着打字**：用右方向键走出公式再输入，字落在公式**外面**；以前会被写进公式源码里，光标也跟着跳回公式内。
- **方向键碰到行内公式不再整块跳过去**：朝公式方向按方向键，会打开公式源码编辑区、把光标送进公式里（与 Typora 一致）；在源码里再按方向键就一个字符一个字符地走，走到两头自然出来。
- **公式后按 Shift+Enter 换行**，接着用输入法打字：换行与字都落在公式外面，不会被公式的 `$` 吸走。
- **块公式（`$$` 独立成段）**：光标与输入位置同样核对过，打字落在光标处的源码里。

## 安装

- **Windows 桌面版**：`markpilot-Setup-2.1.29.exe`（免安装：`markpilot-v2.1.29-portable.exe`）
- **VS Code / Trae 插件**：`markpilot-2.1.29.vsix` —— 扩展面板 → 右上 ⋯ → 从 VSIX 安装…
- **校验**：`SHA256SUMS.txt`
