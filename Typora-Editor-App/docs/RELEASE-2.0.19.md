# MarkPilot 2.0.19

## ✦ 导出终于会问你把文件放哪了

导出从工具栏「更多」里的一个小图标，改成**一眼可见、带「导出」二字的一级按钮**：点开就是
PDF / Word / HTML / 便携 Markdown 四选一，**先弹保存对话框让你选好位置、点了确认才开始导出**；
导出完成后会自动打开资源管理器并选中刚生成的文件，不用再猜它去哪了。

## ✦ 工具栏清爽了：不再有装样子不干活的按钮

去掉了几个看着像功能、点了却没反应甚至帮倒忙的按钮（详见下面「修复」）。工具栏上留下的每一项都真的能用。

## ✦ 鼠标侧键不会再把你正在写的东西翻走

用带前进/后退侧键的鼠标时，编辑区不会再被整片翻走；中键、右键一切照旧。

## 修复

- **导出 PDF 之后不知道文件去哪了**：工具栏「更多」里原先同时有两个「导出」，一个是我们自己的（只有一个没文字的图标），另一个是编辑器内核自带的（写着「导出」，而且只有它里面有 PDF）。点后者导 PDF，屏幕会提示"生成中"，但**文件从来没有被创建过**——它只是把内容塞进一个零高度的隐藏框去调系统的打印命令；导 Markdown / HTML 则会不声不响地下载进系统下载目录。现在那个会骗人的入口已经移除，「导出」提升为带文字的一级按钮，导出成功后会直接帮你定位文件。**编辑器自己的导出引擎一直是好的**（PDF / Word / HTML / 便携 Markdown 四种格式逐字节校验通过），坏的是入口。
- **鼠标侧键会让整个编辑区消失**：用带前进/后退侧键的鼠标时，按「后退」编辑区会整片消失，再按「前进」才拉回来。原因是编辑器把每份文档都装进内部框架，每开一个文档都会往浏览历史里压一条记录，「后退」就把它退回了上一个文档甚至空白页。现在前进/后退侧键（以及常被鼠标驱动映射成的 Alt+←/→）都会被拦下。
- **录音按钮是个坑，已移除**：它看起来能录音，实际点下去会**占用麦克风**，录完却把音频当图片处理、弹一句「不支持的图片格式」，文件不会保存到任何地方；更麻烦的是它会让正文的编辑区变成**只读**，连点两次之后正文就打不了字了。这个功能从来没有真正接好，这版直接拿掉。
- **「关于」里讲的是别人的项目**：以前点「关于」看到的是编辑器内核那个开源库的介绍，还带着它的官网和论坛链接；「帮助」跳的也是它的文档站。现在「关于」显示 MarkPilot 自己的版本号和仓库地址，「帮助」指向我们的 GitHub 仓库。
