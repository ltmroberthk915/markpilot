# MarkPilot 2.2.3

这一版修的是"键盘与鼠标在正文、行内公式、块公式之间来回走"的手感：光标不再丢、列不再漂、
方向键真的逐行走；拖拽与 Shift 组合键的选中在真实长文档里也稳。

## 上下方向键

- **列不会漂了。** 沿着一列上下走，光标停在同一列；遇到短行就停在那一行的末尾（不是行首）。
- **到顶到底光标不会消失**，也不会把目标列弄丢——按到底再往回走，仍回到出发时的那一列。
- **真的逐行走。** 每一按只走一行，不会跨过中间还有内容的那一行。

## 左右方向键与 Home / End

- **行尾按 → 去下一行的行首**、行首按 ← 去上一行的行尾，和常见编辑器的习惯一致。
- 在文档最开头、最末尾这些边界上，**光标不会再"没掉"**。

## 鼠标与组合键

- 单击落点、双击选词、三击选段：位置与高亮都在你点的地方。
- 拖拽选中跨段落、跨行内公式、跨块公式都成立；拖完再按 Shift + 方向键还能继续调整选区。
- 在点击处按住 Shift 再点另一处，选中的就是这两点之间。

## 打开与保存

- 打开、保存仍然逐字节保真：本轮所有验收在文档副本上跑完后，磁盘内容与打开前一致。
