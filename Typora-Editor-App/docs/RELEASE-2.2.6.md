# MarkPilot 2.2.6

这一版把公式周围的两处"点下去不顺手"改好了：点公式旁边的空白、以及编辑公式时预览框挡住正文。

## 点公式旁边的空白，光标落在你看得见的地方

- 点块公式（`$$…$$`）**上方或下方**的空白：光标落到**上一行的末尾 / 下一行的开头**（Typora 的手感），
  不再是"点了一下什么都没有"。
- 如果紧挨着的下一行本身就是一条公式，光标会落到再下一行**有正文**的地方——
  既看得见，也不会在你不注意的时候把字打回公式里。
- 文档最上面那条公式**上方**的页边距行为不变。

## 编辑公式时，预览框不再挡住正文

- 光标停在一条行内公式里时，渲染出来的预览框默认仍在源码**下方**；一旦它要盖住下面那行字，
  就自动**翻到源码上方**——光标之后的那段正文始终看得见。
- 下方本来就是空行时不会翻（保持原位）；表格单元格里照旧占位撑高，不会盖住相邻格子。
- 公式很长、翻上去会被裁掉时也不翻。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.6.exe`；便携版 `markpilot-v2.2.6-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.6.vsix`，或直接在扩展市场更新。
