# MarkPilot 2.1.1

这一版全部是**公式编辑手感**的修复——都是在一份真实的排版测试文档里点出来的：

## ✦ 一行的最后是公式时，光标停在行尾不再弹出预渲染框

以前光标一落到这一行的行尾（在行尾点一下、或者按 `End`），最后一个公式的浮层就自己冒出来挡住下文。
现在**只有点公式本身**才会展开源码来编辑；停在公式前面、后面都只是普通的光标位置，
接着打字就落在公式之后。

## ✦ `$$ … $$` 前后那两个 `$$` 现在可以落光标了

以前块公式展开之后，不管点哪儿，光标都只能停在公式源码的第一个位置——那两个 `$$` 是画上去的伪元素，
不在文档里。现在它们是真实的文本：点它、拖选它、按字符改它都成立。

## ✦ 贴着公式按退格不再把公式毁掉

以前在公式块的边上按一下退格——块的开头、块的结尾、或者紧邻公式的那一段的首尾——
`$$…$$` 会整块散成一行纯文本，或者悄无声息地吃掉源码里的字符。

现在的规则是**一次只动一个单位**：

- 第一下：**把整条公式选中**（文档一个字都不动），你随时可以走开、不会丢东西；
- 第二下：把这条公式**作为一个整体**删掉。

想整块删公式仍然是两下就够；而**在源码里面**正常改字（在源码末尾退格、在源码开头删除）完全不受影响。

## ✦ 顺手修掉巡检中发现的三处同类问题

- 公式源码里按 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` 不再把 `****`、`**`、`<u></u>` 插进 TeX 源码
  （以前公式当场就坏）。剪贴板、撤销重做、全选不受影响。
- 公式源码里按回车不再把 TeX 拆断（以前会得到 `$a$a+1+1$` 这种垃圾）。行内公式里这一下
  只把光标移到公式之后；块公式是多行源码，回车照旧换行。
- 删除整条公式（你自己选中的，或者上面那一步替你选中的）不再留下 `<span>` 之类的残渣文本。

## 修复

- 光标停在行尾、而这一行以公式的 `$` 结尾时，最后一个公式被按「光标所在的节点」自动展开、
  浮出预渲染框：贴边的光标现在不算在编辑公式，并且会把自动挂上的展开态收回。
- 块公式的 `$$` 是 `::before`/`::after` 伪元素，不参与命中测试，鼠标怎么点都只能落到源码第 0 个位置：
  展开态改用真实 `$$` 文本节点（并关掉伪元素，避免画两遍），折叠态照旧只显示渲染结果。
- 光标作为节点的首/尾子位置（Chromium 在行尾常用的落点）时，退格会吃掉收尾的 `$`，
  把公式变成一行字面文本：这类贴边位置改为先选中整条公式。
- 块公式源码开头退格会把 `$$` 围栏拆掉（整块散成一行文本）；行内公式源码末尾删除会整条消失：
  围栏方向的删除改为先选中整条公式；向内改字保持原样。
- 光标停在块公式紧邻的段落首/尾按删除，会把公式块并进段落文本：现在改为先选中整条公式。
- 公式源码里的 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` 会把 Markdown 记号插进 TeX 源码：公式源码内不再生效。
- 行内公式源码里按回车把 TeX 拆断并复制出半截公式：现在只把光标移到公式之后，不改文档。
- 整条公式被选中后删除，浏览器会留下字面 `span` 残渣并连带吃掉后面的段落：改为自己摘节点。
