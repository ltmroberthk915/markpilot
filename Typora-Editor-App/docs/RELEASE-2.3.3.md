# MarkPilot 2.3.3 · 稳如磐石的写作手感收官版

2.3.3 是 MarkPilot 2.x 系列的收官版本：四处影响写作手感与内容安全的交互缺陷彻底根治，自动化验收场景增至 **71** 项，全部通过。如果你正在寻找一个把"光标落在哪、选区选到哪、内容丢不丢"做到像素级的 Markdown 编辑器，这一版值得立刻更新。

## 为什么更新

### 1. 图片下方新建行的输入，不再破坏后面的标题
在图片右侧空白处点击即可新建一行继续写作——现在，无论图片是标准 Markdown 图片、HTML 图片块还是设置过缩放的图片，在新建行里输入的文字都会**独立成段**，紧跟其后的标题、列表、引用原有结构分毫不动，撤销历史也逐字可回。此前，特定图片形态下输入的第一个字会把后面的标题"吞"进正文。

### 2. 标题行尾的 Shift+拖拽选择，精确到字
按住 Shift 从标题行尾拖拽选择时，选区从按下那一刻起就**精确锚定**——不再凭空多选错位的几个字、不再出现拖回起点却收不掉的残留高亮。段落、列表、引用里的同款手势保持浏览器原生行为，零干扰。

### 3. 空标题行周围的点击，行为符合直觉
文档里只写井号的空标题行（比如还没想好标题先占位），点击它与下方内容之间的空白区域，展开的图片源码会**立即收起**、光标清晰落在标题行内——和点击任何正文一样自然。拖拽选择则完全不受影响。

### 4. 查找替换的第一次撤销，光标不再消失
打开文档后第一次使用查找替换、随即按 Ctrl+Z，文字回来了，**光标也回来了**——落点清晰可见，无论你从快捷键、工具栏还是菜单打开的查找面板。

## 品质基线

- **71 项自动化验收场景**全绿，覆盖键盘、鼠标、组合键、键鼠配合、拖拽五类真实输入通道；
- 每处修复均通过"注入缺陷必须变红"的突变验证，杜绝安慰性修复；
- 中文输入法组合期间的一切交互（选择、查找、补全）让位保护，打字不断流。

## 安装与更新

- **Windows 安装包**：下载 `MarkPilot-Setup-2.3.3.exe`，覆盖安装即完成更新，设置与窗口布局自动保留。
- **便携版**：解压 `MarkPilot-2.3.3-portable.zip` 即用，可放 U 盘。
- **VS Code / 类 VS Code 环境**：扩展市场搜索 MarkPilot 更新到 2.3.3（本系列最后一个扩展版本）。
