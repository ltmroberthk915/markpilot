# MarkPilot 2.2.0

**这一版把"写笔记时最怕的那几件事"收掉了：字不会被写进公式里、文件不会被悄悄改坏、保存失败你看得见、崩溃了内容还在。图片复制也修好了。**

## 行尾空白点击不再把字写进公式

在段落行尾及其右侧的空白处点击，光标以前会跑进上一处行内公式的源码里——接着打的字直接写进公式，公式当场被改坏、还会保存到磁盘上。现在行尾之外的点击落在这一行的正文末尾，公式源码一个字都不会动。

原因是公式折行后，它在版面上占的是一个矩形，把"上一行尾部右侧那块空白"也盖在里面；现在这块空白由编辑器自己判定，不再被浏览器和公式预览误认。

## 一个没闭合的 `$` 不再吞掉后面的排版

写到一半漏了个 `$`，以前从那里往后的加粗、标题、列表会一起失效（预览整片变样），现在公式在它该结束的地方（第一个空行或文档末尾）闭合，后面的排版照旧。

## 文件不会被悄悄改坏了

- **非 UTF-8 的文件**（GBK、UTF-16 等）打开时会明确告诉你，并且**不会**自动保存回写原文件——以前会被按 UTF-8 解码成一堆替换字符再写回去，原文件就毁了。
- **保存失败看得见**：文件只读、被别的程序占用、文件被外部改过或删除，现在是一条常驻提示（不只是状态栏上的一个小点），并给出可以点的处理动作。
- **崩溃或异常退出后能找回内容**：编辑中的内容每 60 秒留一份本地快照；下次打开若发现有比磁盘更新的内容，会问你要不要**生成恢复副本**（原文件不会被覆盖）。偏好文件损坏时会留下备份并说明，而不是把设置悄悄重置。

## 图片

- **左键选中图片按 Ctrl+C 真的复制了**：以前"图片看着是选中的，按 Ctrl+C 却没反应"（既没有复制也没有报错）。
- **打开含内嵌图片的文档**不再弹出一个假的"发现未保存的内容"提示——那个提示本来只该在崩溃恢复时出现，以前会误报并挡住文档打开。

## 出问题时有东西可以交出来

帮助菜单里新增 **打开诊断日志** 与 **复制诊断信息**：崩溃、渲染进程异常、保存失败等都会记在本机日志里（只写本机，不上传任何东西）。

## 顺带的打磨

- 打开很大的笔记时不再出现"卡住几十秒"的假死（与上面那个误报提示是同一处原因）。
- 表格单元格里的公式、行内公式的点击与拖选、分栏与大纲面板、导出 HTML/Word/PDF 这一整片都补上了常驻验收，改动它们时会被当场拦住。

## 安装

- **Windows 桌面版**：`markpilot-Setup-2.2.0.exe`（免安装：`markpilot-v2.2.0-portable.exe`）
- **VS Code / Trae 插件**：`markpilot-2.2.0.vsix` —— 扩展面板 → 右上 ⋯ → 从 VSIX 安装…
- **校验**：`SHA256SUMS.txt`

## 修复

- 段落行尾及其右侧空白点击后，光标跑进上一处行内公式源码，继续输入会把字写进公式并存盘。
- 未闭合的 `$` 会让其后整段排版失效。
- 非 UTF-8 文件被按 UTF-8 解码后自动保存回写，造成静默损坏。
- 保存失败只在状态栏留一个小点；现在给出常驻说明与处理动作。
- 崩溃/异常退出最多丢 5 分钟输入且没有恢复入口；现在 60 秒一快照，启动时提示可生成恢复副本。
- 左键选中图片后 Ctrl+C 无反应（图片没被复制）。
- 打开含内嵌图片的文档时误弹"发现未保存的内容"，并会挡住文档打开。
