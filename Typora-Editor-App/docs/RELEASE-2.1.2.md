# MarkPilot 2.1.2

这一版是**对 2.1.1 的返工**。2.1.1 发布后你亲手验证的结论是「一个都没修复成功」——我把安装好的产物用真鼠标、真键盘重测了一遍，**你是对的**：2.1.1 的三条修复里有两条半是空的。这一版全部重做，并且把"对着交付产物验证"这一步固定成一条产物级验收场景。

## ✦ 贴着公式按退格，公式一个字节都不会变

以前（含 2.1.1）在公式块的边上按退格——块的开头、块的结尾、公式与 `(2)` 之间那条看起来是空行的地方——`$$…$$` 会整块散进上一段。2.1.1 把它改成了"第一下先选中整条公式、第二下整条删除"，所以**连按两次公式照样会消失**（这正是你看到的现象：第一次好像没反应，第二次公式没了）。

现在的规则是：

- **第一下：只把光标挪到公式外面最近的文字上**，文档一个字节都不改；
- **第二下：删掉的是公式外面的普通文字**（就是此刻光标所在位置该删的那个字）。

在公式源码**里面**正常改字完全不受影响（源码末尾退格删一个字符、源码开头删除删一个字符）。

## ✦ `$$` 围栏：点在哪，光标就落在哪

- 点**前** `$$` → 光标落在源码**开头**；
- 点**后** `$$` → 光标落在源码**末尾**；
- 接着打字，字符真的落在你点的那一侧。

（2.1.1 里那两个 `$$` 虽然已经是真的文本，但意义不成立：光标停在标记上打字，字符会悄悄跑到源码末尾；点尾 `$$` 光标还会掉进下一段。）

## ✦ 行尾公式的预渲染框：从机制上不可能再停留

以前光标一落到行尾（点一下、或按 `End`），最后一个公式的浮层会自己冒出来；2.1.1 试图"再收一次"，而 Vditor 加展开样式的时机不受我们控制，所以同一处点击**有时收得回、有时收不回**——你看到的是后者。

现在改成**结构性强制**：只要光标不在公式的源码/预览里，展开样式立刻撤掉。不再跟 Vditor 抢时序。

## ✦ 一条如实说明（没做到的事）

你在报告里把「源码编辑只删掉最后一个 `$`」当作期望。块公式的 `$$`、行内公式的 `$` 都是 Vditor 每次重排时**重新生成的标记**，编辑内核里并不存在"删掉一个 `$`"这个动作（改标记文本不参与序列化、会被丢掉）。所以这一版的取舍是：**贴边退格不改文档**，而不是假装删掉一个 `$`、把公式变成半截文本。

要删整条公式仍然很简单：**整条选中它，按一次 `Backspace` / `Delete`**——这条路径干净利落，不留 `<span>` 残渣、也不会吃掉下一段。

## 保留 2.1.1 的其余修复

整条选中后删除不留残渣；公式源码里 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` 不再把 `****` / `**` / `<u></u>` 插进 TeX；行内公式源码里回车不再把 TeX 拆断；折叠态不显示围栏。
