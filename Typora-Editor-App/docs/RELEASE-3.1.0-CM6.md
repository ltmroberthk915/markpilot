# MarkPilot CM6 3.1.0 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

## 这一版你能得到什么

**代码块有了行号**

围栏代码块左侧出现一列行号：灰色小字、右对齐、与代码之间一条 1px 细竖线——与 Typora 同一形态。

- 每个代码块都从 `1` 开始数，不会跨块接着往下编；
- 空行也占一个号；
- 引用区里的代码块同样有号；
- 行内代码没有号；一行折成好几屏的超长行也只算一个号；
- 行号只在屏幕上出现——复制代码、导出 HTML / PDF、看源码，都拿不到它。

**截图可以直接粘进文档**

复制一张截图（微信、QQ、系统截图工具都算），在文档里 `Ctrl+V`，图片直接落进正文并显示出来；光标在哪就插在哪。

**导出的 PDF 用整段最优断行**

导出 PDF 时，中文段落不是逐行塞满，而是像 TeX 那样**整段一起算**：愿意为后文牺牲前文，让每一行的疏密更均匀，并照顾中文禁则（标点不落行首、开引号不落行尾）。文档很大（源文超过 30 万字符）时自动改用标准两端对齐，并明确提示一句——不做半页精排、半页粗排的混合版式。

**图片落到哪里，你自己定**

设置里可以选两种图片落法：

- **落到 `assets` 目录（默认）**：图片存成文档同级的 `assets\图片名.png`，文档里写相对路径，几个文档共用一份素材。
  文档体积小、改动干净，推到 GitHub / GitLab 也能正常显示；
- **内联**：图片内容直接写进文档。文档复制到别的目录、别的盘，甚至把原图删掉，图照旧显示——适合"就要一个文件
  带走"的场合；代价是文档会明显变大，而且 **GitHub / GitLab 不显示这种内联图**。

文档还没保存过时（还不知道 `assets` 该放哪），粘贴的图会先内联进正文并提示先保存——图不会丢。

已经写好的文档可以整篇转换，两条命令都在「更多」菜单里：**「内联全部图片」**把本地路径的图收进文档（外链不动），**「抽出到 assets」**把内联的图落到 `assets\` 并改成相对路径。整篇转换按一次 `Ctrl+Z` 就能整体退回；来回转两次，文档内容一字不差。

**阅读模式下可以换一种排版方式：排版美化**

阅读模式右上角多了一个「排版美化」按钮（和退出胶囊同一簇，不挡正文），按一下就在两种段落断行之间切换；
也可以按 `Ctrl+Alt+K`，或在设置里选。

- **浏览器两端对齐（默认）**：你写多少、浏览器就怎么折行，和其它编辑器一致；
- **Knuth–Plass 整段最优断行**：像 TeX 那样**整段一起算**——愿意为后文牺牲前文，让每行的疏密更均匀，
  并照顾中文禁则（标点不落行首、开引号不落行尾）。适合阅读、校对、排版定稿时看效果。

两个说明：① 只在阅读模式下生效，且**超过 30 万字符的文档自动保持两端对齐**（大文档不做整段重排，避免拖慢）；
② 测量与断行都**跟着你的字体、字号设置走**，自定义 CSS 改过字号后重算。

**文件菜单里多了两条**

- **文件位置**：一眼看到当前文档存在哪；路径太长时中间用省略号收窄，避免把菜单挤出屏幕；
- **复制文件绝对路径**：整条完整路径进剪贴板，前面那点省略只影响显示，复制出来的永远是完整路径。

**表格复制到 Excel / Word，直接就是真表格**

- 在表格里任意位置按 `Ctrl+C`：Excel 里铺成真正的行列，Word 里是真表格（表头底纹、列对齐一起带过去），不再落成一列文字。
- 右键表格**任意位置**（包括表格左右边缘那一两个像素）都能唤出同样的复制命令；另有一条「复制为 Markdown 源码」给需要源码的场合。
- **单元格里按 `Ctrl+C` 不再假装成功**：以前在格子里按复制，剪贴板保持上一次的内容不变——粘出来的是你更早复制的东西；现在格内复制会真的写入。

**表格键位补齐**

- `Ctrl+Enter` 在下方插入行，`Ctrl+Shift+Enter` 在上方插入行；
- `Ctrl+Alt+←/→` 左右插入列，`Alt+↑↓←→` 移动行列；
- 插入行之后光标落回你操作的那一行（以前总是跳回表头）；
- 单元格内 `Ctrl+Shift+E` 插入行内公式 `$…$`（以前在这个位置是死键）；表格外同一个键仍是导出。

**几处挡视线的东西挪开了**

- 表格上方的浮动操作条不再压住表格之上的正文；
- 工具栏折叠成小圆岛后不再压住右侧滚动条，放大界面（内容缩放 101% 以上）也不会被推出屏幕；
- 折叠状态下用键盘（Tab 到按钮 + 回车）也能展开收起。

**图片显示的几处修正**

- 带 `width` / `height` 属性的图片按你写的尺寸显示，不再被强制压回原始大小；
- 行内代码里写的 `![](…)` 保持字面，不会被画成图片；
- 表格单元格里的图片与行内代码正常显示；
- 粗体、斜体、粗斜体嵌套（`**粗体里 *斜体* 收尾**`）不再残留星号。

**重新加载不会丢改动**

点「重新加载」从磁盘重读之前，会先把没保存的修改落盘；保存失败才弹确认，不会静默丢掉刚写的内容。

## 说明

- 本版是独立桌面应用，与 VS Code 扩展版各自演进，本次不更新扩展。
- 文档里的外链图片会被加载（离线或被墙时显示为空白）。
- **含超长单行的大文档打字跟手了**：一行几十万字符（常见于把截图直接内联进文档）的文档里，
  连续打字不再一顿一顿；在那种超长行**内部**编辑仍比普通行慢一些，下一版继续优化。
  普通长文档（含上千行表格）打字与滚动不受影响。
- 同类文档里还有一处可感知的口径：**≥2 万字符的单行里，`**粗体**`、`` `代码` ``、`[链接](…)`
  保持字面显示**——图片写法仍正常显示为图。这样做是为了让那种超长行上的每次按键都保持跟手。
- 零宽空格（Unicode U+200B）在正文里**看不见也不占位**——从别处粘进来的隐藏字符不再显示成一个红点，
  光标能停在它两侧、退格能删掉它。其它不可见控制字符仍会以红点标出，方便你发现它们。
- 尚未逐条取证：4 层以上嵌套引用、Tab 缩进形态。
