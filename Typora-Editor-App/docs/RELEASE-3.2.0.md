# MarkPilot 3.2.0

**图片能摆位置、能调大小；菜单和面板的手感也一起顺了。**

**图片：对齐与大小**

- 右键图片多了一整组操作：**复制图片**、**另存为图片…**、**抽出到 assets**、**删除图片**；
- **对齐**：左对齐 / 居中 / 右对齐——居中的图会稳稳落在版心中间，右对齐贴住右缘；
- **大小**：50% / 100% / 150% / 200%，也可以选「自定义…」输入 5～400 的任意百分比；
- 缩放以这张图**当前在屏幕上的宽度**为参考，所以"先放大到 150% 再放大 150%"得到的是 225%，符合直觉；
- 输入超出范围、或图片还没加载出来时，会明确告诉你原因，**不会**悄悄改坏文档；
- 对齐与大小都写进文档本身（HTML `<img>` 的 `data-typora-align` / `width`），换机器、换编辑器打开都保留；
- 每次操作只算一步，`Ctrl+Z` 一下就能退回。

**右键菜单**

- **正文右键**补齐：剪切 / 复制 / 粘贴 / 全选，段落（标题、引用、三种列表），格式（加粗、斜体、删除线、行内代码、链接），插入（表格、代码块、分割线、图片）；
- **表格右键**的「复制表格（可粘 Excel）」现在真的会把**带表头与单元格的真表格**放进剪贴板（以前可能什么都没写，粘出来是你上一次复制的东西）；
- 菜单会**跟着情境收起来**：点文档任意处、切换文件、滚动页面、窗口失焦、按 `Esc` 都会关掉；
- 右键菜单不再带关闭按钮（它的关闭方式是"选一项 / 点外面 / 滚动 / Esc"），也不会出现"看着能点却没反应"的项。

**导出与文件**

- 导出 PDF / HTML / 文件夹完成后，提示条上有「**打开所在文件夹**」——点一下打开资源管理器并选中刚导出的文件；
- 「设置 → 启动 → **打开上次的文件**」：打开应用就接着上次的文档；上次那个文件若已被移走，会自动往后找最近一个仍在的；关掉即回到每次开空白页；
- 页面内按 `Ctrl+S` 现在是**真的立刻落盘**（以前要等自动保存）。

**文件多开：一次看两份文档**

- 从系统里再打开一个 Markdown 文件（双击另一个 .md、或在命令行再启动一次）会**新开一个窗口**，
  原来那个窗口继续留着你正在写的那份——不再把当前窗口的文件换掉；
- 两个窗口各自独立：各自的标题、未保存标记、自动保存、外部改动提示互不影响；
- 关掉其中一个不会影响另一个；关窗后其文档状态会被正确回收。
**面板、主题与阅读**

- 所有弹出面板的关闭键**钉在右上角**，面板再长也不会滚走（大纲除外）；
- **Typora 社区主题可直接安装**：设置 →「Typora 主题」→ 安装 .css，正文与界面配色一起换，重启仍在；
- 主题配色新增**柔和淡绿**；菜单（含右键菜单）的**不透明度**可在设置里单独调；
- 阅读模式的文案简化为「已美化 / 未美化」与「退出 Esc」；**双开与阅读模式互不干扰**（只有正文进入阅读版式，右侧源码栏保持原样）；
- 含图大文档**滚动更顺**：图片预取改为滚动停稳后、在空闲时段、只处理视口附近的图。

**安装**

- 安装版：`markpilot-Setup-3.2.0.exe`；便携版：`markpilot-3.2.0-portable.exe`。

> 从 3.0.x / 3.1.x 升级：设置与最近文件自动沿用，无需重新配置。
