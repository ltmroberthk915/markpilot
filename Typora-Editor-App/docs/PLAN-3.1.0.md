## 4 验证纪律（本轮换来，继续执行）

1. **`src-cm6` 只有一个写者**，改动串行落；每落一批报文件哈希，别让下游拿到中间态。
2. **探针先自证可求值**：注入闭包必须过 parse / 顶层求值 / 自由变量三道闸——否则会出现"读数全丢却仍报退化"的假绿假红（本轮实测踩过）。

4. **交互类改动**必须五通道真实输入（键盘／鼠标／组合键／键鼠配合／拖拽）+ **真看图**（2 倍放大、光标与高亮一眼可辨）。

6. 大项必须带**指纹降级兜底**（A1 尤其）：增量路径与全量路径的输出要能逐字段+逐字符对账。

## 5 已拍板：N2 口径 = ③ 折中（表格选区按选区给口味）

**表格选区（覆盖整表）上按 Ctrl+C：**
- `text/plain` = **TSV**（Excel/Word 直接铺成真表格；`<br>` 还原真换行、`\|` 还原字面竖线）
- `text/html` = **`<table>`**（带列对齐，与 `copyTable()` 同源）
- **markdown 源码出口保留给"不含表格的选区"**；另设一条显式命令（如「复制为 Markdown 源码」）供需要源码的场合
- 不含表的普通选区：行为不变（仍给文档源码，D8 口径只在这一支继续生效）
- 含图选区：仍走 `imgCopyFill`，图片口味优先级不变

**性能约束（用户明确要求"尽量优化性能"）**
1. **严禁给每键路径新增任何成本**：TSV/HTML 只在 `copy` 事件里构造，不进 `StateField` / `update` / `ViewPlugin.update`。
2. 复制时**不得触发全文重扫**：一律复用既有字段（`lineStylesField.tables`、当前 selection）与 `tables.js` 判据；整表范围判断复用 `tableAt(pos)`（O(行数)，且只在 copy 时跑一次）。
3. 落地后在 8.13MB 夹具上证明**每键 p50 不变**（EXE 侧三枪中位数，地板 2%~6%）。

## 5.1 队列顺序（按"性能优先"重排）
