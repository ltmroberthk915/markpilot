# MarkPilot 2.2.5

这一版把公式编辑里三处"手感别扭"的地方修好了：光标在公式源码里的移动、看不见时的样子、以及点公式旁边正文时落空的那一下。

## 公式源码里的方向键更听话

- 在块公式（`$$…$$`）的源码里按 **←**，光标会**一个字符一个字符**地走到公式最前面（`|ad`），
  不再"绕过"第一个字符、跳到上一行的 `$$` 上。
- 行内公式（`$…$`）同理：走到源码两端时，光标停在源码上，而不是被围栏接走。

## 光标看得见、也画得准

- 段落里"浏览器画不出插入点"的位置（紧贴公式的左/右侧、整行只有一条公式的行），
  编辑器补的光标现在**与文字同高、贴在同一行**，不再是一根比字高一截、看着像把字切了一半的长竖线。
- 位置算不出来时**不画**：以前算错会在窗口左上角留下一根莫名的竖线，现在不会了。

## 点公式后面的正文，光标落在你点的地方

- 修掉一个偶发但很别扭的现象：点开一条行内公式后，再点它**后面**的字，光标进不去、
  公式还一直保持展开、浮出的预览框一直压着下一行。
  现在这两种情况都恢复正常——光标落在你点的那一处，公式随即收回成渲染结果。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.5.exe`；便携版 `markpilot-v2.2.5-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.5.vsix`，或直接在扩展市场更新。
