# MarkPilot CM6 3.0.2 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

这一版把表格编辑补齐了：点进格子就是**原地改字**，敲键盘不再被抢，右键菜单真的能用，粘贴也不会再把表撑坏。

---

## 这一版你能得到什么

**点进格子，就是原地改字**

- 光标直接落进格子，像在正文里一样打字；不再弹出浮起来的大白框，也不会把格子里的字重复显示一遍。
- 编辑带公式的格子时，不会再冒出压住下一行的预览卡片。
- 格子的字号、行高、内边距与表格里其它格完全对齐，看着就是"在表格里写"，而不是"在表格上盖了一层东西"。

**表格里打字，不再被"抢键"**

- 表格里按 `Ctrl+Enter`：在下方加一行（以前这一下会把表格劈成两半）。
- 单元格之间按 `Tab` 逐格前进，从第一行到最后一行都灵。
- 站到表格最后一行按 `↓`：直接走到表格外面继续写，不用绕路。
- 在格子里用中文输入法打字，中途按 `Tab` 或回车，不会再丢拼音、也不会把字串到隔壁格。

**右键菜单真的能用了**

- 在**任何一格**上右键都能出菜单（以前只有在表格边上一条缝的位置才出得来）。
- 菜单里的加行、加列、删行、删列、复制表格，作用的是**你点的那一格**，不会跑到光标以前待过的地方去。

**粘贴不再毁表**

- 往格子里粘一整段多行文字，不会再被硬塞进一格把表格撑坏——会给出提示，表格原样不动。
- 把 Excel 里的区域、网页上的表格、或另一份 markdown 表格粘进正文：直接变成一张 markdown 表格。
- 格子里要写竖线 `|` 时不必自己记得打反斜杠，会自动处理：这一行不会再多分出一格、最右列的内容也不会凭空不见。

**表格里的竖线，全链路一致**

- 格子里写 `\|`：屏幕上看到的是 `|`，导出的 HTML / PDF、复制出去的表格里也是 `|`；不会再出现"屏幕上是一个样、导出件里是另一个样"。
- 导出的表格按表头列数对齐：不会再出现多出来的空格子。

## 常用操作

| 操作 | 快捷键 |
|---|---|
| 新建 / 打开 / 保存 / 另存为 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 切换深色/浅色 | `Ctrl+Shift+L` |
| 放大 / 缩小 / 重置 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| 退出阅读模式 | `Esc` |
| 导出 PDF | `Ctrl+Shift+P` |
| 表格：下方插入行 | `Ctrl+Enter`（光标在表格里时） |
| 表格：上方插入行 | `Ctrl+Shift+Enter` |
| 表格：在本格内前进 / 后退 | `Tab` / `Shift+Tab`（或 `Ctrl+]` / `Ctrl+[`） |
| 表格：走出表格 | 最后一行按 `↓` |
| 表格：右侧插入列 / 删除本列 | `Ctrl+Alt+→` / `Ctrl+Alt+Delete` |
| 表格：删除本行 | `Ctrl+Shift+Backspace` |

把 `.md` 文件直接拖进窗口也能打开；双击 `.md` 文件可用本应用打开。

## 说明

- 本版是**独立桌面应用**，与 VS Code 扩展版各自独立演进，本次不更新扩展（VSIX）。
- 编辑内核为 CodeMirror 6 + KaTeX，应用内为纯本地渲染，不需要联网。
- 表格的整表选择、视口内拖选、对齐按钮与工具栏在后续版本推进。

## 本次更新

**表格编辑**

- 单元格原地编辑：点进格子直接改字，去掉浮层与重复显示。
- 表格内 `Ctrl+Enter` 在下方加行、`Tab` 逐格前进、最后一行 `↓` 出表。
- 表格里的中文输入不再被快捷键打断。

**右键菜单**

- 任意格子上都能弹出菜单，命令作用于被点的那一格。

**粘贴**

- 格内多行粘贴给出提示而不破坏表格；Excel / 网页 / markdown 表格粘进正文即成表。

**导出**

- 表格按表头列数对齐；表格里的竖线在屏幕与导出件中保持一致。
