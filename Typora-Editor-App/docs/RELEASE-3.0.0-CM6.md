# MarkPilot CM6 3.0.0 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

新的 CM6 引擎独立成桌面应用：公式、表格、标题、引用、代码围栏在写作面上直接渲染成最终样子，光标走到哪里，哪里就展开成源码——不切预览、不分左右栏。

---

## 这一版你能得到什么

**写作即成品**

- 标题、引用、列表、代码围栏、行内标记（`**加粗**`、`` `代码` ``、`~~删除~~`、链接）在正文里直接渲染，记号自动收起。
- 块公式独占一行居中显示；行内公式与正文同排。
- 表格按表格画，不再是一堆竖线。

**公式：点开就改，改完就渲染**

- 光标进公式 → 源码展开，同时浮出一块**毛玻璃预渲染预览**压在源码下方，边写边看结果。
- 点渲染后的公式任意位置，光标精确落到对应的那段 LaTeX（点分数线、点根号、点某个字母都行）。
- 公式框随滚动跟随，不会写一半跑位。

**复制出去就是 Markdown**

- 无论复制的是渲染后的公式、表格还是加粗文字，剪贴板里都是**标准 Markdown 源码**——粘到 Typora、Obsidian、GitHub 都能正常渲染。

**写给中文**

- 中文输入法全程安全：拼音预编辑不会打断排版，也不会有"打着打着公式跳走"。
- 公式里、表格里、正文里都能直接打中文。

**顺手的手感**

- 公式区上下移动：从下方上来落在公式内容末尾、再按一次直接出到上一行，**横向位置不丢**（穿过多长的公式都回到原来那一列）。
- 拖拽选中一大段：只有光标所在的那个公式展开，划过的公式保持渲染并带选中底色——不会满屏 LaTeX。
- 行中段直接打 `$$…$$`：打完收笔自动独占一行成块公式，一步 Ctrl+Z 可回退。

**文件安全**

- 输入停顿半秒自动保存，写盘走"临时文件 + 改名"，断电也不会留半截文件。
- 保留原文件的换行风格（CRLF/LF）与 BOM，不会因为改一个字就让整份文件二进制全变。
- 磁盘上的文件被别的程序改过会提示，可选择载入磁盘版本或保留自己的修改。

## 安装

| 下载 | 用途 |
|---|---|
| `markpilot-cm6-Setup-3.0.0.exe` | 安装版：装到本机，带开始菜单与快捷方式 |
| `markpilot-cm6-3.0.0-portable.exe` | 便携版：双击即用，不写注册表，可放 U 盘 |

## 常用操作

| 操作 | 快捷键 |
|---|---|
| 新建 / 打开 / 保存 / 另存为 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 切换深色/浅色 | `Ctrl+Shift+L` |
| 放大 / 缩小 / 重置 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| 打开最近文件 | 菜单「文件 → 最近打开」 |

把 `.md` 文件直接拖进窗口也能打开；双击 `.md` 文件可用本应用打开。

## 说明

- 本版是**独立桌面应用**，与之前的 VS Code 扩展版各自独立演进，本次不更新扩展（VSIX）。
- 编辑内核为 CodeMirror 6 + KaTeX，应用内为纯本地渲染，不需要联网。
- 表格编辑的进阶能力（单元格原地编辑、行列增删、整块复制到 Excel）在后续版本推进。

## 本次更新

**更安静的界面**

- 顶部工具栏改成**悬浮岛**：内容多宽就多宽、始终居中，不再是一条通栏长条；窗口变窄时自动换行，不会挤出横向滚动条。
- 点最右边的收起按钮，工具栏缩成**右上角一个小圆点**，正文一点不被挡；再点一下展开。收起与展开带过渡动画，收起状态会被记住。

**更统一的排版**

- 导出的 HTML 与 PDF 现在**与写作面同一套排版**：同样的衬线字体、同一套字号阶梯与行宽，中文斜体统一走楷体。
- 打印与导出 PDF 自动转为**白纸黑字**：暗色主题下不会再出现"浅灰字打在白纸上"。
- 中文斜体的楷体略微收小，与正文的视觉重量更齐。

**更清爽的主题**

- 两套默认配色更名为**宋韵 深色 / 宋韵 浅色**。
- 换主题更稳：点已经选中的那一项不会再跳到别的配色；菜单显示的"当前"与画面始终一致。

**导出 PDF**：文件 → 导出为 PDF…（Ctrl+Shift+P）。
