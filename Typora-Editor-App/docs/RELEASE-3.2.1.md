# MarkPilot 3.2.1

这一版把"每天都会碰到的小动作"逐个捋顺了：打开文件更安全、开始打字更顺手、列表与代码块更听话、跳转不会再"跳了但看不见"。

## 打开文件更安全

- 拖进来或打开的如果是**图片、压缩包、可执行文件**这类非文本文件，会明确提示并**拒绝打开**，不会再把它当成一篇文档；
- 因此也不会出现"图片被当成文字打开、随手一按保存就把图片写坏"的情况 —— 你的原文件一个字节都不会被改动。

## 一打开就能写

- 带着文件启动后，光标**已经在正文里**：不用先点一下编辑区，直接敲字、按回车、按 Ctrl+End 都生效；
- 关窗快捷键 **Ctrl+W** 可用了；带未保存修改时照常弹出「保存并退出 / 不保存 / 取消」；
- 选「保存并退出」会**真的保存并退出**，不再出现"文件存好了、窗口还杵在那儿"。

## 列表与清单

- 空的列表项按回车**退出列表**（任务清单的空项也一样），不会再续出一个空项目；
- 勾选过的清单项在文档改动之后继续点击也**不会写坏正文** —— 复选框会跟着它的位置走。

## 代码块

- 代码块里按 **Tab** 缩进（Shift+Tab 反缩进），焦点不再被甩到工具栏按钮上；
- 点工具栏「代码块」按钮后，光标就落在围栏里那一行空行上，**接着就能敲代码**，不会再落到块外。

## 跳转与位置

- 点大纲里的标题会**滚到那一条**（包括第一条），光标与视图一起走，不再出现"光标跳了、视图没动"；
- 按 **Ctrl+Home / Ctrl+End** 到文首文末时，首行与光标都不会被顶部工具栏或底部状态栏压住。

## 查找替换

- 打开查找面板后焦点就在**查找框**里，接着输入只会进搜索框，不会误落进正文。

## 安装

- **便携版**：`markpilot-3.2.1-portable.exe`，双击即用，不改系统；
- **安装版**：`markpilot-Setup-3.2.1.exe`，安装后可从开始菜单启动、并把 Markdown 文件的默认打开方式指向 MarkPilot。

## 说明

- 运行环境：Windows 10 / 11（64 位）；
- 设置与最近打开记录与 3.2.0 兼容，升级后无需重新配置。
