# MarkPilot 2.2.13

这一版把"方向键走到公式那一行就出不去了"和"按住方向键走不动"这两类手感问题一起收掉了。

## 独占一行公式的行尾，方向键能过去了

一行里只放一条公式（比如 `$x_{独占一行}+1$`）时，光标走到这一行行尾再按 →，以前会**跳回本行开头**，
整行出不去，只能靠鼠标点走。现在按一次 → 就把光标带到下一行行首。

- 从下一行行首按 ← 回这一行，也是同样：落到这条公式的末尾，不再停在两行之间的空档里（那种位置光标是看不见的）。
- 走进行尾这条公式、再按 → 走出来，一路上光标都看得见，不会中途消失。

## 按住方向键，光标跟着窗口走

长文档里按住 ↓（或 ↑）时，光标走到窗口最后一行会**停住不动**——手一直按着，界面却没有反应。
现在光标到边缘会自动带着正文滚动一行，一路走到底；往回走同样会带着滚动，
**目标列（左右的落点）全程保持**，来回走一趟还能回到出发时的位置。

## 顶部的正文不再被工具栏压住

窗口顶部的工具栏是浮在正文之上的。正文滚到最上面时，最前面几行会钻到工具栏底下：
那一带的文字既看不见、也算不出光标位置，竖着移动时左右落点会被莫名拽到行首。现在这一带按"不可见"处理，
移动会把光标带到工具栏下方，落点照旧按目标列算。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.13.exe`；便携版 `markpilot-v2.2.13-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.13.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.12 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。
