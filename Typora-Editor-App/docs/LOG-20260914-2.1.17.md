# 2.1.17 工作日志（2026-09-14）：公式命令补全的"同类补全"

用户第 8 轮：公式模板补全"最多只显示前两个"、`\mathbb` 不再带出 `\mathscr`/`\mathbf` 之类的同族命令，
要求"加回来"，并希望**候选个数能智能判断**；同时问"以上所有功能之前是否依赖过 AI API"。

## 一 先回答 AI 的问题（有代码证据）

**公式模板补全从来是离线的**：

- `render/js/completion-sources.js` 的 `localCandidates()`：静态命令表 + 本地匹配，无网络调用；
- `render/js/completion.js` 的 `request()`：`if (!aiOnly && config.local) { items=[...localCandidates(), ...anchoredCandidates()]; showItems(); }`
  —— 面板在任何宿主/AI 往返之前画好；
- `render/js/completion-policy.mjs` 首行注释：*"No model call is used to decide whether to request a
  completion or to classify the editing context."*；
- `#` 标题候选读本地大纲 DOM。

唯一联网的是**可选的 AI 续写**（ghost text）：门槛 `config.apiAvailable && config.ai && config.automaticAI`，
`config.ai` 要用户自填 API Key；公开/无 API 版 `API_ENABLED=false` 时整段路径不存在
（`build-flavor.mjs` 由公开打包覆盖）。VSIX 宿主另有 `vscode.executeCompletionItemProvider`（问 IDE 自己的
提供者，用于路径/符号），公式上下文里只在**手动**触发时使用；宿主代码本身不发网络请求。

## 二 复现"固定且少"

`scripts/acceptance/probe-cands.cjs`（真产物；把光标放进行内公式源码，逐个前缀量面板里的按钮数）：

| 前缀 | 修前 | 修后 |
| --- | --- | --- |
| `\` | 12 | 12（顺序不变） |
| `\m` | 5 | 12（前缀命中 12 条：`\mu`/`\mathbb`/…） |
| `\math` | 4 | 11 |
| `\mathbb` | **1** | **12** |
| `\mathb` | 2 | 12 |
| `\frac` | **1** | 5 |
| `\su` | 1 | 7 |
| `\alp` | **1** | 12 |

根因：`localCandidates` 只做 `key.toLowerCase().startsWith(query) || title.includes(query)`，
键入接近完整的命令时只剩它自己一条；同族命令**没有任何机会**出现。

## 三 修法（`render/js/completion-sources.js`）

1. 命令表加**分组**字段：`[键, 说明, 插入文本, 分组]`；分组共 13 个（字体 / 大运算符 / 希腊字母 /
   关系符 / 箭头 / 括号与省略号 / 重音与上下括号 / 间距 / 分式与根式 / 矩阵与环境 / 集合与逻辑 /
   函数名 / 微积分符号），条目 42 → 215。
2. `MAX_ITEMS = 12`、`FAMILY_BELOW = 4`：前缀命中不足 4 条时补同族（补到 12），足够多时一条不补。
3. **表序 = 常用度优先**：前 12 条与旧版逐条一致（`frac, sqrt, sum, int, lim, partial, nabla, infty,
   alpha, beta, gamma, delta`）。排序函数只用 score，其余保持声明顺序（JS sort 稳定）——
   中途我加过"按长度/字典序"的次级比较，结果只敲一个 `\` 时最常用的几条被挤下去了（`\ `、`\,`、`\gg` 跑到前面），
   已改回只按 score。
4. 同类条目的说明后缀 `· 同一类（分组名）`，让用户看得见"为什么它在这儿"。

**已知偶发（记录在案，非本版引入）**：`test:math-caret` 的受保护素材用例
「点公式正中 + 按一次退格」偶尔会把 `\Leftrightarrow` 的反斜杠删掉（同行中部变短 → 判据判为 other）。
机制是 2.1.13 就有的"命令字形 → 光标落在反斜杠之后"（用户 ② 明确要这个语义：点 ∑ 落在 `\` 与 `s` 之间），
点落在命令字形上时退格自然删掉那个反斜杠；该用例只容忍"零改动"或"行尾变短"。
当天实测：4 次里 1 次红、3 次全绿（落点随版面浮动）。
