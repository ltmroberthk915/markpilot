# MarkPilot CM6 3.0.7 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

## 这一版你能得到什么

**引用区里的内容终于"长得对"了**

- 引用区里的**列表显示成圆点**（此前只有行首的列表才画圆点，引用区里是源码模样）。
- 引用区里的**围栏代码块成为真正的代码块**（底色与等宽字体），且代码块里的 `**加粗**` 之类**保持字面**、不会被误当格式。
- **尖括号自动链接** `<https://…>`、`<mailto:…>` 渲染成链接（尖括号隐去）；而 `<不是链接>` 与行内代码里的地址**保持字面**。
- **HTML 注释**在阅读时隐藏（单行与跨行都隐藏，两侧文字不受影响）；把光标放到那一行即可看到源码去修改。
