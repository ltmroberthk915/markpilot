# MarkPilot 2.2.14

这一版收掉公式附近两处"光标看着别扭"的地方：公式后面多出来的一根光标，以及点公式右边缘之外光标跑进公式里。

## 公式后面只留一根光标

段落末尾是行内公式（比如 `循环往返问题：对侧相向出发：$S=L(2n-1)$`）时，公式右边会出现**两条竖线**：
一条细而高，一条偏粗——偏粗的那条是编辑器自己补画的，属于多余。现在只保留细而高的那一条，
光标位置、打字落点完全不变，看起来干净了。

## 点公式右边缘之外，光标就落在公式外面

在公式右边缘靠外一点点（包括右 `$` 之后那一小条）点一下，以前光标会被塞进公式源码里，
公式正展开编辑时尤其明显——你明明点的是公式**外面**，编辑的却是公式。现在这类点击一律落在
公式**外面**第一个正常文本位置；左边缘之外同理，落在公式前面。

- 点公式本身（渲染出来的字形、两边的围栏）习惯不变：源码展开，光标落在你点的那一格。
- 公式前后有正文时，点正文照旧落在正文上。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.14.exe`；便携版 `markpilot-v2.2.14-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.14.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.13 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。
