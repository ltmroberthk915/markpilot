# MarkPilot 3.1.2

**写表格、贴表格、把表格交给 Excel——这一版把表格这条路修顺了。**顺带把主题和阅读体验也补了一截。

**表格：复制到 Excel / Word 真的是表格了**

- 表格右上角的浮动按钮变**小**了（高度减半），并且**落在表头上方**，不再压住表头文字；
- 浮动条的**不透明度可以调**（设置 → 界面透明度 → 表格浮动条）；
- 两处复制菜单——「复制表格（可粘 Excel）」与「复制为 Markdown 源码」——修好了一处会让它们**什么都不写**的问题：
  以前点完再粘贴，出来的是你剪贴板上一次留下的内容（如果那正好是一张截图，粘进 Excel 就会是一张图片）；
  现在点「复制表格（可粘 Excel）」粘进 Excel/Word 是**带表头与单元格的真表格**，数字仍是数字、可以直接算；
  「复制为 Markdown 源码」给出的是表格的 Markdown 源码。
- 复制出去的表格 HTML 带上了编码声明，中文列名在 Excel 里不再变乱码。

**主题：可以直接用 Typora 的社区主题**

- 设置 →「Typora 主题」→ 安装 .css：正文与界面配色一起换，重启仍在；主题的标题、引用、代码块样式一并生效。
- 主题自带的字体与图片文件不会跟着走（纯 CSS 导入，相对引用会被忽略，避免整页报错）；
- 主题只负责**外观**（颜色/底色/字体/圆角/边框），版面（行距、缩进、页宽）仍由编辑器掌握——
  这样任何主题进来都不会把正文版式弄坏。
- 主题配色里新增**柔和淡绿**（低饱和绿底，长时间阅读不刺眼）。

**阅读与窗口**

- 阅读模式的按钮文案简化为「已美化 / 未美化」与「退出 Esc」，细节放进悬停提示；
- **双开与阅读模式互不干扰**：开双开后再进阅读，只有左侧正文进入阅读版式，右侧源码栏保持原样；
- 含图大文档的**滚动更顺**：图片预取改为滚动停稳后、在空闲时段、只处理视口附近的图。

**面板与导出**

- 所有弹出面板的关闭键都**钉在右上角**（面板再长也不会滚走），大纲除外；
- 导出 PDF / HTML / 文件夹完成后，提示条上多了一个「**打开所在文件夹**」链接：点一下直接打开资源管理器并选中刚导出的文件。

**安装**

- 安装版：`markpilot-Setup-3.1.2.exe`；便携版：`markpilot-3.1.2-portable.exe`。

> 从 3.0.x / 3.1.x 升级：设置与最近文件自动沿用，无需重新配置。
