# MarkPilot 2.1.27

**大文档里撤销，不再把滚动条搞乱。**

## 撤销之后，版面高度回到正确值

超长文档会跳过离屏内容的渲染来保持流畅，跳过的部分按上一次渲染时记录的高度占位。此前在公式较多的大文档里按撤销，这些高度会随旧内容一起被换掉，跳过的部分退回一个默认值——**文档总高被抬到真实值的 8 倍**，滚动条比例与「上次读到哪里」跟着一起漂，而且不会自己恢复。

现在这种情况会被当场发现并补回，几乎察觉不到。正常打字时被重建的那一段也会顺手补齐——它此前会悄悄退回默认占位。

## 装上就能感到的差别

- 长文档里连按几次 Ctrl+Z，滚动条比例依旧可信，「上次读到哪里」不会跑偏。
- 长文档里一直打字，滚动条不会越用越飘。

## 安装

- **VS Code / Trae 插件**：`markpilot-2.1.27.vsix` —— 扩展面板 → 右上 ⋯ → 从 VSIX 安装…
- **校验**：`SHA256SUMS.txt`

## 修复

- 长文档撤销后滚动条比例与总高度失真，且不会自己恢复。
- 长文档打字时被重建的那一段会丢占位高度，滚动条随之轻微失真，现在会随即补齐。
