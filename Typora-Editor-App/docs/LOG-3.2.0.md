## 二、被推翻的判断（按错-3 第 4 条保留）

- **多窗口"缺陷①：新窗口读到主会话文档"** —— 2026-10-10 一度判定为真缺陷并连查三轮；
  壳层 trace 显示 `doc:push:openPath {to:2, path:"A.md"}`，即**推给窗口 2 的本就是 A.md**：
  探针 `p.evaluate((p) => mpHost.openInNewWindow(p))` **漏传了第二个参数** ⇒ 应用回退到"当前文件"（正确行为）。
  **结论作废**，改判为探针假象；补参后读数立即为 `["A.md","B.md"]`。
- **"关一个窗口另一个也消失"** —— 一半是探针（`page.close()` 拆掉 CDP 会话 ⇒ 后续 evaluate 全超时）；
  另一半是**真缺陷**（关窗后全局 `win` 仍指向已销毁窗口、会话未注销）⇒ 已修，判据转绿。

### 结案为"非产品缺陷"（保留过程）

- **脏文档拖入同一文件、确认框点「取消」**：普查一度判"内容仍被写入"。复查其自身读数：期望 `docLen=28`、实际也是 `28`，唯一"差异"来自它拿**拖放前的磁盘 sha** 作期望，而它自己在拖放前键入的字符被正常保存 ⇒ **探针记账错误**。另跑两臂实验（工具栏 / 正文落点 + 取消）：文档与磁盘**零变化**。

### 突变验证（"把修复注掉必须变红"，6 条关键修复已完成）

> 口径：绿灯可能来自"修复真的生效"，也可能来自"探针测不出问题"。逐条把修复注掉再复跑，
> 能把这两者分开；每条都验了红→绿两态。

| 修复 | 突变手法 | 突变态读数（应红） | 还原后（应绿） |
|---|---|---|---|
| 二进制嗅探（PNG 被当文本打开） | `if (isBinary)` → `if (false && isBinary)` | 拒绝打开=false、错误说明=false、原文档仍在=false、文档尾出现二进制乱码（`"D\ufffdB`\ufffdQ"`）、壳层无留痕 ⇒ 7 条判据 **4 条转红** | 7/7 全绿 |
| 复选框 `eq()` 补位置 | 注掉 `from/to` 比较 | 定点探针 R1 ⇒ `DIFF-源码被改坏` | R1 ⇒ `OK-仅翻转` |
| 关窗「保存并退出」 | 注掉 `W.__pendingClose = true` | 「保存成功但**没退出：窗口仍然开着**」 | 「退出了（主窗 HWND 消失）」 |
| 浮层大纲跳转滚动 | 禁用"下一帧重施滚动" | `✗ O3`（`visible:false`、`coordsTop:-30144`）+ `✗ O9`（`-30151.1`、首可见行 1194）；**`✓ O11` 停靠态仍正常** | `✓ O3` `✓ O9` |
| 代码块按钮光标落点（`blank+1`） | 让光标回到插入串末尾 | `off CF-7` / `off CF-7b`（与普查原始现象一致） | `ok` / `ok` |
| 列表键位优先级（`Prec.highest`） | 降回 `Prec.high` | `T10` after=`- 甲⏎⏎- [ `、`T11` after=`- 甲⏎⏎-`（与普查逐字一致） | 三条全部 `- 甲⏎` |

**附带结论**：第 4 条突变时"停靠态仍正常"与普查当初观察到的**不对称完全一致**，等于独立印证了根因
（浮层挑中条目会关面板、关闭把滚动吃掉；停靠态没有这个收尾动作）。

**无鉴别力的用例（记录下来，别当证据）**：列表空项回车的 `T12`（光标在行首）**两态都通过** —— 那个场景第三方
处理分支恰好也会退出列表；真正有鉴别力的是 `T10`/`T11`。

**一次"突变没打上"的插曲（按错-12 第 4 条处理）**：二进制嗅探那一条第一次突变时，开关脚本的锚点未命中、
`on` 实际没生效，但同一条命令里的探针**没输出**（过滤条件没匹配上），一度无法判断。处置：**先确认产品已还原**
（源码里 `if (isBinary) {` 在位）并复跑 7/7 绿，再把该条**记为"突变未验证"**；随后修正开关、重做突变，
才拿到"4 条判据转红"的读数。

**尚未补齐**：拖放捕获阶段拦截那一条。它没有可观测判据（该改动的目标是"阻止 CM6 看到文件拖放"这一**假想**风险，
