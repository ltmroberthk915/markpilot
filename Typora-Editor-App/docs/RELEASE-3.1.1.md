# MarkPilot 3.1.1

**一个窗口、打开即写、所见即所得。**这一版把「写中文长文」这条路又修顺了一截：公式怎么摆、图放哪里、导出的 PDF 长什么样，都更贴近你想要的纸面。

**写公式更省事**

- 块公式现在**四种写法都认**：`$$` 单独一行、上下用空行把公式夹起来、引用区里的 `> $$`、以及一行写完的 `$$公式$$`。
  以前引用区里那种写法会整段当普通文字露出来，现在都能正常渲染成居中的公式。

**图片落到哪里，你自己定**

- 插入或粘贴的图片默认**落盘到文档旁边的 `assets/` 目录**并写相对路径：换台电脑、传给别人、传到 GitHub 都能正常显示。
- 想让图片跟着文件走（换目录也不丢图），在设置里切回内联即可；已经内联进文档的图，用「更多 → 抽出到 assets」一次性落盘。

**导出的 PDF 用整段最优断行**

- 导出 PDF 时中文段落不是逐行塞满，而是像 TeX 那样**整段一起算**：愿意为后文牺牲前文，让每一行的疏密更均匀，并照顾中文禁则（标点不落行首、开引号不落行尾）。
- 文档很大（源文超过 30 万字符）时自动改用标准两端对齐，并明确提示一句——不做半页精排、半页粗排的混合版式。

**阅读模式下可以换一种排版方式：排版美化**

- 阅读模式右上角多了一个「排版美化」按钮（和退出胶囊同一簇，不挡正文）：一键在「浏览器两端对齐」与「Knuth–Plass 整段最优断行」之间切换，也可以按 `Ctrl+Alt+K`，或在设置里选。
- 断行跟着你的字体、字号设置走；自定义 CSS 改过字号后重算。

**几处看得见的手感修正**

- 在引用区里选中文字，**高亮底色看得见了**（以前被引用底色盖住）。
- 所有弹出面板右上角都常驻一个 **✕**，随手就能关掉，不用再点空白处。
- `Ctrl+滚轮`缩放**每档 5%**，细调够得着（快捷键与状态栏同步）。
- 换文档时**不会再清空正文**：以前在 A 文档里选了文字再打开 B，敲第一个字会把 B 整篇替换掉并保存——这一版连根修掉，自动保存也加了「体积骤降」拦截。

**安装**

- 安装版：`markpilot-Setup-3.1.1.exe`（可选安装目录、开始菜单与桌面快捷方式）；
- 便携版：`markpilot-3.1.1-portable.exe`（免安装，双击即用）。

> 从 3.0.x / 3.1.0 升级：设置与最近文件会自动迁移，无需重新配置。
