# MarkPilot 2.2.9

这一版修好两处与光标有关的问题：点公式附近的空白"冒出第二根光标"，以及按 **→ / ←** 时
偶尔会整行跳过中间的标题。

## 空白区点击：不再出现第二根光标

- 在公式下方或右侧的空白带点一下、或先回车再点那一行的外侧时，正文里会多出一根竖线
  （编辑器的合成光标画错了位置，而且 DOM 重排后没有收回）。现在：

  - 合成光标一律按**光标所在那一行的行盒**定位，不再用跨行元素的整体矩形；
  - 编辑区一有重排就立即重算，原生光标能画出来时马上收掉自己的那根；
  - 光标落在隐藏的公式源码里、或位置算不出来时，**宁可不画**，也不会在别处冒出一根线。

## → / ←：不再跳过中间的标题

- 在段落末尾按 **→**，光标只会走到**下一行**（标题行的行首也算），不会被整行跳过；
  反向按 **←** 同理。这次修的是编辑器自己的按键事后校正：它原先会把"落在标题标记 `###` 里"
  也当成坏位置去纠，而纠偏的兜底会往下跳行。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.9.exe`；便携版 `markpilot-v2.2.9-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.9.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.8 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。
