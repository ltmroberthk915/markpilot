# MarkPilot 2.3.0

稳定性大版本。历经十轮系统性清剿，共落地 133 项修复，覆盖导出、保存、剪贴板、查找、
公式、表格、图片、光标键盘与主题可读性——每一项修复都经过「复现 → 修复 → 验证 → 回归」
的完整闭环，全量回归连续三轮零失败。

## 大文件导出不再卡死

几百 KB 的长文档（上万行、上千行表格、几十张图）导出 PDF，以前会把内存吃到 2.6GB、
整机卡住几十秒；现在同样的文档约 15 秒完成，内存只有原来的三分之一。超出精细排版
预算的超大文档自动切换兼容模式并明确提示。导出过程中**可以随时取消**，取消后马上能
再次导出；对话框实时显示已用时间。

## 刚打完字就保存、关窗，一个字都不丢

打字后立刻按 Ctrl+S，刚才那几个字也能落盘。打完字马上关窗口、退出程序或切换文档时，
「未保存的修改」确认框一定弹出来——以前存在一小段时间窗口，新打的字会**悄悄消失**。
没动过的文档保存后与原文件一字不差。

## 从 Word、Excel、Outlook 粘贴更放心

- **Word**：带图片的内容粘过来，图片自动归档进文档——删掉源临时文件，图还在。
- **Excel**：多个格子的内容按矩形原位落进表格并自动扩表，制表符不会被塞进格子，
  粘贴范围外的数据也不会丢。
- **Outlook**：邮件内嵌图片不再留下永远打不开的死链引用，会提示先把图片另存再插入。
- 新增 **Ctrl+Shift+V** 粘贴为纯文本；光标折叠时按 Ctrl+Alt+V 不再误清空剪贴板。

## 查找替换更安全

在查找面板打字时，焦点牢牢留在输入框里——以前焦点会被拽进正文，按回车会**误删命中的
文字**。公式内的替换、定位到当前命中处、F3 展开保持、输入法组字期间的守卫等一整族
问题一并修好。

## 光标与键盘全面对齐 Typora 习惯

纵向移动逐行且保住目标列；视口底缘不再有按键死角；PageUp/PageDown 按页移动；
Shift+End/Home 能选整行（标题行不再塌缩）；列表项里按 Tab 缩进成子项；中文整段裹词；
F11 全屏；词跳把整条公式当作一个词；Ctrl+Backspace 贴着公式一次删整条；点公式右缘
光标落在公式外。

## 长文档更流畅

后台换算按块分组提速，单处小改毫秒级落定，撤销不再跳步，大文档打开提速约四成。

## 主题可读性

konayuki 深浅两套主题的代码块高亮对比度达到无障碍 AA 标准，注释不再发灰看不清。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.3.0.exe`；便携版 `markpilot-v2.3.0-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.3.0.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.16 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。

## Bug 修复

本版共落地 133 项修复，以下列出其中用户最容易遇到的问题；完整清单见仓库 CHANGELOG。

- **大文件导出 PDF 把电脑卡死**：几百 KB 的长文档（上万行、上千行表格）导出时内存被吃到 2.6GB、整机卡住几十秒甚至假死。现在同样的文档约 15 秒完成、内存约为原来的三分之一；超大的文档自动切换兼容模式并提示。
- **导出中途不能取消、取消后再也导不出**：点「取消」后界面卡在忙碌状态，之后再点导出没有任何反应。现在取消立即生效，并且马上可以再次导出。
- **导出时没有任何进度提示**：对话框只有静态文字，长文档导出像死机一样。现在会显示「正在打印 PDF…」和已用秒数。
- **刚打完字就按 Ctrl+S，那几个字没存上**：打字后不到半秒内保存，新敲的字会漏掉。现在无论多快跟上，都能落盘。
- **刚打完字就关窗口 / 退出 / 切换文档，新字悄悄丢失**：以前有一小段时间「未保存的修改」确认框不会弹，改动直接丢。现在确认框一定弹出。
- **没编辑过的文档手动保存会被改写**：表格列宽等排版会被顺手重排。现在没动过的文件保存后与原文件一字不差。
- **在查找面板打字后按回车，正文里的命中文字被删掉了**：焦点被悄悄拽进正文，回车变成了删除。现在焦点始终留在查找输入框里。
- **从 Word 粘贴图片，过段时间图就裂了**：图片留在系统临时目录里，清理后全断。现在粘贴时自动归档进文档，删掉源文件图还在。
- **从 Excel 粘贴多个格子的内容会乱**：制表符被当作文字塞进格子、粘贴范围外的数据丢失、表格行错乱。现在按矩形原位落进表格并自动扩表。
- **从 Outlook 粘贴带图内容，留下打不开的死链**：现在改为保留文字、剥离无效图片引用，并提示先另存图片再插入。
- **光标折叠时按 Ctrl+Alt+V 会清空剪贴板**：现在没有选中文本时不再动剪贴板。
- **标题行里按 Shift+End 选不上整行**：选区会当场塌掉。现在能正确选到行尾，Shift+Home 同理收回行首。
- **列表项文字中间按 Tab 没反应**：现在整项缩进成上一项的子项，Shift+Tab 退回。
- **光标在中文里按行内代码键，只裹住一个字**：现在与 Typora 一致，整段连续中文一起裹住。
- **纵向移动光标时目标列丢失、视口底缘有一段按键死角**：现在逐行移动且保住目标列，底缘不再丢键。
- **Ctrl+Backspace 贴着公式会拆散公式围栏**：现在一次删掉整条公式。
- **konayuki 主题代码块注释发灰看不清**：对比度从 2.3:1 提升到 5.2:1 以上，深浅两套主题都达到无障碍 AA 标准。
- **F11 没有反应**：现在按 F11 即可全屏 / 退出全屏。
