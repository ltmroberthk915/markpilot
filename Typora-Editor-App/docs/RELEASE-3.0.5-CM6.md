# MarkPilot CM6 3.0.5 — 引用区表格更好读，工具栏更顺手

这一版修好了引用区表格的两处显示问题，并把工具栏上几个不常用、又容易看错的按钮收进了「更多」菜单。

## 引用区表格：列宽不再挤，公式正常显示

- **中文列不再被压成一字一行**。表格按"看得见的宽度"分配列宽：公式、`$…$` 这类源码很长的格子不会再抢占中文列的空间；每列还有下限，窗口拖窄也不会把「名称」竖排成两行。
- **`| —— |` 这种手写分隔行也能认出表格**（原先只认 `-`，用破折号写的表会整段显示成源码）。
- **格子里带文字的公式**（如 `KB: $\partial_t w$`）与纯公式格子一样正常渲染。

## 工具栏：常用的留着，不常用的收进「更多」

- 「**更多**」按钮挪到工具栏**最右端**（折叠按钮左侧），找菜单不用再往左看。
- 「**界面透明度**」与「**阅读模式（含配色）**」不再各占一个按钮，收进「更多」菜单里**直接可调**：
  - 不透明度：滑杆拖动即时生效，右侧数字口可键入百分比、**回车生效**（Esc 还原），显示当前值；
  - 阅读模式：三档配色（跟随主题 / 米色纸张 / 柔和淡绿）一眼可见、当前档有标记，进入/退出就在同一处；**在阅读模式里也能打开菜单换配色**。

## 图标更好认

- 「**双开**」＝左右两栏（方正面板 + 中缝）；「**阅读模式**」＝一本**打开的书**——两者在缩小到工具栏尺寸时轮廓也完全不同，不再混淆。
- 「**明暗切换**」改成**太阳 / 月亮**并跟随当前状态：深色时显示太阳（点它变亮），浅色时显示月亮（点它变暗）；它紧跟在「主题」按钮右侧。
- 新图标与工具栏其余图标同尺寸、同线宽，深浅主题下都清晰；鼠标悬停会写明"当前：深色/浅色"。

## 引用块与正文对齐

引用行的左侧竖条现在与正文、表格落在**同一条竖轴**上：引用区不会再比正文凸出去一截，整段选中时高亮也不再多出一块。

## 安装

| 文件 | 说明 |
|---|---|
| `markpilot-cm6-3.0.5-portable.exe` | 免安装，双击即用 |
| `markpilot-cm6-Setup-3.0.5.exe` | 安装版，可选安装目录、建快捷方式 |

两个包出自同一次构建，功能完全一致。

## 小贴士

- 页面宽度、内容缩放、工具岛尺寸仍在「更多 → 设置 → 版式」里；
- 界面不透明度与阅读配色现在一步可达：点工具栏最右的「⋯」；
- 阅读模式里按 `Esc` 或点右上角胶囊即可退出。
