# CM6 引擎交互决策台账

本文件是 MarkPilot **CM6 引擎**（`dsh-markpilot/src-cm6/`）交互语义的**内部决策台账**。每条写四件事：口径 / 依据 / 验证 / 与 Typora 的关系。

**择一优先级**（冲突时按此顺序）：① 人直觉（可预测、不跳、不抖） → ② 既有契约（纵向逐行、连续移动保列、光标不消失、文字保真） → ③ 能效（按键数、重排次数、新增状态与分支数）。

---

## D1 空行即真实行【锁定】

- **口径**：文档里的空行在编辑面是**真实行**——可停靠（↑/↓ 会在它上面停）、可删（Backspace/Delete）、可插入。
- **依据**：Typora 把段落之间的空行交给渲染层吃掉（不占停靠点，光标直接跨过）。把空行当真实行是它的**超集**：版式效果一致，同时多出「删空行 / 加空行」这类结构编辑能力。
- **验证**（`.mp-verify/verify-blank-real.cjs`，真机真实键盘）：
  - 块与正文之间的空行可停靠：光标在下一段行首按 ↑ → 落在空行，`lineNo 9→8, col 0`；
  - 可删：下一段行首 Backspace → 空行被删（`$$\n段落乙。`），**块公式仍正常渲染**（`blocks=1`）；
  - Ctrl+Z 一步还原（文档逐字节回到原状）。
- **与 Typora 的关系**：Typora 行为是本方案的**子集**，不构成分歧；不追平它的"空行不占位"，因为那会丢掉上面两项编辑能力。

## D2 块公式纵向穿块 = W′【锁定】

- **口径**：块公式视作「**内容行 + 两侧装饰围栏**」。
  - 进块（视觉相邻，↑ 从下方来 / ↓ 从上方来）→ 落**内容近端**（内容末 / 内容首），光标进 span ⇒ 源码展开；
  - 出块 → 内容首行再 ↑（末行再 ↓）**越过围栏**，直接到块外相邻行；
  - **围栏行（`$$`）不作纵向停靠点**；内容多行时，内部**逐行走**由原生纵向移动负责；
  - **列取"经过前"的值**（模块级 `mathPass={spanFrom,col}`）：穿过块不吃横向位置。
- **依据**：块级 widget 是 replace 装饰，CM6 原生纵向落点在 widget 区域只映射到边界 ⇒ 不补这一拍会**整块跳过**。落点选"内容"而非"围栏"，因为围栏无内容可编辑。
- **验证**（`.mp-verify/verify-wps.cjs`，实测）：
  - 单行内容块：↑×1 → `a+b=c` col 5（内容末）；↑×2 → 块上正文 **col 3（恢复）**；↓×1 → 内容首 col 0；↓×2 → 块下正文 col 2（恢复）；
  - 3 行内容块：内容内部逐行（末行→`y&=2`→`x&=1\\`→首行），只在内容首/末行出块；
  - 全程补全菜单零弹出；0 pageerror。
- **与 Typora 的关系**：落点与跳数一致（Typora 第一跳落 `E=mc^2|`、第二跳出块）；**刻意保留的差异**：Typora 出块后列归零，我们保列（依据契约②）。

### D2 附则：目标列纪律【2026-10-07 修】

- **口径**：目标列只在**新一轮**纵向移动开始时采集一次；只要光标仍停在上一落点、**或**仍停在记着的那个块内
  （块内允许原生逐行移动），就一直沿用该目标列，**钳制不改写它**。
- **依据**：契约「连续移动保住目标列……到底了再往回走，仍回到原来的列」。修前把每一步的**实际列**
  当作新目标列 ⇒ 一步被钳到短行行尾后，原列永久丢失。
- **实测（修前 → 修后）**：
  - 单行内容块：起点 col30 → ↑↑（穿块，落"短行。"行尾 col3）→ ↓↓ ⇒ **col3（丢失）→ col30（恢复）**；
  - 多行内容块：起点 col2 → 逐行走过 3 行内容 → 出块 ⇒ **col5 → col2（恢复）**；
  - 起点 col8 / col0 往返 ⇒ 各自原样返回；0 pageerror。
- **探针**：`.mp-verify/repro-roundtrip.cjs`（三个起点列 × 往返）、`.mp-verify/verify-wps.cjs`（W′ 主序列）。

**四个设计的代价对照（留档）**| 设计 | 穿块按键 | 停靠点有意义 | 重排 | 逐行契约 | 箭头可进块 |
|---|---|---|---|---|---|
| B′（近端落围栏） | 2 | ✗ 闭围栏 | 2×50px | ✗ 跳过内容行 | ✓ |
| **W′（采纳）** | 2 | ✓ 内容行 | 2×50px | ✓ | ✓ |
| W（严格逐行，含围栏停靠） | 4 | 半 | 2×50px | ✓ | ✓ |
| F（纯跳过 = 修前默认） | **1** | —（块非停靠点） | **0** | ✓（按视觉行） | ✗（仅点击） |

F 为「阅读优先 / 能效最优」的备选，未采纳原因：箭头无法进块编辑。切换方式＝删除 `mathVerticalKeys` 与 `verticalIntoMath`。

## D3 补全只在键入时开【锁定】

- **口径**：补全面板仅由**文档变化**（键入）触发；任何"只动光标"的变化（方向键、点击、拖拽）一律先关闭。
- **依据**：否则 ↑ 把光标送进公式源码（`\rho\eta` 这类满反斜杠的行）会自己弹菜单，而菜单打开时 ↑/↓ 被补全 keymap 拦截 ⇒ **上键死循环**（实测复现）。
- **验证**：光标落在 `\rho\eta=x` col 5 → 菜单不弹；↑ 连续上行至块外正常；补全自身功能不受影响。

## D4 行中段 `$$…$$`：即时渲染 ＋ 收笔即换行【锁定】

- **口径**：① 行中段一旦出现完整 `$$…$$` 立即按**行内**渲染（零文档改动，保底"任何正确书写的 LaTeX 都能显示"）；② 光标**紧跟闭合 `$$`** 的那一拍，把它顶成独占一行的块公式。
- **三道闸**：光标紧跟闭合 `$$`（自限）；`$$` 之前有文字；**保护块内不动**（代码围栏 / 表格行 / 引用块 / 列表项）。尾随换行仅在"闭合 `$$` 之后不是行尾"时插入（否则会多送一个空行）。
- **事务**：`userEvent=input.autobreak` ⇒ Ctrl+Z 一步还原。
- **中文输入安全**：显式排除 `input.type.compose`（CM6 的 `isUserEvent` 是**前缀匹配**，`"input.type"` 会误放行组字事务），叠加 `view.composing` 兜底。
- **验证**：正文中段换行成块（6→7 行、无多余空行）；Ctrl+Z 一步还原；引用块内不换行但行内渲染；表格格内（覆盖层镜像非 `input.type`）行结构完好；IME-1/2/3 三场景中文无丢失。

## D5 源码展开态与渲染态同轴【锁定】

- **口径**：块公式的源码行（围栏行、待闭合行、块内各行）一律居中，与 KaTeX `displayMode` 渲染态同轴。
- **判据来源**：**词法级**（行首就是 `$$` 的行；"待闭合态"内部各行；已识别 span 覆盖的行），并塞进既有的 `scanLineStyles` 遍历，**不新增全文扫描**。
- **边界**：待闭合态遇**空行或收尾行**即结束（否则一个手滑的 `$$` 会把其后全文居中——首版实测到的过度）。
- **禁止**：任何"行尾出现 `$$` 即整行居中"的判据（会把整段正文居中；曾造成重大衰退）。
- **验证**：单独 `$$` → center；块内三行恒 center；行尾 `$$s$$` 的正文行 → start；后续正文不受影响。

## D6 预渲染框（浮动源码预览）【锁定】

- **口径**：光标在公式 span 内时，源码展开 ＋ **浮动预览**贴在源码下方 6px；预渲染框**可点击**（像素→tex 源偏移，KaTeX `sourceMap` 的 `data-typora-source-start/end` 五级判定）。
- **颜色**：主题派生 `color-mix(in srgb, var(--mp-bg) 84%, var(--mp-fg))` ＋ 毛玻璃 `blur 7px`、透明度 **0.65**；**不锚定任何硬编码色**（用户可能装自有主题）。
- **坐标纪律**：绝对定位子元素必须用**内容坐标**（viewport − offsetParent rect + offsetParent scroll）；滚动跟随由 `scheduleFloatPosition` rAF 兜住（CM6 高度图估计会让同一行的内容坐标漂移）。
- **验证**：滚动往返后与源码行偏移恒 +6；框内 λ 点击后光标落在源码 col 30；暗/亮主题各出图。

## D7 工具栏【锁定】

- **口径**：对齐 v2.3.3 的**可见集合**（35 项）；已实现 22 项走 `view.dispatch`，未实现的 13 项**置灰并在 `title` 写明原因**（不静默失败）。
- **布局**：`flex-wrap` ＋ `ResizeObserver` 回写 `--mp-toolbar-h`，随面板宽度折行；折行时隐藏分隔符。
- **验证**：35 项 / 22 启用 / 13 TODO 带原因；窄面板折行后高度回写、内容顶距同步；粗体/列表/引用/表格/撤销实测有效；主题切换生效；0 console error。

## D8 选区里的公式：只展开光标所在那一个，其余保持渲染＋选中态【锁定】

- **口径**：公式是否展开，判据从「**选区与 span 相交**」改为「**选区 head（光标端）落在 span 内**」。
  - head 在 span 内 → 源码展开 ＋ 浮动预览（旧行为不变）；
  - span 落在选区里但 head 不在其中 → **保持渲染**，加 `mp-math-selected` 选中底色；
  - 配套（必备）：`copy`/`cut` 在选区碰到数学 span 时，一律用**文档源码**写剪贴板
    （`state.sliceDoc`），否则拿到的是 KaTeX 字形文本而不是 markdown；未碰数学 span 的选区返回
    false 交回浏览器，保住将来富文本/表格 HTML 通道。
- **依据**：旧口径下拖过一段公式密集的正文，整片变成裸 LaTeX（实测截图：满屏 `\in`、`\mathbb`），
  可读性崩；新口径拖拽时可读、选区仍可见，且"head 所在"是唯一需要源码形态的位置。
- **能效账（如实）**：跨越一个公式的重排次数由 1 次（展开后维持）变为 **2 次（展开＋收起）**，
  单次重排幅度实测 **±50px**（块公式展开把下方内容推下 50px）。换来的是拖拽过程可读、
  选区语义可预测（不再有整片源码）。
- **验证**（`.mp-verify/verify-d8.cjs`，真实拖拽：按下→12 次移动→抬起）：
  - 拖过整段（head 落在正文）：`selected:4`、`srcLines:0`（4 个公式全渲染＋选中，无一展开）；
  - **拖到块公式上停住**：`srcLines:3`、`katexBlocks:0`（该块展开）、`selected:2`（前面的行内公式
    保持渲染＋选中）；
  - 复制整段选区：剪贴板逐字为 markdown 源码（含 `$$…$$` 与 `$…$`）；反向拖拽同；
  - 0 pageerror。
- **契约同步**：本条**取代**工作区交互验收总规则「三.4 块公式参与选中时整块并入选区、**源码同时展开**、
  选区不抖」中的"源码同时展开"——改为"**仅 head 所在公式展开，其余保持渲染＋选中态**"；
  "整块并入选区""选区不抖"两条不变。

## 已知偏离 Typora 清单（有意保留）

| 项 | Typora | 本引擎 | 保留理由 |
|---|---|---|---|
| 段落间空行 | 渲染层吃掉，不占停靠点 | 真实行：可停靠/可删 | 超集，多出结构编辑能力（D1） |
| 出块后横向位置 | 归零 | 保住经过前的列 | 契约②「连续移动保住目标列」，零额外开销（D2） |
| 数学源码补全 | 无（官方：#4312 "no autocomplete at all"） | 键入时给候选（自有增强） | 属增强项，不属对齐项；移动路径零弹窗（D3） |
