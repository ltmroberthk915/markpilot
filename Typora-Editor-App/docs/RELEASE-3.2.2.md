# MarkPilot 3.2.2

**超大文档打字更跟手；从网页和 Word 粘进来的内容终于保住格式；多开窗口和 Tab 键的手感也一起顺了。**

**超大文档**

- 十万行级的长文档里打字不再一顿一顿：连续输入的响应速度提升到原来的两倍以上，打开三百万字级别的文档也只要一秒出头；
- 滚动、跳转文首文末依旧顺滑，长时间编辑不会越用越卡。

**富文本粘贴**

- 从网页、Word 里复制一段带格式的内容粘进正文，会转成 Markdown：标题、加粗、斜体、行内代码、链接、有序与无序列表、引用、分隔线都保留；
- 粘贴内容里**同时有表格和正文**时，表格照旧变成 Markdown 表格，表格前后的标题、加粗、链接、列表也一起留下（以前只留表格，其余会丢）；
- 纯文本粘贴逐字落地，代码块内粘贴保持原样，`Ctrl+Shift+V` 始终是"原样粘贴"。

**右键菜单**

- 贴到窗口底部右键时，菜单不再被压成一条细缝：会完整显示，必要时整体上翻；
- 把界面放大到 200%、300% 时，菜单同样完整落在窗口内，每一项都点得到。

**Tab 键**

- 列表里按 Tab 嵌套一层；表格里按 Tab 移到下一格；代码块里按 Tab 缩进两格（`Shift+Tab` 反缩进）；
- 选中几行再按 Tab，整段一起缩进（缩进统一用空格）；
- 光标停在普通段落里按 Tab，仍然是"跳到下一个控件"——不会突然往正文里塞空格；
- `Ctrl+Alt+M` 可以在"Tab 缩进"和"Tab 跳焦点"之间切换，选择会被记住。

**多开窗口**

- 再开一个窗口时用默认大小并停在屏幕中间，不会把主窗口的位置和大小顶掉；
- 改主题、换字体或调字号，**所有已打开的窗口一起变**；
- 每个窗口的缩放各自独立——一个窗口放大看细节，另一个照旧全览。

**安装**

- 安装版：`markpilot-Setup-3.2.2.exe`；便携版：`markpilot-3.2.2-portable.exe`。

> 从 3.0.x / 3.1.x / 3.2.0 / 3.2.1 升级：设置与最近文件自动沿用，无需重新配置。
