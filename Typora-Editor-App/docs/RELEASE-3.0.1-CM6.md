# MarkPilot CM6 3.0.1 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

把文档交出去的那一刻也照顾到了：导出的表格是真正的表、字体跟你写作时看到的一致；阅读时中文正文两端对齐，标点不再乱跑。

---

## 这一版你能得到什么

**导出的表格，是一张真正的表**

- 导出的 HTML / PDF 里，表头行是表头而不是普通单元格：浏览器与阅读器知道哪一行是标题行。
- 把带表格的内容复制进 Excel / WPS，表头样式一并带过去，粘进去就是能直接用的表格。

**导出的文件，字体跟写作面一致**

- 导出的 HTML 与 PDF 沿用写作面的字体设置：正文衬线、代码等宽，中文斜体楷体。
- 不会再出现"打开导出件，整篇字体变了样、代码块变成另一种字"的情况。
- 公式字体与中文斜体照旧一并内嵌，离线打开、转发给别人都不用装字体。

**阅读时更像纸面**

- 中文正文**两端对齐**：右边缘不再参差。
- 行首行尾的禁则收紧：标点不再被顶到行首，也不会孤零零掉在行尾。
- 这两条只在阅读模式生效；回到编辑状态，光标手感与原来完全一样。

**桌面版更完整**

- 工具栏的**全屏**按钮可用：一键铺满屏幕专注写作，再点一下退出，并给出状态提示。
- 导出与打印要用到的本地资源（公式字体等）由应用自己读取，不依赖浏览器限制——导出件该带的资源都带得上。

| 下载 | 用途 |
|---|---|
| `markpilot-cm6-Setup-3.0.1.exe` | 安装版：装到本机，带开始菜单与快捷方式（约 79.1 MB） |
| `markpilot-cm6-3.0.1-portable.exe` | 便携版：双击即用，不写注册表，可放 U 盘（约 78.9 MB） |

## 常用操作

| 操作 | 快捷键 |
|---|---|
| 新建 / 打开 / 保存 / 另存为 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 切换深色/浅色 | `Ctrl+Shift+L` |
| 放大 / 缩小 / 重置 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` |
| 退出阅读模式 | `Esc` |
| 导出 PDF | `Ctrl+Shift+P` |

把 `.md` 文件直接拖进窗口也能打开；双击 `.md` 文件可用本应用打开。

## 说明

- 本版是**独立桌面应用**，与 VS Code 扩展版各自独立演进，本次不更新扩展（VSIX）。
- 编辑内核为 CodeMirror 6 + KaTeX，应用内为纯本地渲染，不需要联网。
- 表格编辑的进阶能力（单元格原地编辑、行列增删）在后续版本推进。

## 本次更新

**导出**

- 导出的表格带真正的表头行：阅读器知道哪一行是标题行，复制进 Excel 时表头样式一起带过去。
- 导出件与写作面同一套字体：正文衬线、代码等宽、中文斜体楷体，打开不会被换成默认字体。

**阅读模式**

- 中文正文两端对齐，行首行尾的禁则按中文排版口径收紧：标点不再被顶到行首、也不孤零零掉在行尾。

**桌面版**

- 工具栏「全屏」按钮可用，点击后给出状态提示。
- 导出与打印所需的本地资源（公式字体等）由应用自己读取。

**导出 PDF**：文件 → 导出为 PDF…（Ctrl+Shift+P）。
