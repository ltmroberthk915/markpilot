# MarkPilot 2.2.12

这一版修好三处"点一下不对、看一眼不对"的小毛病，都在数学笔记里最容易碰到。

## 一行里有两个等号时，后面的加粗不再失灵

数学笔记里 `=` 很常见，比如"时间差 + 接者单倍距离时间 = **慢者独自行驶时间**"。以前只要这一行出现过
第二个 `=`，后面的 `**加粗**`、`*斜体*` 就会原样显示星号，看上去像没生效。现在正常渲染。

- 顺带把 `==高亮==` 也接上了（Typora 同样支持这个写法）。
- 单个 `=`、以及当分隔线用的 `====`，显示不受影响。
- 打开、保存的文件**逐字节不变**——这只是"怎么显示"，不改你的笔记。

## 点公式源码，光标就落在你点的那一格

- 用鼠标拖选跨过一条公式之后、或者公式源码已经展开时，点它源码里的某个字：光标现在落在那一个字上。
  以前会跳到这条公式的最前面。
- 拖选翻开源码之后**快速点一下**（按下就松手）也准了：落点按你**按下那一刻**瞄准的位置算，
  不再因为松手时那一行重新排版而偏一格。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.12.exe`；便携版 `markpilot-v2.2.12-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.12.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.11 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。
