# 1.0.13 / VSIX 0.1.23：公式编辑配色修复

用户发现浅色阅读时，公式源码框和下方预览框仍为黑色。本机复现为「默认深色 / Konayuki Dark」搭配「米色 / 淡绿」的行内公式编辑：文字已经使用浅色阅读方案中的深色文字，源码背景仍是 `#2a2d2e`，预览背景仍是深色主题面板。

根因有两处：行内公式源码带有 Vditor 的 marker 类，被一般代码配色规则排除；下方浮动预览使用独立的面板背景变量，此前调色盘没有覆盖。修复为展开的行内数学源码单独指定阅读背景和光标颜色，并让正文内部的面板变量跟随阅读配色。修改仅涉及共享 CSS，不改变 Markdown、撤销、公式缓存或 AI 请求逻辑。

新增 48 种组合的回归检查：即时渲染 / 所见即所得 × 四个主题 × 三种调色盘 × 行内 / 块级公式。检查实际展开并聚焦后的源码、光标、预览文字与背景，对半透明背景先进行合成再计算对比度，确认保持 Markdown 原文。旧版制品复现四种不可读组合，新版全部通过；另验证公式编辑的撤销、重做、下方实时预览和后续输入。

章节上下文、独立调色盘、固定大纲按钮以及社区 CSS 的成本评估继续保留，说明见 [1.0.12 功能与实测](FEATURES-1.0.12.md)。
