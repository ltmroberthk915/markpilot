# MarkPilot 2.1.0

## ✦ 一次开好几份稿子：一个文件一个独立窗口

以前打开第二个文件会**顶掉**已经打开的那一份——这是产品最要紧的缺陷之一。这版改成：
**每个文件一个独立窗口**，各自可以拖动、缩放、最大化，互不影响；关掉一个不影响其它；
只有关窗口或退出应用时才问你要不要保存，而且是**逐个**确认，点「取消」就中止整个退出
（已经确认过的窗口内容不会丢）。

顺手一起做好的：

- **同一个文件只开一个窗口**：再次打开已在别处的文件，直接把那个窗口带到前面，不会弄出两份互相覆盖。
- **记住你上次开着哪些窗口**：每个窗口的文件、工作区、位置和大小都记下来，下次打开原样回来。
- **每个窗口一套文件夹树**：不同窗口可以开在不同目录，互不牵动；同一个目录只监听一次。
- **拖入或一次选中多个文件**：每个文件各开一个窗口；当前窗口若还停在欢迎页，就先填进当前窗口。

## ✦ 两个窗口之间复制粘贴，表格和图片都能带着走

多窗口之后最要紧的是"窗口之间搬东西"。这版把跨窗口的复制、剪切、粘贴都测过并修好了：
复杂表格里的**粗体、公式、行内代码、图片、转义竖线**粘到另一个窗口后都还在、并且重新渲染成
真节点；剪切表格格子只清空选中的格子、不改表形；图片剪切/复制粘到另一份文档后
**跟着那份文档走**，不会指向原来那个文件夹。

## ✦ 窗口很小的时候，工具栏会自己让位

窗口压得很矮时，工具栏换行后会占掉一大块高度。现在只要工具栏占到可视高度的 35% 以上，
它就**自动收上去**；鼠标移到窗口顶边它滑出来，鼠标离开再收回去。

窗口本身也不会再被压到比工具栏还矮了：**最小高度按「换行之后实测的工具栏高度」来定**
（让工具栏最多占可视高度的 80%）。窗口越窄、工具栏换行越高，能缩到的最小高度就跟着变高；
再拉宽，最小高度又跟着降回去。

## ✦ 在 IDE 里也不再「只能开一份」

- 默认把标签页**钉住**：以前单击文件会用同一个标签顶掉上一份（IDE 的「预览标签」行为），
  现在默认新开标签，多份稿子可以同时开着。
- 新增右键菜单「**用 MarkPilot 打开（新标签页）**」，任何设置组合下都强制新开标签。
- 切回某个标签时，编辑区会和最新内容对齐一次（长时间在后台的标签不会再显示旧内容）。

## 修复

- **复制复杂表格的单元格会丢掉格式**：在带粗体或行内代码的单元格上复制，记号会被悄悄吃掉
  （粘到别处只剩纯文字，公式还会被重复展开一遍）。现在按 Markdown 逐格还原，
  粗体、公式、行内代码、图片、转义竖线都能原样过去。
- **剪切表格格子会粘成一串**：剪切选中的表格格子后，剪贴板里得到的是一串连在一起的文字
  （还可能撑坏表形），粘到另一个窗口只剩一格。现在剪切和复制是同一套矩形语义，
  只清空选中格、不动表形。
- **剪切图片会指向原文档的文件夹**：剪走的图片粘到另一份文档后引用的是**原来那个文件所在目录**，
  换个文档就断链。现在剪切图片也按"图片"进剪贴板，粘到哪份文档就跟着哪份文档走。
- **一次打开多个文件却只剩一个窗口**：一次拖入或一次多选多个文件时，第二个文件会被误判成
  「填进刚建好的那个空窗口」，几个文件挤进同一个窗口——它正是「开一个顶掉一个」的另一种形态。
- **个别弹窗关掉后还留在页面上，导致再也打不开**：窗口被别的窗口完全遮住时，
  「关于」「快捷键设置」这类弹窗的关闭事件可能不派发，节点留在页面里、判重逻辑就把后续的
  打开请求挡掉了。现在关闭动作自己收尾，关一次干净一次。
- **退出应用时的偶发报错框**：多窗口退出时窗口正在销毁，焦点回调读到已销毁的窗口会弹错误框
  并卡住退出流程；现在这类回调一律跳过销毁中的窗口。
- **新建窗口会继承上一个窗口的最大化状态**：现在只有会话恢复和启动欢迎窗口会最大化，
  其余新窗口按上次的普通尺寸开窗。
