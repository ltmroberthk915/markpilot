> 展开代码编辑的情况下，进行一次鼠标在代码区的点击与渲染区的点击都会导致重新渲染一次这种闪烁，你把它修正,

用户同时给了公式内容 `\mathbb{E}_{\mathbb{P}}[\mathbf{1}_{E}]=\int \mathbf{1}_{E} d\mathbb{P}=\int_{E} d\mathbb{P}=\mathbb{P}(E)`。

## 二 取证过程（先证伪"是 Vditor 在重渲染"）

1. **第一版探针**（`scripts/acceptance/probe-click-rerender.cjs`）钩住 `innerHTML` / `replaceChildren` /
   `appendChild` / `insertAdjacentHTML` / `setAttribute` / KaTeX 的 `renderToString`，在块公式 owner 之内记调用栈。
   结果：**KaTeX 重建 0 次、preview 逐字节不变、首子节点同一**——用户的"重新渲染"不是 KaTeX 重跑，
   所以最初的假设（"预渲染被重建"）是错的。
2. 但 MutationObserver 抓到 **owner 的 class 每一次点击都变动**：`class ⇒ vditor-ir__node`（摘掉 `--expand`）
   之后又有几次赋值回到展开态。
3. **第二版探针**补了两样关键仪器：
   - **逐帧 rAF 采样**（rAF 回调之后紧接着就是这一帧的布局与绘制，采到的状态就是用户这一帧看到的）；
   - **给 owner 挂 `classList` 代理**（`DOMTokenList.add/remove/toggle/replace` 全走它），把调用栈连同
     "这一刻的光标在哪、有没有 press 类、谁是 activeElement"一起记下来。
   第一版还踩了个坑：`reset()` 里忘了打开采样开关，rAF 循环第一拍就退出了，采样帧数恒为 0——
   **"没采到"和"没发生"在数字上长得一模一样**，所以这一版把"自证采到足够多帧"写成了断言。
4. 得到决定性读数：

```
classList.remove → DIV.vditor-ir__node [vditor-ir__node--expand]
    ↳ refreshMathEditing (render/js/math-edit.js:300)   ← 我们自己
    ctx {caret: "TEXT@0", inMathCode: true, inOwner: true, pointer: true, hasFocus: true}
classList.add → DIV.vditor-ir__node [vditor-ir__node--expand]
    ↳ B (cdn/vditor/dist/index.min.js) ← 松手后 Vditor 的 click 处理器
```

5. **归因**：`refreshMathEditing` 里第 7 轮加的那条防抖规则

```js
const pointerDown = root.classList.contains(POINTER);
const blocked = owner => pointerDown && owner.dataset?.type === 'math-block';
if (active) { const owner = ownerOf(active); if (owner && !blocked(owner)) editing.add(owner); }
```

   在 press 期间把块公式挡在 `editing` 之外，于是下面那条"收回"循环把已经展开的块公式收了。
   press 与 click 之间隔着帧 ⇒ 块盒 145→119→145（26px 就是源码行那一条）⇒ 整块闪烁。
   键盘不挂 `.typora-ir-pointer` ⇒ 不闪。**用户的两条观察正好把这个开关锁死。**
6. **时序上的坑（重要教训，已写进探针与场景注释）**：CDP 把 `mousePressed`/`mouseReleased` 连着发时，
   两帧之间没有间隔，**一帧折叠态都采不到**——"点一下会闪"在台面上直接消失。改成按下后等 250ms 再松开
   （人手时序），闪烁立刻现形（15 帧折叠态）。

## 三 改了什么

`render/js/math-edit.js`（**只此一处**）：

- 模块级新增 `let pressFrozen = null;`；
- `refreshMathEditing` 里，press 期间**快照"按下那一刻已展开的块公式"**（只在 press 的第一帧算一次），
  并把两道收回循环都加上 `frozen(owner)` 跳过：

```js
if (!pointerDown) pressFrozen = null;
else if (!pressFrozen || pressFrozen.root !== root) pressFrozen = {root,
  owners: new Set([...root.getElementsByClassName(EXPAND)]
    .filter(node => node.dataset?.type === 'math-block' && ownMath(node)))};
const frozen = owner => !!pressFrozen && pressFrozen.owners.has(owner);
```

冻结语义 = **不展开（第 7 轮防抖原样保留）+ 不收回**；松手后 pointer 类摘掉，快照失效，
"光标不在公式里就收回去"的正常语义完全不变。
