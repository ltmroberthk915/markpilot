# MarkPilot 2.2.2

这一版修的是"上下方向键与公式打交道"的手感，以及用鼠标把公式一起选进来的体验。

## 上下方向键

- **光标列会保持住了。** 从一个纯公式行的上一行往下、或者从下一行往上，进到公式再走回来，
  光标回到原来的列——不再"上去再下来位置对不上"。
- **不再整行跳过。** 从公式里往外走，落到的一定是紧挨着的那一行。

## 把公式选进来

- **鼠标拖拽跨过公式块**：块公式会整条被选进选区，并且在拖拽结束时显示它的源码，
  看得见自己选中了什么。松手之后选区保持原样，不会自己缩回去。
- 行内公式的拖拽手感、Shift + 方向键的选中与 2.2.1 一致。

## 宋体主题

`宋体-朙`、`宋体-暗` 两套主题里的**斜体**（中文走楷体字面）字号放大约 6%——
楷体的字面比宋体略小略轻，同字号看着会"缩"一圈，这一档把它补回来。

## 安装

- 桌面版：运行 `markpilot-Setup-2.2.2.exe` 按向导安装；也可以直接用免安装的
  `markpilot-v2.2.2-portable.exe`。
- 编辑器扩展：`markpilot-2.2.2.vsix`（扩展面板 → 从 VSIX 安装）。

2.2.1 与更早的内容（围栏直接可编辑、空公式可见可删、EXE 与 VSIX 同版本发行等）全部保留。
