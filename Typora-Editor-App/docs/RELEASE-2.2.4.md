# MarkPilot 2.2.4

这一版修的是"找不到光标"和"行首行尾的四个键"。

## 光标不会再"看不见"

在段落末尾、两个公式紧挨着的地方、以及段落里的某些位置，光标本来会停在浏览器画不出来的位置上——
你点一下却看不到插入点。现在这些位置会显示一条正常的光标：粗细、颜色、闪烁都和别处一样，
打字落点也没有任何改变（只是把该有的光标显示出来）。

## 行首与行尾

- **Home**：光标到本行的行首（不再跑进 `#` 之类标记里，也不会在折行段落上掉到上一行的末尾）；
  再按一次才去整段的开头。
- **End**：到本行行尾；行尾是公式时，光标落在公式之后。
- **Ctrl+Home / Ctrl+End**：到文档开头 / 结尾，光标一定看得见。
- **←/→ 在行首行尾**：按左右键跨到上一行行尾 / 下一行行首，与常见编辑器一致；
  文档最开头、最末尾按不动时，光标保持在原处、不会消失。

## 说明

这一版只改显示与落点校正，**不改任何保存/序列化逻辑**：打开、编辑、保存仍然逐字节保真。
