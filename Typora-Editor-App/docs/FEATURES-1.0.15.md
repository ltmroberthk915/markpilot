# marcopilot 1.0.15 / 插件 0.1.25-local

收尾版本：marcopilot 的图片内嵌、缩放与 Office 迁移三大能力保持 1.0.14 语义不变，本轮补齐正确性缺口并完成发布闭环。

本版同时提供两条互不覆盖的发行线：自用版继续保留用户自行配置的 AI 补全；[Jinxi 公开版说明](PUBLIC-RELEASE-1.0.15.md) 使用独立 App ID、安装包名和 VSIX publisher，发布运行时不携带个人远程补全 API、API Key、密钥保险库或私有模型配置。

## 打开与保存的正确性收口

- 打开文件先完成内嵌图片掩蔽、成功后才切换旧文档：打开失败时旧文档的补全、自动保存与快照定时器完全不受影响。
- 超过 20 MB、空字节或缓存目录不可写的内嵌图片不再阻断整篇打开：原文保留 + 一次性提示；插入新图片仍严格限制 20 MB。
- 另存为（含只读文件保存失败后的"另存为副本"）自动把相对路径图片内嵌为 data URI，副本移动到任意位置仍可独立打开；无法读取的图片保留原引用并逐条提示。目标目录不存在时自动创建。
- 保存原图对话框取消时提示"已取消"而不再误报成功；保存对话框不再受 30 秒媒体请求超时影响（其他操作超时行为不变）。
- 重新加载不再静默吞错（仅文件不存在属正常取消）。
- 右键图片可设置 5–400% 显示缩放（预设 25/50/75/100/150%）：缩放按源码偏移原位替换 raw Markdown、既有 HTML、IR 或 WYSIWYG 中的同一张图片，只保留一个 `<img width data-typora-scale>`；原像素不重采样，undo/redo 与保存后重开均保持一致。

## VS Code 宿主修复（真实宿主验证）

- 当前 VS Code 将 TextDocument 数据属性冻结，旧代理在激活时即抛错。改为纯门面对象后真宿主全绿：**105 项检查全部通过**（旧基线 101 + 新增内嵌上传、偏移映射、撤销重做×内嵌图、媒体通道错误回执、CRLF 往返）。
- Trae 宿主复跑同一份 0.1.25-local VSIX：Trae API 1.107.1 下 **105 项检查全部通过**；测试未输入或提交任何账号凭据。
- 修正缓存 URL 匹配同时兼容 `file+` 与 `file%2B` 两种拼写：此前 VS Code 宿主下保存会把内部缓存 URL 写进 md 文件（已在真宿主修复并验证，落盘零缓存 URL）。
- 更多菜单恢复"内容主题"与内置导出入口（对照 1.0.14 原菜单），Word / 便携 Markdown 导出入口保持不变。

## 质量修复

- 公式转 OMML 的私用区占位符会跳过原式中已使用的码位，避免含 U+E000 类字面量的公式被占位符碰撞破坏。
- 本地图片路径不再误剥 `#`/`?`：文件名含空格、括号、井号、字面 `%` 均可正确读取；仅远程 URL 剥查询串。新增引用式、重复图、远程失败整单报错等边界单测。
- Word 渲染复验（Word COM → PDF → 逐页检查）：矩阵括号随内容伸缩、嵌套列表"1.→2.→•"编号正确（两处历史缺陷确认修复）、表格前导零 00123 保留、中文无乱码。

## 边界与限制

- 内嵌图片使单个 .md 自包含可迁移；部分第三方 Markdown 预览器禁用 dataURI，不能保证所有软件显示。
- DOCX 尽量保真（可编辑公式/表格/列表/图片），不承诺完全无损：真实教材 2,844 个公式中 138 个（约 4.8%）转换不支持，按设计保留 LaTeX 源码并列入导出警告，内容不丢失。
- Office 剪贴板迁移仅支持 Windows；Office 图片粘贴为位相同原始字节（PNG 无重编码）。
- Pandoc DOCX/HTML 同条件对照已完成；严格 PDF 对照受源文档第 903 行附近的 Pandoc/xelatex 语法错误限制，因此不宣称 PDF 速度差异。
- 本版本不含付费 API 实验。
