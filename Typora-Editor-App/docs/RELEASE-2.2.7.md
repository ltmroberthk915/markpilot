# MarkPilot 2.2.7

这一版修好了行内公式独占一行时，左右方向键把光标"走丢"的问题。

## ←/→ 走进"整行只有一条公式"的行，光标看得见

- 上一段末尾按 **→**（下一行正好是一条独占一行的行内公式）：光标进入这条公式的源码开头，
  公式随即展开——不再是"按一下，光标没了"。
- 下一段开头按 **←**（上一行是这样一条公式）：光标落在公式源码的末尾，同样看得见。
- 上下方向键本来就是这个行为，这一版把左右方向键补齐到同一手感。

## 手感细节

- 行尾就是公式的行（不是独占一行）不受影响，照旧按"行尾 → 下一行行首"走。
- 光标隐形时的兜底落点现在**严格朝你按的方向**找下一行，不会再因为折行的行尾渲染而"往回跳"。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.7.exe`；便携版 `markpilot-v2.2.7-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.7.vsix`，或直接在扩展市场更新。
