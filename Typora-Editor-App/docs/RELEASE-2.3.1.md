# MarkPilot 2.3.1

稳定性小版本，把编辑手感打磨到位：打字速度、光标显示、选区、图片与公式编辑、窗口大小
记忆与若干界面细节，共十多项改进，每一项都经过「复现 → 修复 → 验证 → 回归」的完整闭环。

## 打字流畅度大幅提升

以前每敲一个字，都要把整篇文档重新换算一遍——文档越长，打字越一顿一顿。现在纯文本
按键约 4 毫秒就落定（此前约 50 毫秒），长文档里的手感与短文档一致；公式、表格、标题
等复杂位置的行为一字不差。

## 任何时候只有一根光标

图片旁边、空段落里这些特殊位置，以前时而出现「两根光标」、时而光标干脆看不见。现在
光标显示统一交给系统原生绘制：永远只有一根，闪烁节奏与系统一致，插在哪都看得见。

## 图片编辑更省心

- **点图片右侧的空白**，光标直接落在图片之后，图片源码不会被抖出来；正文里直接写的
  `<img …>` 也一样，不再先展开源码行。
- **粘贴多行文字**时，换行不会再被塞进图片源码里，图片保持完整。
- 图片后按**回车**直接新起一段，**撤销**一步就回到原样。

## 公式更安全

标题里带行内公式时，在内容最左侧按回车（或退格合并相邻段落），公式以前会**悄悄消失**；
现在合并后公式完整保留，一个字节都不丢。

## 标题里的光标与选区

- 标题里按住 **Shift+←** 能一路反向选中文字，贴着公式时整条公式并入选区；
- 从标题按 **↑ / ↓** 进出相邻的空段落不再失灵，光标正确落进空行。

## 撤销后光标落回文字

撤销之后，光标稳稳落回刚才编辑的位置，在文字里看得见——不再藏进看不见的层里，
也不需要点一下鼠标才找回。

## 窗口大小不再漂移

调整窗口大小后反复开关、最大化再还原，窗口尺寸保持设定值不再一点点走样；每个窗口
各自记忆，互不干扰。

## 界面与性能细节

- 大纲面板跳转后，标题落在工具栏下方并留出呼吸空间，不再被工具栏挡住一截；
- 「关于」对话框显示完整版本号；帮助菜单新增**检查更新**，启动时也会静默检查，
  有新版本才提醒；
- 同一会话里再次打开文档更快：内部排版资源改走缓存，不再每次重新加载。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.3.1.exe`；便携版 `markpilot-v2.3.1-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.3.1.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.3.0 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。
- 升级后首次启动会重新记忆一次窗口大小（一次性），此后保持稳定。

## Bug 修复

- **长文档里打字一顿一顿**：每敲一个字都要整篇重排，按键延迟约 50 毫秒。现在纯文本按键约 4 毫秒落定。
- **图片旁边出现两根光标，或光标看不见**：光标显示统一为系统原生绘制，任何位置都只有一根、都可见。
- **点图片右侧空白，图片源码被抖出来**：光标直接落在图片之后；`<img …>` 裸 HTML 图片同样不再展开源码行。
- **粘贴多行文字，换行被塞进图片源码**：多行粘贴整单拦截，图片保持完整。
- **标题里的公式在段落合并时悄悄消失**：在内容最左按回车或退格合并相邻段落后，公式完整保留。
- **标题里按 Shift+← 反向选不上文字（贴着公式时尤其明显）**：现在能一路反向选中，整条公式并入选区。
- **从标题按 ↑ / ↓ 到相邻空段落没有反应**：光标正确落进空段落，按键不再被吞。
- **撤销之后光标不见了**：光标落回刚才编辑的位置，在文字里直接可见。
- **窗口开关几次后大小悄悄变化**：尺寸持久化与恢复改用同一口径，反复开关、最大化还原都不再漂移。
- **大纲跳转后标题被工具栏挡住一截**：标题落在工具栏下沿并留 14px 空隙。
- **「关于」对话框不显示版本号**：现在显示完整版本号（MarkPilot v2.3.1）。
- **同一会话里再次打开文档偏慢**：内部排版资源改走条件缓存，重复打开不再重新加载 3.8MB 排版引擎。
