# MarkPilot 2.1.24

**AI 补全这次做到了「能读、能改、能自己排查」。**

## 建议框终于像个正常的浮层

建议长的时候，直接在里面滚动查看；窗口会按光标上下的空间自动放大，不用拉着滚动条看半句。点一下框不会消失，也不会把光标挪到正文里——读完再决定：Tab 接受，Esc 取消。

## 配置完全由你决定

不预设任何服务商或模型。粘一段 Claude Code / cc-switch 的 `settings.json`、一段 JSON、或一行 `KEY=VALUE`，模型就配好了；不需要的模型配置随时删除，密钥一并清掉。

## 地址怎么写都能用

`https://api.deepseek.com`、`.../v1`、`.../anthropic` 都指向同一个端点，照服务商文档原样粘贴即可。密钥按平台保存，改模型名不会丢。

## 出问题时不用猜

报错会带上服务商返回的原文和**实际请求地址**，并说清是「密钥没填 / 地址不对 / 模型只回了思考内容 / 生成被截断」中的哪一种。

## 安装

- **Windows 桌面版**：`markpilot-Setup-2.1.24.exe`（免安装：`markpilot-v2.1.24-portable.exe`）
- **VS Code / Trae 插件**：`markpilot-2.1.24.vsix` —— 扩展面板 → 右上 ⋯ → 从 VSIX 安装…
- **校验**：`SHA256SUMS.txt`

## 修复

- AI 补全报「HTTP 404」：地址与协议不一致时不再拼出服务商不存在的路径，旧配置照旧能用。
- AI 建议框不能滚动、点一下就消失：现在可在框内滚动查看，点击不关闭、也不移动光标，点正文仍会关掉。
- 报错只说「暂无建议」：现在会说明原因（密钥、地址、模型只回思考内容、生成被截断），并附上实际请求地址。
- 改模型名后需要重填密钥：密钥按平台保存，改模型名不再影响。
- 修改 API 地址会顺手关掉 AI：不再自动关闭，并提示新地址需要填一次密钥。
