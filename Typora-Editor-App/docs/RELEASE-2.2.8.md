# MarkPilot 2.2.8

这一版修好三处与光标、查找有关的毛病：标题最左边按左键"卡住"、在那里按退格会把 `#` 删掉，
以及"Ctrl+F 之后点查找框打字，字却进了正文"。

## 查找面板：点击与输入恢复正常

- 之前从公式附近点开查找面板、在输入框里打字时，字会跑到正文里（面板一直显示 0 个结果）。
  原因是编辑器的点击处理把浮层上的点击当成了正文点击。现在浮层上的点击不再被接管。

## 标题块首：← 走得出去，退格不再吃 `#`

- 光标停在标题最左边时，按 **←** 会走到上一行的末尾（和其它行一致），不再"按了没反应"。
- 同样在这个位置按 **退格**：上一块是表格这类"吞不下正文"的块时**什么都不会发生**（`#` 还在、
  标题不降级）；上一块是段落时，标题正常并进上一段——两种情况都跟 Typora 的习惯一致，
  而且一次 Ctrl+Z 就能退回。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.8.exe`；便携版 `markpilot-v2.2.8-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.8.vsix`，或直接在扩展市场更新。
