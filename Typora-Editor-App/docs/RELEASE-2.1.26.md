# MarkPilot 2.1.26

**你的 Typora 主题，现在可以直接用在这里。**

## 导入你自己的 Typora 主题

「主题」里多了一栏：选整套主题的文件（可以多选，主题里互相引用的子文件一起选上），或者直接把样式粘进去。导入后当场生效，随时停用、随时删除。

Typora 主题的正文样式会自动落到 MarkPilot 的写作区上；响应式断点、条件选择器、主题自己定义的配色变量都照常生效。

## 它和内置主题是同一套做法

内置的 Konayuki、宋体-朙就是 Typora 社区主题。现在你也可以把社区里任何一套主题拿来用，不必等我们出新版。

## 有三件事它做不到，先说清楚

- **主题自带的字体文件不会跟过来**：主题里用本地字体文件的地方会退回系统字体。这些引用会被拦掉，而不是让编辑器去加载不存在的文件。
- **主题里的图片（背景图等）同理**：读不到的图片会留空，其余样式照常。
- **只作用于正文**：工具栏、菜单、侧边栏保持 MarkPilot 自己的样子，所以不会和 Typora 里一模一样。

导入之后会给你一行统计：生效多少条、丢弃多少条不属于写作区的样式、多少本地字体没加载——一眼知道为什么和 Typora 里有点不同。

## 主题多的时候对话框也好用

导入的主题一多，主题对话框会长过窗口、底部的按钮点不到。现在对话框与主题列表各自限高并可滚动。

## 安装

- **Windows 桌面版**：`markpilot-Setup-2.1.26.exe`（免安装：`markpilot-v2.1.26-portable.exe`）
- **VS Code / Trae 插件**：`markpilot-2.1.26.vsix` —— 扩展面板 → 右上 ⋯ → 从 VSIX 安装…
- **校验**：`SHA256SUMS.txt`

## 修复

- 主题对话框：导入多套主题后不再长过窗口、底部按钮不再点不到。
- 主题里的本地字体与图片不再被加载（此前会让编辑器去请求读不到的文件）。
- 带互相引用的主题现在能完整生效（此前只拿到外壳样式）。
