# MarkPilot 3.2.3

**换了新图标：扁平靛蓝圆角块 + 白色 M，任务栏、桌面、开始菜单里都一眼认得出。**

**新图标**

- 去掉旧的"多色渐变 + 星芒"样式，改用单一靛蓝配白色几何 M——桌面与任务栏里更干净、更醒目；
- 安装后的程序、安装包本身、便携版三者图标一致；
- 小尺寸（16 / 24 / 32 像素）下仍然清楚，不会糊成一团。

**大文档**

- 十万行级的长文档里打字不再一顿一顿：连续输入响应速度提升到原来的两倍以上；打开三百万字级文档约一秒；
- 滚动、跳转文首文末依旧顺滑。

**粘贴**

- 从网页、Word 复制带格式的内容，会转成 Markdown：标题、加粗、斜体、行内代码、链接、有序与无序列表、引用、分隔线都保留；
- 粘贴内容里同时有**表格和正文**时，表格照旧变成 Markdown 表格，表格前后的标题、加粗、链接、列表也一起留下；
- 纯文本逐字落地，代码块内粘贴保持原样，`Ctrl+Shift+V` 始终是"原样粘贴"。

**右键菜单**

- 贴到窗口底部右键，菜单会完整显示（必要时整体上翻），不再被压成一条细缝；
- 界面放大到 200%、300% 时，菜单同样完整落在窗口内，每一项都点得到。

**Tab 键**

- 列表里嵌套一层、表格里移到下一格、代码块里缩进两格（`Shift+Tab` 反缩进）；
- 选中几行按 Tab，整段一起缩进（统一用空格）；
- 普通段落里按 Tab 仍是"跳到下一个控件"，不会往正文里塞空格；
- `Ctrl+Alt+M` 切换"Tab 缩进 / Tab 跳焦点"，选择会被记住。

**多开窗口**

- 再开一个窗口时用默认大小并停在屏幕中间，不会顶掉主窗口的位置和大小；
- 改主题、换字体或调字号，所有已打开的窗口一起变；
- 每个窗口的缩放各自独立。

**安装**

- 安装版：`markpilot-Setup-3.2.3.exe`；便携版：`markpilot-3.2.3-portable.exe`。

> 从 3.0.x / 3.1.x / 3.2.x 升级：设置与最近文件自动沿用，无需重新配置。
