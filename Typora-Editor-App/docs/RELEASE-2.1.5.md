# MarkPilot 2.1.5

## ✦ 清空整篇之后接着打字，不再变成公式

`Ctrl+A` 全选 + 一次退格把文档清空之后，接着打的第一句话以前会**变成公式**：当文档最后一块是块公式时，
光标会停在那个被清空的 `$$` 里，你打的字直接进了公式源码——屏幕上出现的是一段按公式排版的斜体字
（打 `abc`，文档里就变成 `$$\nabc\n$$`）。

现在清空之后是一个普通的空段落，接着打字进的是正文。

## 修复

- **清空整篇之后接着打字会被当成公式**：`Ctrl+A` 全选 + 一次退格之后，如果文档最后一块是块公式，光标会停在
  那个空 `$$` 的源码里，之后输入的字符全被写成 TeX（打 `abc` 就得到 `$$\nabc\n$$`）。现在这种"清空后只剩
  一个空块公式"的形状会归位成空段落，打字进正文；清空后按**一次** `Ctrl+Z` 依旧逐字节把整篇文档还原。
