# Typora Editor 1.0.10：桌面导出与本地资源鉴权

桌面菜单 **文件 → 导出**，以及编辑器 **更多（…）→ 导出图标**，可选择：

- **PDF 文档**：原生保存对话框直接保存 PDF。独立后台页面完成 Markdown、KaTeX、Mermaid、代码高亮、图片和字体加载后再调用 Electron `printToPDF`，不依赖系统打印机或固定延时。A4、11 磅正文、重复表头、标题书签；长公式根据可用宽度适配。
- **HTML（独立网页）**：公式与 Mermaid 已转为静态内容；内嵌样式、字体和图片，离线打开无需编辑器、CDN、脚本或本地服务。导出采用浅色阅读样式。
- **Markdown 副本**：导出编辑器当前源码，包含尚未保存的输入。原文件及撤销历史保持原状。

保存后提供打开文件和定位文件夹。生成时可取消；错误公式保留源码，缺图显示占位，完成面板列出具体提示。图片单个上限 20 MB、合计上限 100 MB；远程图片请求超时 15 秒，完整导出超时 3 分钟。不可访问的图片不会阻塞其他内容。

导出原子写入，不能覆盖当前 Markdown 或其硬链接/符号链接目标；目标在生成期间被外部修改时停止写入。原始 HTML 中的活动脚本、事件处理、iframe 和不安全链接不会进入导出结果。

## 本地服务

每次服务启动产生 256 位随机令牌，只驻留主进程内存。包括 `/ws-file/`、`/ws/`、`/doc/`、`/shell`、`/render/` 在内的全部路由要求令牌，并校验实际回环地址与端口。

主进程仅为注册窗口中可信页面的同源请求附加请求头；其他进程、未注册 Electron 窗口和外部网页不能获取令牌。令牌不出现在文档、URL、HTML、设置或导出文件里，外部请求会剥离该请求头。同时修正 shell 静态目录的路径前缀穿越检查，错误响应不泄露文件绝对路径。

## 实测

真实笔记：`动态规划教材（渲染修复副本）.md`，178,107 UTF-16 字符、2,844 个公式。测试只写入隔离副本，原文件 SHA-256 保持 `854c06a50d591c99b53810bcb0951e291b1c7bd495336d22897b855c3748599f`。

一次完整导出：HTML 约 3.5 秒、8.9 MB；PDF 约 19.6 秒、3.1 MB、96 页、150 个标题书签。公式无渲染警告；检查首尾、跨页表格及正文公式页面。时间为本机单次记录，不是其他机器的承诺。

鉴权、图片路径、取消、错误资源、写入失败、并发导出、目标竞争修改、未保存内容、原文件保护、离线 HTML 和 PDF 已覆盖。数据见 `.perf/desktop-export.json`、`.perf/export-book.json` 与 `.perf/server-auth.log`。MathJax 评估见 [MATH-ENGINE-BENCHMARK.md](MATH-ENGINE-BENCHMARK.md)。

新版原生导出由 App 主进程提供。VS Code/Trae 的插件宿主不具有 Electron `printToPDF` 接口，本次共享工具栏适配不会将该接口用于插件。
