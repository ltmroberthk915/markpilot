# MarkPilot CM6 3.0.8 · 独立桌面版

**Typora 手感的 Markdown 编辑器，一个窗口、打开即写、所见即所得。**

## 这一版修了什么

**有序列表显示正确的序号**

- 引用区里的有序列表此前被画成圆点（`•`），现在显示**数字序号** `1.` `2.` `3.`。
- 正文里的有序列表此前**也是错的**（同样被画成圆点），一并修好——两条路径现在合并成同一套实现，不会再各自漂移。
- 序号规则与 Typora 一致：**按列表首项声明的数字起算**（`3.` 开头就显示 `3.`），其后逐项递增；**空行打断列表后重新起算**；`3)` 这种右括号写法统一显示为 `3.`。
- 无序列表仍是圆点，与 Typora 相同。
