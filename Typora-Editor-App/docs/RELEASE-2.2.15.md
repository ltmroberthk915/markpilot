# MarkPilot 2.2.15

这一版把上一版"点公式右边缘之外"那条修到位，并收掉一条中文输入法相关的"重大 bug"。

## 公式右边界，以右 `$` 的中间为准

上一版把"公式外面"的起点定在右 `$` 的**右边缘**，结果是：点右 `$` 靠右的那一半，光标仍旧被
塞进公式源码——你瞄准的是"公式外面"，落点却在里面。现在边界取右 `$` 的**中间**：
右 `$` 靠右的那一半也算公式外面，点下去光标落在公式之后第一个正常文本位置；
左 `$` 靠左的那一半同理，落在公式之前。

## 中文输入法：字不再被写进公式

光标停在右 `$` 之后（看起来已经在公式外面）时，用中文输入法打字，上屏的字以前会被写进
公式源码（公式里多出你打的字）；现在正常落在公式外面的正文里。

## 跨行长公式与预渲染浮框

占多行的行内公式、以及公式展开时浮在源码上/下方的预渲染框，按在上面仍旧算"按公式本身"，
照旧进源码编辑、落点在你按的那一格，不会被推到外面。

## 安装

- **Windows 桌面版**：运行 `markpilot-Setup-2.2.15.exe`；便携版 `markpilot-v2.2.15-portable.exe`。
- **VS Code / Trae**：扩展面板里"从 VSIX 安装"选择 `markpilot-2.2.15.vsix`，或直接在扩展市场更新。

## 兼容性

- 与 2.2.14 相比没有设置项变化；打开、保存、导出的文件格式与前一版完全一致。
