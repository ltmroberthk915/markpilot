# MarkPilot 2.3.2

一次聚焦编辑手感的更新：标题行的回车语义、图片源码的呼出手势、图片多选的选中提示，以及
标题附近的行内公式保护。四件事都按「你按下什么、屏幕上就该发生什么」重新对齐。

## 标题行回车：井号留在原行，内容落到下一行

在 `### ` 后面（文字之前）按回车，现在会把三级标题标记**留在当前行**，只把后面的内容推到
下一行，并让那行成为普通正文；光标直接停在正文开头，可以接着往下写。

把光标放在 `### ` **之前**按回车，才是原来的行为：上方插入一个空行、整个标题行下移。
两种手势从此一眼可辨。

光标停在井号**中间**时仍按"块首"处理，不会把标题拆出错误级别；`#` 到 `######` 六级一致。

## 图片：点两下必出源码，快慢都一样

以前呼出图片源码要看手速——两次点击间隔小于系统双击时间才会展开，点慢一点就只停在
"选中"。现在**第一下点击选中图片，第二下点击一定展开源码**，间隔是 150 毫秒还是 3 秒
没有区别；继续点也不会把已经展开的源码收回去。

大图同样成立：源码行把图片顶下去以后，落在原位置的点击不会让源码折回。
`Alt` + 单击、右键菜单、拖动选中等既有手势保持不变。

## 图片多选：选中框不会再凭空消失

单击图片是实线框；按住 `Ctrl` 再点时，**哪怕点的就是刚才那一张**，也会从实线框变成多选
用的虚线框，屏幕上始终有一个看得见的选中指示。再 `Ctrl` 点一下这张虚线图才取消。

多选之后按 `Delete` 删的是图片、按 `Ctrl+C` 复制的是整组图片，正文一个字都不会被动；
多选过程中编辑光标留在原处，不会跑到文档开头。

## 标题与公式：拆分、退格都不再丢公式

标题里带行内公式时，拆分、拆分后立刻退格、以及随后的撤销，公式都不会再被静默吃掉。
这条保护同时覆盖"空标题后面紧跟一个段落、在段落开头按退格"的形状。

## Bug 修复

- **在 `### ` 后面按回车，整个标题行往下跑**：现在井号留在原行、内容落到下一行成为普通正文；与"在井号之前按回车"两种手势不再长得一样。
- **点图片出源码要看手速，点慢了要点好几次**：第二下点击必定展开源码，与两次点击的间隔无关。
- **单击图片后按住 `Ctrl` 再点同一张，选中框整个消失**：现在变成多选虚线框，屏幕上始终有可见的选中指示。
- **多选图片之后打字，字跑到文章最前面、甚至吃掉第一行标题的 `#`**：编辑光标留在你原来的位置，正文逐字不动。
- **标题里带公式时，拆分后按退格公式悄悄消失**：拆分、退格、撤销整条链路上公式完整保留。
- **多选图片后按 `Delete` 误伤正文**：现在删的是图片本身。
