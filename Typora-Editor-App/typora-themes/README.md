# 宋体主题对 · Typora 第三方主题

MarkPilot 内置主题「**宋体-朙**」（明色）与「**宋体-暗**」（暗色）的 Typora 版本。
两套配色和排版尺度与 MarkPilot 里完全一致，可以在这两个编辑器之间保持同一份阅读观感。

| 文件 | 对应 | 纸色 |
|---|---|---|
| `宋体-朙.css` | 明色 | `#FAF9F6` 米白纸 |
| `宋体-暗.css` | 暗色 | `#2E3440` 深蓝灰纸 |

## 装进 Typora

1. Typora → 文件 → 偏好设置 → 外观 → **打开主题文件夹**。
2. 把这两个 `.css` 文件（连同本文件）复制进去。
3. 重启 Typora（或切换一次主题），主题列表里就会出现「宋体-朙」和「宋体-暗」。
4. 想要明暗自动跟随时，把「宋体-朙」设为浅色模式主题、「宋体-暗」设为深色模式主题。

单个文件即完整主题，不依赖外部字体或图片，直接丢进去就能用。

## 这套主题在做什么

**正文是宋体 + Georgia 的混排。** 西文栈固定为 `Georgia, 'Times New Roman'`，
汉字回落到 `SimSun / 宋体`。顺序是刻意的——西文和数字先进 Georgia，汉字才落到宋体；
西文栈里**不放假名 `serif`**，否则逐字回落会被截断，汉字会掉进默认衬线字体而不是宋体。

**宋体只有 400 一个字重，表达不了"半档加肥"。** 所以正文用 `-webkit-text-stroke: .007em`
做细描边来加磅数，标题和 `**加粗**` 则各自用 700 / 900 的字重，层级仍然分明：
正文 400+.007em < 标题 700 < 加粗 900。

**中文斜体走楷体字面。** 中文没有真正的斜体字形，默认的合成倾斜只是把字拉歪；
这里改成楷体（`KaiTi / 楷体`）配合 `font-synthesis-style: none`，是中文排版里"斜体"的正解。

**六阶语法梯子。** 代码高亮的取色不是随手挑的，是按人眼亮度差（ΔL*）排出的六档：
注释最贴纸面、字面量次之、字符串、正文、类型、关键字最外。所以在一段代码里，
关键字最跳、注释最退，扫读时结构先跳出来。

## 与 MarkPilot 内置版的一致性

配色、字体栈、行距、版心宽度都是从内置主题逐项搬过来的，取值可以对着
`app/renderer/css/telari.css` 逐条核对。两处是为了 Typora 不得不补的：

- **选区色与侧栏色**：内置主题由宿主界面提供，Typora 需要主题自己声明，
  这里按主色（`--primary-color`）同源推导。
- **代码高亮类名**：内置版针对 Vditor 的 `.hljs-*`，Typora 的代码区是 CodeMirror，
  这里换成 `.cm-*` 体系，六阶取色值不变。

设计出处与完整拆解（含配色梯子的对比度算式）见 MarkPilot 仓库
`docs/TELARI-TYPOGRAPHY-ANALYSIS.md`。
