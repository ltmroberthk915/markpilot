**0.1.18-local：四个补全模型一键切换**

编辑器工具栏 → **补全 ▾** → 点击菜单顶部的模型按钮。四个按钮排列为两行，当前模型高亮并显示“✓ 当前使用”，工具栏仍只占原来的一个入口。也可在命令面板执行 **Markdown Editor: 切换补全模型**。

| 按钮 | 实际模型 ID | API |
| --- | --- | --- |
| GLM | `glm-5.3` | 智谱 Anthropic 兼容接口 |
| GLM Flash | `glm-5.3-flash` | 智谱 Anthropic 兼容接口 |
| DS Flash Vision Exp | `deepseek-v4-flash-vision-exp` | DeepSeek Anthropic 兼容接口 |
| DS Pro | `deepseek-v4-pro` | DeepSeek Anthropic 兼容接口 |

DS Flash 仅使用用户指定的 Vision Exp 版本，不做其他 Flash 型号的自动回退。切换按钮同时更新地址、协议、模型；模型仍可在菜单的“模型”项中手动编辑。

GLM 两款模型共用 GLM 密钥，DeepSeek 两款共用 DeepSeek 密钥。密钥保存在对应 IDE 的原生 SecretStorage 中，不写入工作区设置、前端消息或 VSIX。旧版密钥只迁移到原先配置的地址。不同自定义地址及协议独立保存，删除当前平台密钥不会删除其他平台的密钥。

切换立即取消旧模型尚未完成的请求，清除旧建议缓存，保留本地补全、自动请求、光标停顿建议和延时设置。点击切换本身不发起计费请求；后续输入、光标触发或 `Alt+\` 使用选中的模型。保留单次直接补写、上下文预算、数学优先及本地判断的设计。

VS Code 和 Trae 已配置默认 **DS Pro**，开启本地补全、自动 AI 和光标停顿建议，基础延时 650 ms。GLM 密钥沿用原先保存的凭据，DeepSeek 使用本次用户提供的凭据；两套 IDE 均已保存两平台的密钥。新安装且没有个人配置时仍保持 AI 请求关闭。安装和实际配置结果见 [release-0.1.18.json](release-0.1.18.json)。

与前一版的 [40 个缺口质量对照](QUALITY-DP-MODELS-0.1.17.md) 共用补全生成逻辑，本次只需验证四个预设的连接和切换，不重复整批模型质量实验。

两套 IDE 均已安装 `0.1.18-local`，各核验 468 个扩展文件与最终 VSIX 一致。桌面教材原文件的 SHA-256 保持不变。已有窗口可执行 **开发人员: 重新加载窗口** 后使用新版菜单。
