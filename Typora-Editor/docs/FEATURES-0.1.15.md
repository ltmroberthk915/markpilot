# 0.1.15-local：补全下拉菜单与自动触发修复

工具栏只保留 **补全 ▾** 按钮。点击后展开 API Key、地址、模型、自动 AI 开关、本地补全开关和更多设置。菜单浮在编辑区上方，展开时不会增加工具栏高度；支持方向键选择、Esc 关闭和点击外部关闭。API Key 仍通过宿主密码输入框填写并保存在 SecretStorage。

## 自动触发

- 本地公式和模板候选从停顿 260 ms 调整为 120 ms，不再等待 Markdown 源码定位和宿主同步。
- 编辑器为显示输入光标而自动滚动时保留补全；用户滚轮、点击、移动光标或 Esc 仍可取消。
- 编辑器重建当前块后，输入回调和恢复的光标会重新触发补全，不再受 350 ms 的恢复窗口限制。
- 超长段落、列表或引用不再使本地和 AI 补全整体失效。源码定位超出预算时，本地候选直接使用光标词元；AI 使用当前文本节点附近的有界上下文；无法精确定位时仍跳过宿主候选，避免改错位置。
- AI 延迟直接从最后一次输入计算，不再额外叠加宿主同步耗时。保留已有延迟配置（默认 650 ms）。中文输入法组词期间暂停，提交后恢复。
- AI 显示正在请求、错误和超时状态；超时从 5 秒调整为 15 秒。快速重试不再静默丢弃。输入变化会取消旧请求，空闲时不轮询。

入口路径：**补全 ▾ → 自动 AI 补全**。仅保存密钥会启用手动 AI，自动请求仍由开关控制。自动补全的触发等待与模型生成耗时不同；真实响应速度仍由所配服务决定。

仅更新 VS Code / Trae 插件。安装包：`dist/seepine.md-editor-0.1.15-local.vsix`。

最终安装包已通过 8 项接口单元测试、VS Code 1.134.0 的 81 项集成检查和 Trae（VS Code API 1.107.1）的 45 项集成检查，并安装到两个 IDE。重载窗口后生效。

测试覆盖下拉菜单及设置保存、三种模式的真实键盘公式输入、原生中文 IME、连续输入合并请求、5.5 秒慢响应、大文件末尾自动滚动、超长段落、撤销和公式缓存。AI 使用本机模拟接口，未读取用户密钥或调用真实智谱服务。

15.6 万字符、2200 个公式的合成文档，VS Code 局部源码准备 10 次采样为 0.3–1.1 ms，未调用整篇 `getValue()`；该数值不代表总体输入延迟或模型响应时间。完整记录见 [release-0.1.15.json](release-0.1.15.json)。
