**0.1.17-local：按真实数学教材修正补全输入格式**

公式中的双反斜杠、把缺口补成整条公式、续写下文末尾等问题，会让已有建议无法直接使用。新版在同一次生成中提供原样 LaTeX 和明确的插入位置，正文也在最后重现光标处的句子，避免模型照抄 JSON 转义或接错位置。

保留 0.1.16 的光标停留触发、输入触发、本地候选与 AI 候选共存、建议缓存、继续输入时复用剩余建议。触发判断在本地完成，不额外调用 LLM。每次生成仍有固定上下文预算和短输出限制。

数学建议如果越过已有 dollar 分隔符继续输出正文，只保留前面的公式片段；正文建议不能借用右侧已有公式的开头来闭合自己未完成的 dollar 公式。GLM 数学请求增加供应商文档支持的 effort 控制，但实测部分响应仍返回思考块，不能承诺该兼容接口完全不思考。

用《动态规划教材（渲染修复副本）》固定 28 个公式、12 个文字缺口，对 GLM 5.3 Flash、DeepSeek V4 Flash Vision Exp、DeepSeek V4 Pro 比较两种格式，并对固定 10 个缺口各重复三次，共 360 次成功返回的生成。[完整结果与逐项评级](QUALITY-DP-MODELS-0.1.17.md) 保留了空建议、格式错误和数学错误。

格式改进很明显；模型仍可能混淆矩阵乘积、下标或句子边界。新格式首轮可直接采用数为 GLM 34/40、Flash 33/40、Pro 32/40；固定公式连续三次均可用为 5/7、6/7、7/7。样本规模与评阅标准不足以用 1–2 题的差距判定总体能力。

验证：18 项单元检查；最终 VSIX 在 VS Code 1.134.0 和 Trae 1.107.1 中各通过 55 项补全回归。包括输入/光标触发、IME、局部上下文预算、缓存、取消、公式右侧保留、接受及撤销。40 个实测上下文生成的生产请求还逐字核对了实验中的新格式请求。
