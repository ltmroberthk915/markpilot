# MarkPilot 3.6.9

本次更新把文档图片两侧的点击行为整理成一条固定规则，编辑图文混排的长文档时不再误入图片源码。

- **点图片右侧直接编辑下一行**：无论是点图片右边的空白，还是编辑器最右侧的空白，光标都会落到图片下面一行的开头，可以直接继续写；图片源码不会再被意外展开。下一行是标题、列表或任务项时，光标会落在标记之后，不会把 `#`、`-`、`[ ]` 写坏。
- **点图片本身仍是编辑源码**：点图片会显示它的 Markdown 源码并把光标放进 `[]` 里，和原来一样。
- **图片在文末、或下一行是表格/围栏/分隔线时**：光标会停在图片紧右侧，图片源码收起、文档结构不变。

适用于 Windows x64。下载并运行 `markpilot-Setup-3.6.9.exe` 安装；无需安装时，可使用 `markpilot-3.6.9-portable.exe`。
