# MarkPilot 3.6.17

恢复了 MarkPilot V2 最后版本的深蓝宋体主题，作为第 10 套内置主题「宋韵 深蓝」。

- **新增「宋韵 深蓝」**：纸面 `#2E3440` 深蓝、正文 `#C3C7CF`、标题 `#EAEDF3`、主色 `#28AAF1`；引用底 `#353C4A` 配 `#53607A` 左缘条，代码块 `#232935`，六级语法色沿用 V2 原色板。可在工具栏「主题」或设置里直接选择。
- **现有「宋韵 深色」不变**：仍是中性暗色 `#1f2126`；两套主题并存，「切换明暗」只会在同族明暗之间走。
- **其余行为与 3.6.16 一致**：本次只增加主题配色，不改编辑、保存、多窗口协同、导出与导入协议；已有主题、字体、自动保存与最近文件设置继续保留。

Windows 提供安装版和便携版。配套 DSH Markdown 插件版本为 0.3.12（内核 3.6.17）。
