# dsh-markdown-typora 0.3.3

DSH 右侧栏的 Markdown 编辑器，内核是 MarkPilot CM6 3.6.6。这一版把「手动保存」和「选中文段送进对话」补完整，侧栏打开的文件也不再被会话工作区边界挡住。

## 这一版新增

- **Ctrl/Cmd + S 立即保存**：不管光标在编辑区、侧栏还是对话输入框，按保存键都会保存当前 Markdown 文档，并给出「已保存 / 没有需要保存的改动 / 保存失败 / 冲突」的明确结果。不会再弹出浏览器的「保存网页/HTML」对话框。
- **侧栏文件直接保存**：从右侧栏打开的文件，即使不在当前会话的工作区目录里，也能写回它自己的文件夹。版本守卫和外部修改冲突提示保持不变；操作系统层面只读或被占用的文件仍会明确报错。
- **选中文段 → 对话带文件地址**：点「插入对话」或按 `Ctrl/Cmd + Shift + Enter`，插入内容开头会先给文档的绝对路径，再空一行接 Markdown 源码，对话里能直接看出这段内容来自哪个文件。
- **保存失败不再静默**：保存请求排队、拉全文超时、冲突、权限错误都会在面板上显示结果，而不是按了没反应。

## 能做什么

- **即时渲染**：标题、列表、引用、表格、代码块、公式与 Mermaid 图表，写下来就是排版后的样子；光标进块看源码，离开回到渲染。
- **公式点哪改哪**：点渲染预览里的任意符号，源码光标落到生成它的那段 LaTeX。
- **选中文段，送进对话**：选一段 Markdown，点「插入对话」，绝对路径和源码一起落进当前会话的输入框。
- **保存带版本守卫**：磁盘上的新版本不会被旧缓冲覆盖，冲突会明确报错而不是盲写。
- **离线可用**：KaTeX、Mermaid、语法高亮 Worker 全部随包，不依赖网络。

## 安装

在 DSH 里装进当前 profile：

```bash
dsh plugin --profile web add dsh-markdown-typora-0.3.3.tgz
dsh plugin --profile desktop add dsh-markdown-typora-0.3.3.tgz
```

装完重启宿主，右侧栏打开 Markdown 文件即用。从 0.3.2 升级直接覆盖安装，重启后完成。

## 兼容性

- 文档格式、保存协议与文件地址协议都没有变化，0.3.2 打开的文件照常可用。
- 图片读取走插件自身的只读通道，只服务图片扩展名，且仅在有会话凭据的本机宿主内可达。
- 插件要求 DSH 0.2.1-rc 及以上版本的右侧栏契约。

## 已知限制

- 引用里写绝对 Windows 路径（`![](D:\pics\a.png)`）时图片不显示；用相对路径或 `assets/` 目录即可。
- 引用里的文件名含 `#`、`?`、`%` 时无法按 URL 寻址，图片不显示。
- 文档在操作系统层面只读、被其它程序锁定，或所在磁盘不可写时，保存会失败并显示错误。
- 大文档（15 万字以上）首次打开需要构建一次语法树，之后的输入与滚动不再受它影响。
