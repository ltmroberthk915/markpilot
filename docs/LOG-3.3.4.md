# 3.3.4：表格行内格式与实际几何通知

单元格旧投影只处理代码、图片和数学，未处理文字格式；HTML 行内出口另有星号正则，但缺少下划线和删除线。新增 inline-format.js，使用本机 Lezer 的公开 Tree 接口及官方强调、删除线解析，配对无属性 u 标签。单元格、活动 rendered floor 和 HTML 出口共用此投影。代码、TeX 和图片作为原子处理，源码、UTF-16 选区 codec 与撤销历史仍由原文档管理。

解析缓存只保存精确源码及语法树，最多256条、131072源码字符，长于16384字符的条目不缓存；不缓存文档专属图片地址或资源 HTML。普通无标记文字直接转义。

单元格沿用原有链接源码形式，但链接文字内的格式、代码、公式及图片继续投影。最后兼容性复核补回该路径，并新增真实链接标签断言及单元测试；链接出口仍走原有 HTML 回调。新旧 bundle 的严格局部 AST 边界证明因生成符号变化未成立，故最后构建重新执行全部37套477例，不使用旧回归结果的资格化复用。

表格实际尺寸改动原先未通知工具条。每个 view 使用一个 ResizeObserver，节点注册及取消由 region lease 管理。实际尺寸未变的同步 DOM 替换继承逻辑行记录，避免每个字符都重新扫描表格定位。缓存按文档 epoch、region、context、逻辑行及表格拓扑隔离并限制近端数量。

200% 缩放的实测另发现：表头保留旧列宽，输入触发重建才应用64px列宽下限，表头高度从590.38px骤降到187.20px。既有列宽策略现由真实宽度变化触发并合并到 RAF，高度变化不重新计算列宽；输入前后真实光标高度和滚动位置作为回归判据。顶部主工具条及表格工具条按实际可见占用保护当前单元格光标，不新增滚动监听或更改预览参数。

验证范围包括37套既有及新增工作流、477例，新增普通/引用表的表头与正文四格式、源码编辑/撤销重做/手动保存/HTML出口，以及实际顶部遮挡命中。负控分别移除格式投影、几何生命周期、宽度刷新、可用顶部边界；单独移除尺寸后的工具条重摆在列宽已修复的旧场景中不再有鉴别力，保留该结果而不算作负控通过。最终证据以本批冻结产物与实际安装包验收收据为准。

最后构建的首次完整回归在公式编辑的自动保存用例遇到 Windows EPERM：同目录临时文件替换原文件被拒绝，原盘和未保存状态保留。日志与保存错误路径已复核，未将原因推断为用户操作或特定后台程序；同一载荷的14例公式流程定向复跑全过。失败原件继续保留，发布门禁使用随后完整执行的最终收据。
