# MarkPilot 3.6.14 学习笔记编辑验证

基线是本机的正式 3.6.13。反例和对照均在隔离窗口中执行，源码状态、选区、撤销历史与文件读回分别核对。代表性大笔记只用于制作独立副本。原始收据在 `.mp-verify/study-3614/`。

| 学习笔记流程 | 3.6.13 反例及修复判据 |
| --- | --- |
| 正向复制、反向剪切带制表符的 Markdown | 系统剪贴板文字正确，目标笔记却变成了表格。原生复制、剪切和右键菜单现在保留来源。外部相同字节的 TSV 仍可建表。同目录相对图片的反向剪切覆盖了源、目标两份文档的历史和磁盘内容。 |
| 在公式上交错使用鼠标和键盘 | 鼠标尚未松开时导航或输入，旧释放动作会抢回光标。Ctrl+点公式还可能丢掉副光标或扩宽旧的反向选区。现在只校准当前手势的新落点，已有精确选区保持原方向。 |
| 公式与引用、普通段落的边界 | 引用中缺少闭合符会吞掉外层笔记，同一行两个双美元公式会吞掉中间文字。按容器配对围栏，编辑和 HTML 输出共享单行判据。孤立行尾也不会凭空产生数学块。 |
| 输入和自动换行的先后顺序 | 输入后立刻跳到另一段，延迟换行会误写新光标所在位置。代码里字面的美元符号也可能增加源码行。只有仍然有效的公式输入才触发换行。 |
| 代码样例中的反引号、HTML 注释与换行 | 单反引号包裹内含反引号的选区会破坏代码跨度，代码中的注释开头会隐藏后文。富文本代码块中的可见换行也会消失。代码定界符、投影与粘贴共用实际代码跨度，并保留代码中的字面字符。 |
| 网页数学和科学排版 | 富文本公式可能混入 TeX 注释、MathML 和可见层的重复文本。现在优先保留显式 TeX，含内部美元时使用无歧义的表示。上下标同时在源码、正文投影和富文本输出中保留。 |
| 粗斜体与混排样式 | 内容已经加粗时按斜体会剥掉原来的粗体。现在判断对应的强调定界符。相邻或嵌套的网页样式按共同范围序列化，避免生成可见的多余星号。 |
| 富文本段落、链接和表格 | 段内换行、表格单元格中的多段内容会粘连，链接标签的字面右方括号会截断链接，带图片的表题会阻止整表粘贴。现在保留文字边界、链接标签、表题及来源顺序。 |
| 图文中有不可读取的图片 | 一个不可访问的附件会吞掉整个粘贴。现在在同一插入事务中保留可读内容及其他图片，并给出提示。如果片段只有不可读取的图片，原选区不被替换。替代文字中的 Markdown 符号按字面保留。 |
| 从讲义复制稀疏表格 | 170 行、最宽 150 列的样例因补空格而膨胀。正文行的额外对齐填充受预算约束，显式空单元格、表头和分隔行仍保留。 |

3.6.13 首次同一行公式探针没有确认输入到达，改为先打开已有公式再编辑标题。图片正常对照首次遇到已有的图片删除保护，随后通过真实按钮确认撤销。两种入口失败都保留了原记录。后台解析模型也区分了“接受当前 Worker 的结果”和“20 毫秒内完成渲染侧解析”，仍检查退役回调不得发布结果。

最终候选的数学粘贴测试最初漏传剪贴板写入凭据，9 项都在粘贴前停止。修正测试入口后，同一程序的 9 项全部通过。另一项跨窗口草稿保护测试在创建窗口后曾有一次等待编辑焦点超时，尚未执行保存或关闭。保留原始收据后，6 次从独立进程启动并观测新空白文档的原生焦点、活动元素和编辑器焦点，均通过。首次超时原因未能复现。

同一冻结候选完整重跑数据安全组，23 项全部通过，包括副窗口保存后关闭主窗口仍提示处理未保存草稿。旧版空行行内公式的对照也再次通过，按快捷键、键入第一个字符、删回空公式三个时刻均沿用段落对齐。稀疏表格示例的整份笔记从 79,637 个字符降至 3,647 个字符，这是保存源码长度的实测，未测通用粘贴耗时。

- 最终源码通过 457 项单元测试，零失败、零跳过。同一应用包在 Windows 桌面通过 32 组、395 项回归，其中 7 组、37 项直接针对本轮学习笔记流程。
