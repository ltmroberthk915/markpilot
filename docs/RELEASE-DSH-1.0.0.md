# MarkPilot for DSH 1.0.0

More room for writing, with a compact vertical workbench and a floating toolbar. Switch transparency and themes immediately, edit tables across document and AI chat, and resize the workspace smoothly.

- A wider document canvas with compact margins and transparent vertical controls.
- Live appearance settings without reopening the editor.
- Stable table presentation when switching focus to AI chat.
- Native workspace widths restored when the editor closes, with an optional setting to retain adjustable handles.
- Windows responsiveness improvements and platform adapter boundaries for future macOS/Linux work.

The bundled MarkPilot editor core remains 3.6.17. Existing preferences and documents are preserved. Windows is the validated desktop platform for this release.

Install: `dsh plugin --profile desktop add dsh-markdown-typora@1.0.0`

Alternatively install the attached `dsh-markdown-typora-1.0.0.tgz` using DSH plugin management.
