# 3.3.7：表格行高交接与长文档渲染预算

本批范围是相邻表格单元格切换的视口漂移，以及大文档原生滚动条拖动后进入公式编辑的延迟。实际安装 3.3.6、代表性文档和当前偏好均使用隔离副本；原件只读。

## 行高机制

等布局的单元格切换会替换行 widget。未知行高使 CM 高度图暂时退回默认文本高度，紧接着另一笔选区事务保存了错误的滚动锚点。相同屏幕位置的两次原生切换分别增加约 243.797、243.789 CSS px。共享几何缓存现在交接实测的视口像素高度，保留布局签名、文档 epoch、逻辑行和当前 lease；冷点击及偏好失效仅补测当前行。

负控仅移除行高交接，在匹配的屏幕位置再次产生两次约 244 px 的跳变；恢复后八次原生点击均为零视口位移。跨格、输入、撤销、重做和保存仍依据真实源码范围。表格列宽在共享 measure 中先批量读、再批量写。

## 渲染预算与缓存

固定 `@codemirror/view` 6.43.14 的原始字节和 MIT 许可，通过受控生成器新增项目维护的 `EditorView.viewportMargin` Facet。默认仍为上游的 1000，较大的公式/表格文档选择 300（上下合计）；保留上游过大范围容差、滚动目标和 anchor/head 的完整额外视口。预算变化立即重算视口。所有 view imports 统一 alias，构建检查要求单一 view/state 模块。

公式 HTML 与离线 DOM 模板分别有界缓存，每个消费者复制独立节点，不缓存 mounted owner 或 lease。块公式尺寸采用实际 DOMRect 视口单位，过期上下文不能提供高度。

## 验证与口径

- 212 项单元测试；7 项定向原生操作：100/145/200% 单元格切换、完整块高度、高公式编辑与预算撤销、重复公式归属、跨两屏拖选及反向/松手/Shift 继续选择。
- 同条件原生滚动条五段测试中，3.3.6 基线长任务 44 次，最终载荷样本为 15 次；四次有效公式点击约 27–42 ms。点击前用可见帧确认滚动结算在 500 ms 内完成，实际等待约 11–63 ms，等待与点击响应分开计量。第五段没有可见正文公式，明确记作不适用，不计成功点击。更早候选为 24 次、私有预算反事实为 20 次；不能把私有反事实当旧版基线，也不能从一次样本推定所有滚动形式或设备的收益。
- 同一冻结载荷的前 39 组、481 项公共回归全部通过并保留原始执行证据；最后新增组因探针的拖选中途截图与反向取样基准校正，单独重跑 7 项并通过。完整 ASAR 成员、运行时、产品资源、其余探针/夹具和输入集合保持一致；仅该末组探针发生已记录的字节变化。合计 40 组、488 项判据完成，不把保留证据写成修正后重跑全套。原红灯收据保留不覆盖，包装及装机結果以本批私有收据为最终事实源。
- 首个跨屏拖选探针落在正文外侧空白，焦点断言阻止误判；第二次可见文字入口需要更长真实自动滚动时间。失败收据保留，修正入口和有界等待后通过，没有补焦点或改选区掩盖失败。
- 最终跨屏探针在按住区间的截图前后观察到 trusted `mousemove buttons=0`，CM 按钮释放逻辑会结束拖选；仅凭源码不能确定事件的外部来源。探针现在在松手后截图，按住时保留按钮和坐标轨迹并拒绝提前释放；反向从实际上边沿 endpoint 建立基准，仍要求前进两屏及从前进终态和反向 endpoint 各返回一屏。连续手势、松手停止、Shift 继续、源码保真均通过。最终一次执行还捕获探针自身 SHA 和完整执行前后冻结快照；第一次校正绿灯与旧红灯均留存。
- 完整回归首次在 205% 单元格一次输入 600W 时拦截光标越界。只读 setter 诊断记录产品先滚至 630.976 CSS px，约 1.3 ms 后 CM measure 锚点补偿又写回 429.268；当时最大滚动位置 2907，排除了滚动范围夹断。输入揭示现在只在首次需要滚动时追加最多两轮 measure→RAF 确认，合计最多三轮；新指针、键盘或滚轮意图立即取消。恢复后同臂增长、撤销、重做、删除及输入后立即滚轮均通过，鼠标相邻切格仍为零位移。最初旧载荷保留为该修复的负控。

内部完整证据位于 `.mp-verify/codex-audit/cell-switch-scroll/`，包含实际载荷、冻结输入、操作收据及独立复核。文档正文、profile、截图和升级备份不纳入发布文件。快速缩放同一帧的 RO 时序尚无确定故障证据；普通连续反向滚动的收益不能从远距离拖动数据推定。

## 安装交付验证

安装版、便携版及独立身份测试包的 73 个运行文件、144 个 ASAR 资源均与冻结载荷相符。便携版 9 项笔记操作通过；含空格路径的隔离安装与卸载完成，原注册表值和类型保持一致。正常安装从 3.3.6 升级至 3.3.7 前保存程序、profile、注册项和快捷方式备份，升级后完整程序载荷及注册项核对通过。实际安装程序上的代表性副本 E6 相邻单元格八次点击均为零位移，原件保持原始 SHA；正常 profile 的真实 Windows Shell 默认 `.md` 打开加载新文档，同时保留旧文档、选区和撤销/重做历史。仅关闭验收拥有的两个干净合成窗口。
