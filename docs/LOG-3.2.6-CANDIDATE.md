2026-10-11；这是源码及本地候选记录，尚未发 GitHub Release 或升级远程主机。承接 [窗口数据安全修复](LOG-3.2.5-DATA-SAFETY.md)，保留 CM6 发布 bundle，不重建引擎。

## 编码行为

打开和重新加载使用同一个严格解码模块。UTF-8 与带 BOM 的 UTF-16 LE/BE 可编辑；字节序、BOM 和均匀 LF/CRLF 在保存及另存为中保留。中文、ASCII、emoji、正文中的第二个 U+FEFF、合法 U+FFFD 与偶发 NUL 均有往返判据。

奇数长度 UTF-16、孤立代理、损坏 UTF-8、UTF-32 或二进制文件拒绝打开，不改变当前文档或磁盘字节。内存中不完整的 Unicode 字符拒绝保存，保留草稿与原磁盘，并提示删除该字符或撤销；不静默替换文字。修正文字后可恢复保存。

无 BOM 的 UTF-16 没有可靠自动识别承诺，UTF-32 签名优先于歧义的 UTF-16 开头 NUL；遇到歧义明确拒绝而不猜测。混合换行沿用原多数策略，保存会统一，不能声称混合 EOL 逐字节保持。
