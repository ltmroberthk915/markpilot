# MarkPilot 3.6.11 / DSH 0.3.6 验证记录

本批基线为已安装的桌面 3.6.10 和本地插件 0.3.5。私有原始收据位于 `.mp-verify/architecture-3610/`。正式安装完成，未发布远端。

| 范围 | 行为和证据 |
| --- | --- |
| 公式识别和位置 | 3.6.10 在空行插入行内公式时将裸 `$$` 当作块级排版。删除重复的排版推断后，行内公式保留段落对齐，完整块公式仍居中。行内识别共用源码解析器。三个相邻公式独立渲染，点击用当前控件的 region 身份确定字形所属源码。真实输入从旧版失败到新代码 14/14 通过，最终正式安装另跑 7/7。两条故障路径均新增永久 GUI 回归用例，在正式安装版通过。 |
| 图片与资源 | SVG 使用 `.svg`，百分号编码与 base64 共用严格预算和字节解码。实际抽出 113 字节 SVG，磁盘逐字节相等。完整图片事务经过确认或取消后返回实际结果，支持撤销。网络与本地读取对实际流量实施上限。 |
| 桌面与 DSH 写入 | 外部冲突后通过当前文档、版本和目标取得一次覆盖许可，正式流程保留后续外改保护。候选真实点击确认后，独立回读 UTF-16LE、BOM、CRLF 均正确。本地 DSH 保存与 edit 共用路径队列、稳定快照、编码和原子替换，写入失败不破坏原文件，队列可重试。两个宿主从同一版本写入时只有一个成功。 |
| DSH 编辑和恢复 | 引擎回执确认后才提交父层文档和版本，保存与重载串行，同会话 cwd 变化不会重新指向另一文件。父层记录连续编辑增量，IndexedDB 检查点配合有界同步尾日志。真实浏览器验证丢回执后马上关闭、未结束的输入法组字、9 MB 副本关闭重开及多个恢复槽隔离。新恢复副本耐久后才能清旧记录，旧回执不能清更新的草稿。 |

桌面与插件共 399 项单元及集成检查通过。冻结产物的 270 项 GUI 回归通过，保留原始失败收据。图片选择器旧探针在整文件读取入口注入延迟，新版改用流式读取。更新注入位置后，两项竞态检查均通过。公式五通道与图片转换由独立视觉复核读取合成帧确认。

在同一份 9,033,628 字节代表文档副本中，以相同运行时和输入探针各采样 14 次。输入事件到第二个动画帧的中位数分别为 25.1 ms 和 29.4 ms，取第七与第八个排序值的平均数。两版的十二次续输都保持本行数学扫描。这些单轮读数支持确认编辑行为和扫描范围，不能据此声称新版整体提速。原文档摘要在实测前后一致。

三个 Windows 包的全部 160 个 ASAR 成员与 77 个运行文件核对通过。DSH tarball 的全部 145 个文件和来源逐字节匹配，包内原生写入器也进行了竞争保存。唯一安装身份在带空格目录安装、卸载，然后升级正式安装。升级后 PE 为 `3.6.11.0`。安装前后 487 个 profile 文件保持一致。默认文件关联打开第二篇文档时，首篇正文、选区、脏状态和撤销历史保留。

严格注册表比较的原始差异收据已保留。正式安装涉及原产品卸载项及两个产品快捷方式，另有五个 Windows 包共十个活动时间戳前移。独立审核逐值记录，两个 ContentDeliveryManager 时间落在安装期间，未归因到具体写入进程。交付索引、安装位置、备份与校验和见 `.mp-verify/architecture-3610/delivery.json` 和同目录 `SHA256SUMS.txt`。
