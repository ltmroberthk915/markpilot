# MarkPilot 3.3.1

公式编辑时，预览框按内容完整高度显示，高括号、分式和矩阵无需在框内上下滚动。柔和的实线边界和轻阴影让预览与正文自然区分，长公式的横向滚动条更细，并去掉两端箭头。

预览避让更贴近编辑位置，最多移动 67.2 px。在「更多 → 设置 → 公式预渲染框」中取消「就近避让正文」，预览便直接显示在源码下方；设置会被记住。

[Windows 安装包](https://github.com/ltmroberthk915/markpilot/releases/download/v3.3.1/markpilot-Setup-3.3.1.exe) · [便携版](https://github.com/ltmroberthk915/markpilot/releases/download/v3.3.1/markpilot-3.3.1-portable.exe) · [校验文件](https://github.com/ltmroberthk915/markpilot/releases/download/v3.3.1/SHA256SUMS.txt)

运行安装包升级即可保留已有设置。横向拖动、点击预览定位源码、撤销与重做继续使用同一文档的编辑历史。
