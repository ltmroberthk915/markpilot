# 窗口数据安全修复证据

所有文档、位图和路径都是合成夹具；目录只包含小型 JSON 和截图。完整运行时、安装包、浏览器 profile、模型会话及中间源码副本留在忽略目录中。

- [修复版定向结果](positive/result.json)：15 条，包括刷新和取消另存为关闭；每张全图另有 2 倍局部 caret 图。
- [真实旧代码回退](rollback/result.json)：12 条，1 通过、11 失败；是产品逻辑回退后的预期红项。
- [保存回执回退](receipt-mutant/result.json)：1 条预期失败。
- [磁盘冲突回退与恢复](negative-controls.json)：真实文件系统测试、源文件 SHA 与恢复状态。

PNG 的 SHA256 是原文件的完整哈希。红 caret 标记按编辑器坐标叠加，不代表截图抓到了原生闪烁光标。主控重算所有图片 SHA 并看实际图像，Flash 独立复核视觉，GLM 只读文本审查；报告不得把图已生成等同于图已看过。

复跑方法见 [质量工具说明](../../../tools/quality/README.md)，实现与范围见 [工程记录](../../LOG-3.2.5-DATA-SAFETY.md)。最终便携版与隔离安装验证在后续 3.2.6 候选证据中。
