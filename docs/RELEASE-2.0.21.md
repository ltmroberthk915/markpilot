# MarkPilot for DSH 2.0.21

首次打开 Markdown 时，文件栏在左、编辑器居中、AI 对话在右。之前明确选择右侧布局的用户可以继续使用原来的位置。

- **导出 PDF**。在编辑器「导出」中选择 PDF，即可将当前稿件存为 A4 文档，支持表格、数学公式、Mermaid 流程图和本地图片。
- **在表格里对照公式**。编辑单元格时，将光标移到公式旁就能看到排版结果，和正文公式的操作一致。
- **在正文与脚注之间跳转**。工具岛提供脚注按钮。主题、字体、页面、阅读外观与快捷键集中在「更多 → 编辑器设置」。

在 DSH 的插件市场搜索 `MarkPilot`，或运行 `dsh plugin --profile desktop add dsh-markdown-editor-typora@2.0.21`。打开 DSH 后，点左侧 **Markdown** 进入编辑器。
