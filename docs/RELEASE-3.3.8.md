# MarkPilot 3.3.8

CSS 主题导入后会保存在 MarkPilot 自己的主题目录。移动、修改或删除原 CSS 文件后，重开文档、重启应用仍可使用导入时的副本；切换明暗也会保留主题外观。

正文、一级至六级标题、斜体、粗体和代码可以分别选择字体。留空即可沿用默认字体。主题 CSS 明确指定字体时，字体设置会禁用并显示原因；移除主题后，之前保存的字体选择会恢复。

更多菜单提供主题、字体、页面缩放和界面大纲的直接入口。设置按常规与保存、主题、字体、页面与缩放、阅读与排版、图片、界面与大纲、快捷键分组，查找修改项更方便。

小主题文件显示实际字节数。合法 CSS 的末项声明省略分号时，颜色也能正确读取。多窗口共用主题和字体选择，设置变化不会改写文档内容或撤销记录。

Windows 使用 `markpilot-Setup-3.3.8.exe` 安装；便携版为 `markpilot-3.3.8-portable.exe`。打开后从「更多 → 主题…」导入 CSS，从「更多 → 字体…」调整各类文字。

安装与卸载会在 MarkPilot 仍运行时停止。请先保存文档并关闭所有 MarkPilot 窗口，再继续操作。

主题中的相对字体和图片文件仍需另行适配；导入 CSS 不会复制整套主题素材。旧版已保存的主题会保留现有外观，重新导入原 CSS 可保存完整原始文件。
