# MarkPilot 3.6.3 核验与本地交付

基线 checkout：`ec47ac37554b13cef3488435ee5de51fe42d439d`。桌面版本由 3.6.2 升至 3.6.3，运行时 Electron 44.9.3。私有原始证据位于 `.mp-verify/remediation-363/`；正文、profile、升级备份和私件截图均不进入发布材料。

## 行为与数据边界

- 修正长行压缩高度、缩放与源码栏打开时序；约 9 MB、24 张内嵌图片的实际文档副本在 165% 和 100% 缩放、文末打开、滚动和重开后两栏均可读。原件与副本磁盘 SHA-256 保持不变。
- 正文的活动源码、表格活动单元格与双栏源码隐藏内嵌图片数据。底层数据作为原子区间保护，保留说明、尺寸等正常编辑；完整图片内容仍写入 Markdown。
- 删除、替换和会移除图片的历史操作先提供备份、直接继续、取消。备份写入同目录 `assets`，按内容验证、独占创建并处理重名；写入失败不应用原编辑。异步确认绑定文档、路径、选区与历史，迟到结果不能修改另一个文档。取消正在进行的备份后，已经成功写出的备份可保留，原文不删除。
- 修正表格非活动行复用与宽度更新、无选区剪切，以及块公式关闭定界符右端点的源码归属。
- 修正 PDF 临时目录的 Windows 8.3 别名准入；统一原生 canonical 路径，同时保留 token、父目录、session 和 worker 目录身份校验。
- 大文档等待 Worker 时复制已知语法前缀；跨修改边界的内联节点不保留。最终 mixed parser 仅在确认旧树没有实际挂载的内层语言时跳过外层 fragments，保留 JavaScript/HTML 挂载和原生失败回退。全文替换重新计算容器/HTML 标志。

## 保留的失败与裁定

- 旧 `cell-owner` 突变在当前普通历史路径 2/2 仍通过，已判不可鉴别，不计有效 RED。当前历史通过 `resume→activateSourceCellSelection` 从源选区重建活动格；旧 `resyncCellEdit` 守卫仍服务确认 replay 和过期源检查，未删除产品保护。
- 第一轮 Worker 故障检查以已安装 EXE 搭配 `--app` 启动，实际仍载入 3.6.2 ASAR，整次排除。生命周期工具现在校验实际 app root；最终以三个真实变异 ASAR 重测。
- 首轮 mixed-mounts 负控因巨大对象断言格式化导致 ArrayBuffer 耗尽，不计有效红灯；改为对象身份布尔断言后十类全部完成。
- 首次 >260 原生 Worker 检查缺 ACL 夹具，错误保留；补齐原夹具、绑定身份后完整同命令通过。
- 旧 DSH 复核会话在 r4 请求开始前 TRANSPORT 失败。重新建立独立视觉复核会话，旧失败不计完成。
