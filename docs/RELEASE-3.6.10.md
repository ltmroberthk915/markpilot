# MarkPilot 3.6.10

连续编辑时，光标、选区和未保存内容有更完整的保护。

- 任务列表支持标记后的多个空格，勾选时保留原有排版。
- 表格内选中文字后按 Enter，可以正确进入下一行或追加新行。
- 多行引用公式的字形点击与源码位置一致，继续输入仍在对应字符处。
- 多光标删除完整 emoji、组合字符时，保留全部光标和统一的撤销记录。
- 等待选图或读图时继续编辑，图片仍使用发起操作时的位置；切到阅读模式后取消写入。
- 批量内联图片保留代码示例、公式和文档头信息，支持带空格、百分号及括号的本地图片地址。
- DSH 插件保留失败重载前的编辑状态，可再次重载；关闭标签时保留可用恢复副本，旧读取回执不会覆盖较新的内容。

Windows 桌面版提供 Setup 安装包与便携版。DSH 插件对应版本为 **0.3.5**，使用相同的 3.6.10 编辑核心；更新后重新加载 DSH 宿主即可加载新的客户端。

关闭时无法及时取得全文的恢复副本会标记为旧缓存，恢复提示保留其时间。它不保证包含未收到的最后一次输入。
