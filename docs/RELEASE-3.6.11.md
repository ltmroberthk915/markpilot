# MarkPilot 3.6.11

行内公式从空白输入到完整表达式保持一致的对齐方式。连续排列的公式可以分别点击、编辑和撤销，完整块公式继续居中显示。

- SVG 和百分号编码图片可以保真抽出到 assets；确认、取消和撤销均保留明确的编辑结果。
- 图片读取和下载按实际字节限制大小，超限时停止读取。
- 外部文件冲突后的“保留我的内容”使用当前文件版本确认，保护继续编辑的内容。
- 配套 DSH 插件 0.3.6 支持大文档恢复、关闭时的最新编辑保留，以及带回执的文档同步；同文件的并发保存执行版本校验和原子替换。

Windows 用户可运行 Setup 安装包升级；便携版可解包后直接启动。
