# MarkPilot 3.6.25

在 Windows 桌面版编辑带公式的表格时，把光标移进单元格公式旁，就能一边输入 LaTeX，一边看排版结果。移出后，单元格恢复完整的阅读效果。

- 用工具岛上的脚注按钮插入脚注，在正文引用与脚注定义之间来回跳转。
- 在「更多 → 编辑器设置」里调整主题、字体、页面、阅读外观和快捷键。「更多」菜单随内容收拢。
- 工具岛腾出了原先上下插入空行、撤销和重做占用的位置。撤销和重做仍可用快捷键操作。
