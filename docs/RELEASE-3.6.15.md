# MarkPilot 3.6.15

整理笔记时，可以从公式预览中的一个字符向前拖选，跨到正文、代码或图片，再复制、剪切或撤销。拖动期间按住 Shift 可以继续选取。用方向键或 Ctrl+End 重新定位后，旧的鼠标动作不会抢回光标。

- **跨文件夹整理图文**。桌面版会调整选区内真实图片的相对地址。把有图的段落从讲义剪切到总结笔记，即使两个文件夹里有同名图片，目标笔记仍引用原资源。代码示例里的路径会按原文保留。
- **摘录数学材料**。网页提供的 TeX 优先保留。没有 TeX 注释时，可识别的分式、根式和上下标会转成可编辑的公式。特殊数学记号保留为可读源码。合并表头、图注和数据的行列关系一起保存在笔记里。
- **边输入中文边移动位置**。在输入法完成提交前点击另一段，已选的词留在原处，后续输入交给新位置。使用微软拼音编辑表格时，候选仍在的第一下 Tab 可展开候选。选词后再按 Tab，下一字从下一格开头输入，并可直接在格内保存。
- **阅读正在加载图片的笔记**。图片展开时，编辑器保留正文的阅读位置和正在拖选的文字。直接阅读图片、图片已有明确宽高或滚动位于页顶时，保留相应布局。

Windows 提供安装版和便携版，配套 DSH Markdown 插件版本为 0.3.10。
