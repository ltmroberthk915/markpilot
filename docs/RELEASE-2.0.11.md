# MarkPilot 2.0.11

## 这一版让你得到什么

MarkPilot 把 Markdown 编辑区带进 DeepSeek Harness：公式、代码块、表格、图片、Mermaid 和长文稿都在熟悉的编辑界面里完成，保存、恢复和 AI 引用继续按同一套文档模型工作。

这一版把编辑器内核更新到 CM6 3.6.24，并带来一组阅读与选区改进：

- **阅读位置跟着文件走**：桌面版与插件按文件保存阅读位置；重新打开标签页、整页刷新或切换文件后，都回到上次读到的位置，两个窗口可以独立滚动互不干扰。插件对当前打开的文件保持优先权并持续续期；恢复视口不会移动编辑光标。
- **跨表格拖选更稳**：按住鼠标拖选穿过表格时，表格布局在拖动期间保持稳定，渲染行持续显示选择底色，松开后才更新源码显示；反向拖选、键盘与鼠标配合以及滚轮操作同样稳定。
- **脚注边界更严谨**：文末未闭合的 HTML 注释、引用内代码围栏隐式结束、嵌套引用等边界下，插入脚注前先确认引用与定义能成对落在有效正文中，无法成对时原文保持不变；跳转、返回与导出链接行为一致。
- 长文输入、围栏显形、表格列对齐、公式选区与保存提示等既有改进继续有效。

## 安装

在 DeepSeek Harness 中通过插件市场安装，或使用：

```bash
dsh plugin add dsh-markdown-editor-typora
```

安装后重启宿主。已有文档、会话和设置不会被清除。

## 兼容性

- DeepSeek Harness 0.2.0-rc.2 及以上
- Node.js 20 及以上
- 编辑器内核为 CM6 3.6.24；不修改文档模型、恢复协议或 AI 引用协议

## 已知边界

- 窄窗口会优先保证编辑区和对话都可操作，极窄宽度下可能自动收起挤压布局。
- 存在真实外部改写时，保存仍会按版本守卫拒绝并提示冲突；此时以「重载磁盘版本 / 复制我的内容」处理后再继续。
