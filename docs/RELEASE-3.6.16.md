# MarkPilot 3.6.16

同一份本地 Markdown 笔记可以同时在桌面版和 DSH 插件中编辑。你可以在一个窗口推导公式，在另一个窗口补充说明，两边都能在保存前看到对方的输入。

- **各窗口独立撤销。** 可以分别撤销各自的输入。若两个窗口同时替换了同一段文字，编辑器会提示冲突，保留可以复制或另存的草稿。异常退出后，重新打开笔记时可以查看恢复副本的位置。在共享笔记里剪切一段、撤销再重做后直接保存，不会再被误报为无效编辑，正文照常写盘。
- **保存期间继续输入。** 一次保存还在等待时，可以继续改笔记。桌面版和 DSH 插件会重新同步，把最后的正文写到磁盘。若其他程序改写了原文件，可以从冲突提示中点一次“另存为”，把自己的草稿存到新文件。共享笔记冲突提示里的“保留我的修改”也会真正生效：确认后只写入该笔记的共享正文，若磁盘在确认后又被改动，保存会再次拒绝并保留草稿。
- **重新载入外部修订。** 笔记在别处改过段落顺序后，再按撤销，编辑器会跳过可能把旧字插回另一段的那一步，并说明原因。其余仍然有效的编辑可以继续撤销。
- **在公式预览里反向选字。** 从公式右侧往左拖选时，中途按住 Shift 或轻滚滚轮，选区会继续跟随鼠标。使用全选命令或切换文档后，新的选区优先。
- **编辑学习笔记里的表格。** 从单元格打开浮动菜单，插行或删列会作用于当前行列。按 End 再退格可以改掉最后一个可见字符。粘贴含条件概率、代码竖线和列对齐的 Markdown 表格，保存后仍保留这些内容。
- **在讲义与总结之间剪切图文。** 桌面版会调整选区内图片和本地 Markdown 链接的相对地址，保留讲义片段。连定义一起粘贴时，搬来的同名标签会改用新的名称，目标笔记原有的引用仍指向原文件。
- **首次保存和另存为。** Windows 会在第一次实际编辑后提前准备安全写入组件，缩短按下保存后的等待。另存为可以直接选用尚未创建的多层目录，随笔记迁移的配图也会一起保存。
- **重新加载 DSH 插件。** 插件管理器重新加载 MarkPilot 后，新打开的笔记仍能参加多窗口编辑。连续重新加载同一版本会复用后台写入进程。

Windows 提供安装版和便携版。配套 DSH Markdown 插件版本为 0.3.11。
