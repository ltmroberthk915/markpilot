# MarkPilot 3.6.13 手动编辑交错验证

基线是正式安装的 3.6.12。原始反例、正向对照和独立审阅在 `.mp-verify/manual-3613/`。下表按用户工作流归为十类，相同工作流内有不同的按键或事务根因。

| 操作 | 3.6.12 的表现 | 3.6.13 的判据 |
| --- | --- | --- |
| 另存为失败后回原稿 Ctrl+S | 无关目标失败，原稿保存也被阻断 | 原稿继续保存。原稿本来有冲突时，保留原有恢复操作 |
| 确认覆盖外改后又输入 | 暂存期间开始新编辑，旧稿仍被用于覆盖外部文件 | 提交前核对确认时的修订，外部内容保留，可重新确认最新稿 |
| 目录重定向后重新加载 | 原窗口载入不同物理文件的内容，后续编辑可能写错文件 | 当前文档保持原身份。可以显式打开新文件 |
| 紧凑表格输入末尾反斜杠 | 单元格分隔符变成字面管道，Tab 无法进入原相邻格 | 保留右侧单元格，后续输入仍留在原格 |
| 表格选区、回车与历史 | 删选区后加行需要撤两次，Shift+↓ 在表尾写换行，整行选区 Shift+Enter 会把整行替成 `<br>` | 同格键入是一次可撤销事务，扩选与跨格换行均保护结构 |
| 取消选区格式及多光标编辑 | 整段粗体到文末会取消失败，倒选后可能覆盖后缀。多光标格式会丢主光标 | 保留实际内容、方向、主选区及下一次编辑的撤销边界 |
| 快速确认公式补全 | 同一帧新键入的字符残留，已有命令参数前被插入多余模板 | 用实时命令范围核对实际选中的候选。已有相同命令只移动光标 |
| 粘图尚未完成就重写 | 即使已全选替换文档，旧图片仍会出现在新文字旁，原锚点在文末也会触发 | 原位被覆盖时取消。相邻普通输入或局部边界删除仍正确映射 |
| 两个窗口独立阅读 | 另一窗口的全局偏好令本窗按钮执行相反动作。只读任务框仍会修改源码 | 以窗口当前模式切换。只读任务框不可改写，表格编辑键也检查只读 |
| 右击编辑工具 | 右击 Undo 会撤掉已输入的文字 | 仅主按钮或键盘激活执行命令。右击任务框也保留原文 |

基线的「重新加载」首次探针未确认窗口失焦，改用真实菜单并单独验证加载完成。公式已有参数首次探针等待不存在的预览节点，改用真实键盘进入。两次入口失败均保留，不计作产品反例。中文组字期间点击阅读按钮的正对照在基线也通过。只读表格四键通过真实 CodeMirror 状态和注册命令独立验证。按桌面按钮切换阅读后的对应键到达页面而非编辑器，未将该入口算作四次桌面复现。

独立视觉复核读取 8 张基线和 7 张候选合成截图，并与真实按键和文件收据对照。取消迟到的图片插入可以保住正文。若宿主已经把图片写进 `assets`，该文件会保留，未执行自动删除。表格整行选区用例中的 `focus` 字段专指浮层单元格输入框，不等于整个编辑器失焦。

表格编辑、文件保存及富文本编辑的私有模型分别保留了单项源码负控及恢复结果。阅读状态与右键工具栏使用实际安装版反例、候选版同臂正向结果和独立审阅，未另计补充的源码变异审阅。

首轮整体验证的分栏右键用例发现，「普通选区加粗并立即输入」从一步撤销变成两步。保留了该次失败记录。随后将单独的撤销边界限定为选中含定界符的整段并取消格式，两种操作顺序都有组件断言。首轮和最终构建的同一按键读数见 `history-oracles.json`。
