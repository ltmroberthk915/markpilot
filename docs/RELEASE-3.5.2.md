# MarkPilot 3.5.2

大纲可以直接显示标题中的行内公式；常用公式、引用和代码块有了更直接的快捷键。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+E | 插入行内公式，光标位于两个美元符号之间，两侧不加空格 |
| Ctrl+Shift+M | 插入块公式，光标位于两条公式围栏之间 |
| Ctrl+Shift+Q | 插入或取消引用前缀 |
| Ctrl+Shift+K | 插入代码块，光标位于代码内容行 |

首次升级会迁移这四组键位，导出 HTML 可继续从菜单使用；之后仍可在快捷键设置中自行重绑。表格内支持行内公式，块级操作会提示移到表格外。

大纲公式支持浮层和停靠模式。超长标题与无法解析的公式保留文字显示。
