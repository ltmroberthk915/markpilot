# 3.2.11 公式导航、文字粘贴与查找返回记录

本版本完善引用、嵌套引用、带空白及单行块公式的上下键入口；进入后立即输入落在对应 TeX 正文，撤销重做保留位置。同一公式正文内粘贴文字保留换行和空白；仅 HTML 的 Windows 剪贴板使用实际片段，避免载体换行进入公式。活动表格可以用 Ctrl+F 打开查找，返回单个真实格内选区后立即编辑。正式安装完成，未推送、未发布。

纵向导航复用现有公式正文映射。格内查找复用工具栏命令；查找返回只接管同格、可精确往返 codec 的单一选区，并保留原始 anchor/head。格编辑与正文继续共享 CM6 文档和历史。返回动作在相应焦点事件的一次微任务内完成，没有添加延迟重试；主动 Escape 退出格编辑不会重新打开覆盖层。跨公式粘贴仍保留现有富文本行为。

冻结源码完整 ASAR 为 `0ea5ef6c394dc0b62bf7464b89cb4a4afe8bca07a94028a5f6e343131ac3dcf7`。工具单测 89 项、预检 124 项、冻结源码 16 套共 322 项通过，重建 bundle 与 Worker 的完整 SHA 一致。五个独立根因在一次性副本中完成实际突变失败、逐字节恢复和同臂成功，原 checkout 未变。新派的独立视觉复核实际打开 102 张去重后的完整及局部图，并核对真实键盘、鼠标、组合键、键鼠配合和按下移动抬起的拖拽记录。图数、用例数和各阶段检查存在交叉，不代表覆盖率。

三种 EXE 的实际载荷核对内层 EXE、完整 ASAR、核心文件及版本资源。唯一安装身份在含空格路径完成安装和卸载；便携版、隔离安装、正式实装分别通过 20、50、50 项交付边界检查。正式版本资源为 3.2.11.0 / 3.2.11；原 v2 程序、两个配置目录、注册项及快捷方式目标保留。合成快照含有效的实装失败基线、五组突变及恢复记录，见 [公开快照](verification/quality-3.2.11/snapshot.json) 和 [实装记录](verification/quality-3.2.11/installed.json)。
