# MarkPilot 3.6.12

关闭文件期间继续打字，编辑器会保留后来输入的内容。恢复默认外观可立即更新界面，并保留当前文档、撤销历史和自定义快捷键。

- **保存文件**。已打开文档的目录改指向另一位置时，保存会提示重新选择路径。通过另存为仍可把草稿写到明确选定的位置。
- **导出图片和 PDF**。图片另存为会保护打开的 Markdown 文档。导出期间目标发生变化时，编辑器保留外部文件，提示重新选择。
- **编辑长表格**。插入一行只增加该行所需的源码。短表继续按列对齐，长单元格不会给其他行添加巨量空格。引用表中转义的末尾竖线也能正常保留。
- **DSH 插件 0.3.7**。Markdown 模型工具按当前会话的文件权限和工作目录读写。

Windows 用户可运行 Setup 安装包升级，或使用便携版。
