# MarkPilot 3.6.0

长文档输入与行内公式编辑更稳。在公式行连续输入时，上方加粗段落不再反复闪烁或跳行，输入节奏更均匀；从公式左右两侧进入编辑，都能立即看到源码。剪贴板与表格编辑的日常操作也更可靠。

- 大文档在行内公式附近连续输入时，上方加粗段落保持稳定，不再反复重排。
- 光标在公式右侧按 ←，或直接用鼠标点击公式，都会展开源码；与从左侧进入的体验一致。公式补全菜单不再遮住正在输入的那一行。
- Windows 剪贴板在 Electron 44 下重新实现：复制、剪切、粘贴与撤销重做保持一致，右键剪切后光标仍留在正文，不再跳到菜单。
- 在表格单元格中编辑时，同一张表的其他行保持完整；横向滚动或调整页面缩放后继续输入，表格内容与光标不跳位。
