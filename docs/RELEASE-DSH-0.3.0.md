# dsh-markdown 0.3.0

**MarkPilot CM6 3.6.6 内核的 DeepSeek Harness 侧栏 Markdown 编辑器。**

在 DSH 右侧栏里直接写 Markdown：标题、列表、表格、行内公式、代码块与 Mermaid 即时渲染；选中一段文字，就能把它的 **Markdown 源码**送进当前对话。

## 本次更新

- **内核升级到 MarkPilot 3.6.6**：与桌面版 3.6.6 同一份已验收的编辑引擎。
- **长文档更稳**：带内嵌图片的长文档可以同时看渲染内容与可编辑源码；图片数据不再挤进正文与源码栏，移除前可选择备份到文档同目录的 `assets`。
- **表格编辑**：中文输入法组合输入、转义竖线（`a\|b`）、格式操作与撤销重做都和单元格源码保持一致。
- **公式选区**：选区跨过行内公式边界时保留完整公式，复制与随后继续编辑不再错位。
- **保存与插入的通道修正**：编辑器的变更通知与全文回执现在一定能到达插件侧，自动保存按预期触发；选中文段插入对话的源码与编辑器选区逐字符一致。

## 安装

```sh
dsh plugin --profile web add dsh-markdown-0.3.0.tgz
dsh plugin --profile desktop add dsh-markdown-0.3.0.tgz
```

安装后重启宿主，右侧栏打开任意 `.md` 文件即可编辑。

## 使用

1. 打开右侧栏，按 `Ctrl+P` 选择工作区里的 `.md` 文件。
2. 正常写作；停止输入约 1.5 秒后自动保存，磁盘上的新版本永远不会被旧缓冲覆盖。
3. 选中一段文字 → 点浮出的「插入对话」，或按 `Ctrl/Cmd + Shift + Enter`，Markdown 源码会插入到输入框中。
4. 想撤销这次插入：点回输入框，按 `Ctrl/Cmd + Z`（按设计不抢焦点）。

## 说明

- 引擎随插件离线打包：KaTeX 字体、Markdown Worker、Mermaid 都在本地，不依赖 CDN。
- 主题跟随宿主明暗；首帧即正确配色。
- 桌面版专属的导出、图片选择等依赖 Electron 原生能力的入口在 DSH 中不可用；编辑、公式、表格、Mermaid、保存、选中文段插入不受影响。
- 需要 DSH >= 0.2.0-rc.2（0.2.1-rc.3 实测）。
