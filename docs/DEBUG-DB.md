## 二十八、下划线 `<u>…</u>` 的 WYSIWYG（用户报"下划线没有渲染"）——真因是**开闭标记长度不等**

### 28.1 现象与真因（一次问清，不是猜的）

**用户看到的**：`2020<u>年5月1号是</u>周几` —— 标签原样露在正文里。

**实测到的 DOM**（`probe-u-thirds.cjs`，基线）：
```
'甲词2020<'  +  游离 'u'(8.05px)  +  '>年5月1号是</'  +  游离 'u'  +  '>周几（周五）'
```
⇒ 隐藏区间是 `[a, a+2]` 与 `[b-2, b]` ✓ —— **只隐了 `<u` 与 `u>`** ✗，`>` 与 `</` 留在屏幕上 ✗。

**真因（静态读码即定案 ✓）**：`scanInlineMarks` 里的通用 `scan(re, width, …)` 用**一个** `width` 算两侧隐藏区间 ✗ ——
