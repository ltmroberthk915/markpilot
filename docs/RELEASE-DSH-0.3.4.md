# dsh-markdown-typora 0.3.4

DSH 右侧栏的 Markdown 编辑器，内核升级到 MarkPilot CM6 3.6.9。这一版修好了「点图片右侧会跳进图片源码」和「点最右侧空白光标消失」这两个日常问题。

## 这一版修复

- **点图片右侧，直接在下一行写**：点图片右边的空白（无论离图片多远、是否已经点开过图片），光标都会落到图片下面一行的开头，可以直接继续输入。不会再展开图片源码，也不会再把字写进图片语法。
- **最右侧空白不再丢光标**：点编辑器右侧的空白/装订线，同样按上面规则落点；不会出现「点了之后光标不见、键盘没反应」。
- **标题和列表不被写坏**：下一行是标题、列表或任务项时，光标停在 `#`、`-`、`[ ]` 这些标记之后，继续输入不会破坏结构。
- **点图片本身还是改源码**：点图片仍然显示它的 Markdown 源码、光标落在 `[]` 之间，和以前一样。

## 能做什么

- **即时渲染**：标题、列表、引用、表格、代码块、公式与 Mermaid 图表，写下来就是排版后的样子；光标进块看源码，离开回到渲染。
- **公式点哪改哪**：点渲染预览里的任意符号，源码光标落到生成它的那段 LaTeX。
- **选中文段，送进对话**：选一段 Markdown，点「插入对话」，绝对路径和源码一起落进当前会话的输入框。
- **保存带版本守卫**：磁盘上的新版本不会被旧缓冲覆盖，冲突会明确报错而不是盲写。
- **离线可用**：KaTeX、Mermaid、语法高亮 Worker 全部随包，不依赖网络。

## 安装

在 DSH 里装进当前 profile，装完重启宿主：

```bash
dsh plugin --profile web add dsh-markdown-typora-0.3.4.tgz
dsh plugin --profile desktop add dsh-markdown-typora-0.3.4.tgz
```

从 0.3.3 升级直接覆盖安装即可，文档格式、保存协议和文件地址协议都没有变化。

## 已知限制

- 点图片右侧后，如果下一行是表格、围栏代码、分隔线、块公式或缩进代码，光标会停在图片紧右侧而不是结构行内部（避免写坏结构）；图片在文档最后一行时同样停在图片右侧。
- 分屏源码视图不套用这条落点规则。
- 引用里写绝对 Windows 路径（`![](D:\pics\a.png)`）时图片不显示；用相对路径或 `assets/` 目录即可。
- 引用里的文件名含 `#`、`?`、`%` 时无法按 URL 寻址，图片不显示。
- 文档在操作系统层面只读、被其它程序锁定，或所在磁盘不可写时，保存会失败并显示错误。
