# dsh-markdown-typora 0.3.2

DSH 右侧栏的 Markdown 编辑器，内核是 MarkPilot CM6 3.6.6。这一版补上文档里的本地图片。

## 这一版新增

- **文档里的本地图片会显示**：`![](assets/diagram.png)`、`![](../figures/a.png)` 这类相对路径引用，直接在面板里出图——截图、流程图、粘贴到 `assets/` 的资料图都照常可见。
- **读不出来时仍然说清楚**：文件确实不存在时保留「图片加载失败」加原始路径的占位，不再是一块空白。
- **表格里的图一起修好**：表格单元格内的相对路径图片走同一条通道。

## 能做什么

- **即时渲染**：标题、列表、引用、表格、代码块、公式与 Mermaid 图表，写下来就是排版后的样子；光标进块看源码，离开回到渲染。
- **公式点哪改哪**：点渲染预览里的任意符号，源码光标落到生成它的那段 LaTeX。
- **选中文段，送进对话**：选一段 Markdown，点「插入对话」，源码直接落进当前会话的输入框。
- **保存带版本守卫**：磁盘上的新版本不会被旧缓冲覆盖，冲突会明确报错而不是盲写。
- **离线可用**：KaTeX、Mermaid、语法高亮 Worker 全部随包，不依赖网络。

## 安装

在 DSH 里装进当前 profile：

```bash
dsh plugin --profile web add dsh-markdown-typora-0.3.2.tgz
dsh plugin --profile desktop add dsh-markdown-typora-0.3.2.tgz
```

装完重启宿主，右侧栏打开 Markdown 文件即用。从 0.3.1 升级直接覆盖安装，重启后完成。

## 兼容性

- 文档格式、保存协议与文件地址协议都没有变化，0.3.1 打开的文件照常可用。
- 图片读取走插件自身的只读通道，只服务图片扩展名，且仅在有会话凭据的本机宿主内可达。

## 已知限制

- 引用里写**绝对 Windows 路径**（`![](D:\pics\a.png)`）时图片不显示；用相对路径或 `assets/` 目录即可。
- 引用里的文件名含 `#`、`?`、`%` 时无法按 URL 寻址，图片不显示。
- 插件只支持 DSH 0.2.1-rc 及以上版本的右侧栏契约。
- 大文档（15 万字以上）首次打开需要构建一次语法树，之后的输入与滚动不再受它影响。
