# dsh-markdown-typora 0.3.11

DSH 右侧栏的 Markdown 编辑器，内核升级到 MarkPilot CM6 3.6.16。这是 0.3.4（3.6.9 内核）之后第一次公开发布，把期间积累的多窗口共享编辑、保存稳定性与插件重载修复一起带上。

## 这一版的主要变化

- **同一份笔记，多窗口一起写**：桌面版与 DSH 侧栏可以同时打开同一个 `.md`。未保存的修改实时互通，每个窗口只撤销自己的输入；真正的冲突会明确提示并保留双方草稿，不再盲写覆盖。
- **保存更可靠**：保存等待期间继续输入，最终写入的是最新正文；其他程序改写原文件会明确报冲突；恢复横幅里的「保留我的修改」在共享笔记里也会真正落盘。
- **剪切、撤销、重做后保存**：共享笔记里 Ctrl+X 一段、撤销、重做，再按 Ctrl+S，不再被误报为「无效的协同编辑」，正文正常写盘。
- **反向拖选**：从渲染公式跨过代码、图片拖到上一段时选区跟随指针，顶边自动滚动也能选到目标位置。
- **表格编辑**：单元格插行/删列、End/退格、转义竖线、中文组字与撤销/重做保持同步；粘贴带条件概率、竖线、列对齐与图注的 HTML 表格时内容保留。
- **跨笔记剪切图文**：讲义与总结之间搬动带图段落时，真实图片和本地 Markdown 链接的相对地址会调整；连定义一起搬入时同名标签改名，目标笔记原有引用仍指向原文件。
- **插件管理器重载**：重载插件后新打开的笔记仍能加入共享编辑；连续重载同一版本会复用后台写入进程。重载后共享打开曾出现的 `liveCommitDirectory is not a function` 已修复。
- **共享磁盘事务**：插件的 8 个 host 文件与桌面版使用同一套跨进程写序、版本校验与原子替换实现，字节一致。

## 能做什么

- **即时渲染**：标题、列表、引用、表格、代码块、公式与 Mermaid 图表，写下来就是排版后的样子；光标进块看源码，离开回到渲染。
- **公式点哪改哪**：点渲染预览里的任意符号，源码光标落到生成它的那段 LaTeX。
- **选中文段，送进对话**：选一段 Markdown，点「插入对话」，绝对路径和源码一起落进当前会话的输入框。
- **保存带版本守卫**：磁盘上的新版本不会被旧缓冲覆盖，冲突会明确报错而不是盲写。
- **离线可用**：KaTeX、Mermaid、语法高亮 Worker 全部随包，不依赖网络。

## 安装

在 DSH 里装进当前 profile，装完重启宿主：

```bash
dsh plugin --profile web add dsh-markdown-typora-0.3.11.tgz
dsh plugin --profile desktop add dsh-markdown-typora-0.3.11.tgz
```

从 0.3.4 升级直接覆盖安装即可。

npm 上的 `dsh-markdown-typora@0.3.11` 已发布并成为 latest（`npm install dsh-markdown-typora@0.3.11` 或按包名安装即可）。registry 上的 tarball 与上面 GitHub Release 的 TGZ 逐字节相同（SHA-256 `0169a98d…`，146 个文件）。

## 已知限制

- 分屏源码视图不套用正文的落点与选区扩展规则。
- 引用里写绝对 Windows 路径（`![](D:\pics\a.png)`）时图片不显示；用相对路径或 `assets/` 目录即可。
- 引用里的文件名含 `#`、`?`、`%` 时无法按 URL 寻址，图片不显示。
- 文档在操作系统层面只读、被其它程序锁定，或所在磁盘不可写时，保存会失败并显示错误。
- 物理中文输入法的提交时序依赖宿主窗口前台；自动化环境下这部分由实际键盘/输入法事件单独核验。
