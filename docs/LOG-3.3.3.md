# MarkPilot 3.3.3 内部验证记录

本批围绕笔记编辑、保存及导出的既有功能包络，收敛公式与表格源码布局和图片资源协议。版本基线为实际安装的 3.3.2；预览避让 67.2 CSS px、水平滚动条 3px、预览不跟随滚动/resize 等交互参数保持现有设计。

行内公式使用有界 epoch/region 度量缓存及零宽高度支撑，保留原单行的 ascent/depth 和相邻文字基线。实际源码折行允许正常重排，不增加整段固定空白。表格活动格使用原渲染高度与当前源码自然高度的最大值；原渲染高度不随编辑反馈增长。正文仍为唯一源码/历史拥有者，格内 sizer 和 overlay 只呈现该源码。

单元格点击依据实际 DOM 文字命中并经过已有 cell codec；滚轮对所属正文容器做一次物理位移换算。输入后的 caret reveal 等待 CodeMirror measure/scroll-anchor 补偿完成，再执行一次有 owner/epoch/serial/focus 闸门的 rAF。真正的滚动操作撤销旧 reveal，不持续跟随预览。

独立块公式仅折叠首尾围栏的视觉换行；原始文档 LF 和引用前缀保留。指针与无修饰原生纵向键共用隐藏换行端点规范器，保留原生 visual goalColumn、bidi/assoc 与已有 anchor。完整真实反向链修前 20→30→36→29→26，修后 20→30→36→30→20；下出正文 61，引用/嵌套引用的即时输入、Undo 和真实围栏字符编辑保留。原生体内落点以独立 DOM glyph 几何核对，未恢复旧源列0或单元格宽度比例尺子。

图片识别按源码中的 code/raw HTML/Markdown 原子顺序进行，共用渲染/导出/另存为语法。导出只转义一次并保留代码字面内容，Windows 绝对路径和 file URI 按本地资源打包。跨目录另存为先按不可变源码快照复制相对资源，独占发布、冲突拒绝，最后一次 canonical await 后再次检查 owner；Markdown 提交前复验目标路径和内容。后续 Markdown 提交失败时，已经发布的图片副本保留。

最终验收结果由实际原始收据填入；在完整回归、根因负控、视觉复核、载荷及实装边界完成前，不把准备脚本或代理报告记成通过。

限制：本批为明确支持语法与输入场景的证据，不宣称完整 CommonMark/HTML 实体支持、全操作覆盖率或 OS/真实 IME 验收。CDP trusted 输入、像素观察、独立文件回读、安装身份和 Release 附件校验分别记账。真实文档/profile 和像素保持私有；公开索引仅包含合成 case ID、产物身份和摘要。
