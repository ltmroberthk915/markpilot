# MarkPilot 2.0.7

## 这一版让你得到什么

MarkPilot 把 Markdown 编辑区带进 DeepSeek Harness：公式、代码块、表格、图片、Mermaid 和长文稿都在熟悉的编辑界面里完成，保存、恢复和 AI 引用继续按同一套文档模型工作。

2.0.7 修复了一个会话分栏的可见问题：当会话的标签栏比编辑区晚出现时，编辑工具条可能压在「对话 / 轨迹」上方；第一次拖动中间分隔线之后，分隔线还会停在错误的高度。现在编辑区会在标签栏出现、替换或高度变化后自动贴到它的下沿，短聊天和长历史下都不再出现这个遮挡。拖动过程中不会为每一次鼠标移动重复测量头部，无标签、折叠和窄窗口布局保持原有行为。

## 安装

在 DeepSeek Harness 中通过插件市场安装，或使用：

```bash
dsh plugin add dsh-markdown-editor-typora
```

安装后重启宿主。已有文档、会话和设置不会被清除。

## 兼容性

- DeepSeek Harness 0.2.0-rc.2 及以上
- Node.js 20 及以上
- 编辑器内核仍为 CM6 3.6.19；本次不修改编辑、保存、恢复或 AI 引用协议

## 已知边界

- 窄窗口会优先保证编辑区和对话都可操作，极窄宽度下可能自动收起挤压布局。
- 分栏拖动的 rAF 观测只用于宿主布局稳定性，不代表物理显示器延迟。
