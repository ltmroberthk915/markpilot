# MarkPilot 3.6.13

选中含标记的整段粗体再取消格式，后续输入会替换原本选中的文字，一次撤销即可找回这段文字。用多个光标加粗时，后续扩选仍从原来的主光标开始。

- **写公式**时，候选项按确认瞬间的命令和光标位置补全，已有的花括号参数会保留。
- **改表格**时，可以在紧凑单元格里连续输入反斜杠。选中文字后回车，一次撤销即可恢复文字和行结构。方向键扩选和格内换行也会保护行、列边界。
- **粘贴图片**后仍可继续编辑。插入点附近的普通输入会带着图片位置一起移动。整篇重写或删掉插入点，会取消尚未完成的插入。
- **另存为**遇到错误后，仍能回到原稿保存。确认覆盖外部版本之后继续输入，编辑器会保留外部文件，等待重新确认。原目录被改指向另一个文件时，重新加载会保留当前文档。
- **阅读与鼠标操作**按当前窗口生效。阅读时任务框保持只读，右击工具栏不会执行撤销等编辑动作。

可使用 Windows 安装包升级，或使用便携版。配套 DSH Markdown 插件版本为 0.3.8。
