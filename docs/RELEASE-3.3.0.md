# MarkPilot 3.3.0

保存时间由你决定。默认使用手动保存，按 `Ctrl+S` 写入文件；也可在「设置」中开启自动保存，并选择保存间隔。

- 新打开、拖入或新建的文档使用独立窗口，已有文档和撤销历史继续保留；重复打开同一路径会回到已有窗口。
- 长文档滚动更稳定，末尾留白更紧凑，尾部编辑位置保持可见。
- 带右上角关闭按钮的面板支持 `Esc`，关闭后可继续编辑。
- 公式预览在编辑位置附近避让，额外移动最多 96 个视口像素；附近没有空位时使用覆盖显示。滚动和窗口缩放时不再持续重新定位，输入公式时才刷新布局。
- 图片、公式、代码和 Mermaid 图继续与正文共用源码、选区和撤销历史。

安装版用于安装或升级；便携版无需安装。自动保存默认间隔为 30 秒，可设置为 1 秒至 1 小时。
