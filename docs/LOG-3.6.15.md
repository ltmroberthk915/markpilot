### Windows 表格候选窗复测

表格内完成组字后换格，渲染器已验证第二格得到 `ZKEEP`，保存后读盘一致。首次实装原生测试时，Windows 前台属于 DeepSeek Harness。另开独立合成笔记等待手动激活，180 秒内仍未取得前台，最终采样序号 2759。该次系统按键发送数为 0，隔离进程已正常关闭。原生输入测试单列，不计入上述 34 项。

另作了一次首窗对照，直接用预写好的表格作为唯一启动文档。当时前台仍属于同一外部进程，未发键。随后用户就绪，两个新开的隔离窗口均自然取得 Windows 前台。

- **先选词，再换格。** 真实微软拼音输入 `ni`，按空格选择“你”，按 Tab 换格，在目标格输入 `Z`。磁盘原文得到 `|ab你|ZKEEP|`。撤销只移除了 `Z`，重做后新窗口读回相同内容。主进程及单元格都收到了 Tab，原生按键均已释放。
- **候选仍在时按 Tab。** 系统候选面板展开，编辑器没有收到这次 Tab 的按下事件，原格仍在组字。接着按空格后，前台变为 Edge，测试按守卫停止，未向外部窗口发键。磁盘仍为原始 `|ab|KEEP|`。这里记录的是输入时序与实测的窗口变化；没有证据能判定 Edge 为何获得前台。微软的按键说明列明，Tab 展开必应建议、空格接受当前候选、数字键选择对应候选项。[微软拼音按键说明](https://support.microsoft.com/en-us/windows/hardware/input-devices/microsoft-simplified-chinese-ime)
- **展开候选后按数字选词，再换格。** 前两次启动等待前台到期，都没有发键。最终实测开始时，Windows 已将前台交给隔离窗口，程序请求激活的次数为零。系统输入 `ni` 后按第一次 Tab，候选面板下缘从 1064 像素移到 1512 像素，编辑器仍在原格组字。数字 `1` 仅在原格提交一次“你”。第二次 Tab 的按下事件到达主进程和编辑器，落点进入第二格。输入 `Z` 后得到 `|ab你|ZKEEP|`，保存、撤销、重做通过。在具有新文档 ID 的窗口重开后，全文与磁盘一致。所有按键已释放，两次成功测试均无残余进程。
