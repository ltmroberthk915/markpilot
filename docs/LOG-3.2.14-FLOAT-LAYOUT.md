# CM6 公式编辑预览：横向边界与真实操作验收

本批范围是公式编辑预览的横向布局：长行内公式、块公式、引用、列表、分屏和内容缩放共用同一边界计算。源码、主选区、字形映射和历史仍由 CM6 管理。特殊区域的完整统一方案见 `LOG-3.2.13-REGION-ARCHITECTURE.md`。

## 已确认的缺陷与处理

| 触发 | 3.2.13 行为 | 处理 |
|---|---|---|
| 引用中长行内公式自然折行 | 预览从源码起点的横坐标展开，右缘越过文字列；一个 100% 样本越界约 24px | 先限制预览外框宽度，再把横坐标钳制到有效文字列 |
| 200% 缩放、窄视口、多层引用 | 预览宽度约 1378px，超出约 513px 的文字列，并撑大编辑器横向滚动范围 | 保持公式字号，超宽内容在预览框内横向滚动 |
| 引用中的块公式 | 居中参照引用背景盒；90% 上限未包含 padding/border | 行内和块公式都使用源行内侧文字列、正文内侧列与 scroller 可见 client 盒的交集；宽度口径为 border-box |
| 编辑期间缩窄视口 | 尺寸变化的调度被文档/选区变化条件挡住，旧位置和上限继续保留 | 几何和 viewport 更新独立触发同一测量周期 |
| 列表或分屏中拖动预览滚动条 | 在移除条带豁免的实际反例中，滚动成功但源码 head 被改动 | 仅真实滚动条条带停止事件冒泡，保留浏览器滚动；有效字形点击仍使用原映射 |

纯函数 `floating-layout.js` 负责横向约束和视口到局部坐标的转换。消费者保留自己的锚点、纵向策略和生命周期。公式预览通过 `EditorView.requestMeasure({read,write,key})` 合并测量：读阶段集中读取盒几何，写阶段只更新样式。没有新增焦点重试、滚动重试、影子文档或历史事务。

`coordsAtPos` 与 DOMRect 都是视口 CSS 像素。转换时按实际 offsetParent 的 CSS zoom、边框和滚动量计算；引用行也可能成为 offsetParent，不能固定假设为 scroller。源码末尾下方 6 个视口 CSS 像素的纵向锚点保留。

## 可复用测试工具

`tools/quality/float-layout-workflows.cjs` 默认生成八组通用样本：长引用、双层引用、块公式、列表、分式、双行矩阵、分屏和短公式对照。通过真实 Chromium 输入完成：

- 普通字形点击 → 立即输入 → Undo → Redo 后立即输入；源码落点由夹具中的明确字母独立计算。
- 原生滚动条按下、连续移动、抬起 → 保留选区及输入所有者 → 立即输入并撤销。
- 框内横向滚轮读取公式尾部并返回开头；记录各阶段的完整几何，避免把编辑前宽度用于编辑后滚动上限。
- 预览字形点击与 Shift 点击、正文滚动往返、视口缩窄再放宽。
- 分式和矩阵的字形纵向边界、原字号、外框边界及源码末尾锚点。

每个输出目录保留执行时探针副本、夹具、真实事件记录、完整截图、光标附近放大图和 SHA256。红色标记来自 CM6 测得的光标坐标，不代表系统合成层的物理闪烁光标。CDP 视口模拟不等于 Windows 原生改窗。

几何取样先调用公开的 `coordsAtPos` 完成待处理测量，并预读所有源码锚点，然后才读取 DOMRect、文字列和字形。`coordsAtPos` 可能同步触发 CM6 的测量周期；如果先读外框再读锚点，一个返回对象可能混入两个布局时刻。横向滚轮还记录事件自身的预览 client 盒，并断言实际落点在内容区。

```powershell
npm ci --prefix tools/quality
node tools/quality/float-layout-workflows.cjs --exe "C:/path/to/MarkPilot.exe" --expected-sha256 <完整SHA256> --out .mp-verify/float-check
```

输出目录必须为空。`MP_QUALITY_CASES` 可筛选用例。可选 `--sample` 接受本机片段副本；当前附加臂要求首个目标行内公式以普通字母 `e` 开头。任意语料特征抽样与范围绑定使用另一个 `corpus-math-workflows.cjs`。片段、语料、截图、profile 和安装包不进入测试工具提交。

## 已知边界

预览仍采用浮层，可能遮住后续引用文字或段落；该纵向呈现问题属于统一区域方案，本批没有解决。补全菜单的左侧边界仅有静态风险候选，未取得新实际反例，因此未改动其产品逻辑。缺失锚点时的离屏生命周期策略没有扩展；已测试的是正常滚动离开再返回。

本批不把通用样本通过外推为所有公式、所有主题、Windows 真实 IME 或全部原生窗口行为已验证，也不声称行业最优性能。
