# MarkPilot 3.5.1

3.5.1 着重改善表格编辑、撤销历史、大纲跳转与长文源码分屏的使用体验。

- 表格中的文字移动、继续输入与撤销重做更连贯，源文本、目标单元格和选中状态保持一致。
- 大纲跳转随页面缩放对齐；80%、100%、125% 三档完成了定位验证。
- 组字过程与保存协调处理，提交组字内容后再保存完整文本。
- 源码分屏采用增量同步，避免在十万行文档里每次输入都重建整篇源码视图。
- 加强阅读模式、源码面板与编辑操作之间的只读边界，以及菜单、选区和文档历史的状态隔离。

超长文档开启源码分屏、连续组字时，部分输入顺序仍有额外性能开销。
