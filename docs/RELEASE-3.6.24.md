# MarkPilot 3.6.24

面向 Windows 桌面版的更新，把跨窗口阅读位置、表格拖选稳定性和 PDF 导出内存策略补齐，脚注边界更严谨。

- **阅读位置跟着文件走**：桌面版与 DSH 插件按文件保存阅读位置；重新打开标签页、整页刷新或切换文件后，都回到上次读到的位置，两个窗口可以独立滚动互不干扰。插件对当前打开的文件保持优先权并持续续期；恢复视口不会移动编辑光标。
- **跨表格拖选更稳**：按住鼠标拖选穿过表格时，表格布局在拖动期间保持稳定，渲染行持续显示选择底色，松开后才更新源码显示；反向拖选以及不同缩放档位下的键盘、鼠标与滚轮操作同样稳定。
- **PDF 导出内存策略**：导出前与导出过程中检查可用内存余量，不足时在创建打印进程前中止，并区分物理内存、系统提交余量与打印进程占用给出提示；运行中连续两次低于安全水位才会中止，打印进程受独立内存上限保护。低内存状态下普通文档仍可正常导出。
- **脚注边界更严谨**：文末未闭合的 HTML 注释、引用内代码围栏隐式结束、嵌套引用等边界下，插入脚注前先确认引用与定义能成对落在有效正文中，无法成对时原文保持不变；跳转、返回与导出链接行为一致，导出保留脚注链接与文末列表。
- **既有能力保持不变**：文档、主题、字体、自动保存、最近文件、表格与 Mermaid 等设置继续保留；编辑、保存、恢复与 AI 引用协议不因本次更新改变。

Windows 提供安装版和便携版。也可以通过 npm 获取桌面分发包：

```bash
npm install -g markpilot-cm6
markpilot --download
```

配套 DSH Markdown 插件版本为 2.0.11，桌面版与插件共用同一份编辑内核。
