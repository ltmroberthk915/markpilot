# MarkPilot 3.6.8

本次更新修复两个日常编辑问题，继续保留即时渲染、公式、表格与源码双栏体验。

- **行内公式与中文输入法**：在公式右侧继续输入中文时，不再同时显示渲染公式和公式源码，也不会出现双光标、重影或组字后源码未收起的情况。
- **复制后的定位**：复制文本后若 Ctrl 仍按住并点击目标行，不会再误加第二个光标；随后粘贴和输入只作用于目标位置。需要多光标时，松开后重新按 Ctrl 点击，或使用原有快捷键即可。

适用于 Windows x64。下载并运行 `markpilot-Setup-3.6.8.exe` 安装；无需安装时，可使用 `markpilot-3.6.8-portable.exe`。
