# MarkPilot 3.3.2

这次更新改善查找、替换和分屏编辑的连续操作。

- 查找框输入新关键词后，首次按 Enter 就使用最新内容；替换框也会立即使用当前输入。
- 在分屏源码中右键时，正文选区保持不变。可以对已选文字加粗，再直接继续输入，撤销和重做仍使用该文档的历史。
- 在查找框等面板中右键时，不会弹出正文格式菜单或误改笔记。

保留手动保存、可设置间隔的自动保存和多文档独立窗口。公式预览继续按实际高度显示，采用柔和边界，支持关闭避让，横向滚动条为 3px。
