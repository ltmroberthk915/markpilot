# CM6 架构审查与性能改进顺序

当前最有价值的方向是保留 CM6 单一文档和历史，把不同编辑表面的交接集中起来，再优化实测热路径。现有数据不足以证明“行业性能最优”；也没有与 Typora 在同机、同文件、同操作下的对照数据。

## 现有契约

| 对象 | 权威状态 | 派生状态及限制 |
| --- | --- | --- |
| Markdown 与文档历史 | CM EditorState | 新文档创建新状态；同文件刷新以最小变化映射历史 |
| 表格格编辑 | CM 源范围与文档历史 | body 上的 contenteditable 暂存预编辑文字与 DOM 选区，在输入和命令边界回写；不得另建文档撤销栈 |
| 公式交互 | 当前数学范围与源码坐标映射 | 渲染字形和浮层是投影；鼠标拖选已经形成的范围不能被单击落位覆盖 |
| Worker 解析 | 对应 revision 的解析镜像 | 回包必须核对 Worker 实例、revision 与 Text 身份；旧树不承担保存或当前输入的权威状态 |
| 保存 | document-store 的文档身份、修订和磁盘快照 | 异步保存完成不能提交到已经切换的文档；外部修改与并发写入保留冲突边界 |

DOM 光标先移动而 CM 暂时未同步，在格编辑中可以是正常状态。判据应放在真正的输入、提交和历史命令边界，不能用每次方向键后的强制 dispatch 消除合法延迟。

## 先集中命令归属

正文、格覆盖层、搜索框、工具栏和桌面菜单原先有分散入口。原生菜单的 Undo/Redo 已在 3.2.11 装机产物上确认没有消费者，六个实际 MenuItem 回调臂失败。仅改 Electron role 的样机只能使正文和格 Undo 生效，Redo 未产生可信历史事件；搜索框的原生历史正常。

修订方案让菜单通过一个引擎历史入口识别真实焦点归属：正文和活动格复用 CM 历史，格编辑复用既有 history 回填；其他输入控件交给原生历史。无可撤销内容也属于已经处理的命令，不能落到别人的历史。待图取消复用已有 effect，不增加历史栈或固定延时。

后续逐个迁移已经验证的动作，集中来源、文档身份、编辑表面和本次指针目标。明确执行、拒绝、不处理三种结果。工具栏显式返回正文与搜索框保留自身焦点是不同契约，不能统一强制 focus。

## 再集中投影编辑会话

将格编辑的读取选区、提交、历史回填和退休操作封装为一套会话接口，再考虑让 ViewPlugin 拥有覆盖层 DOM 生命周期。StateField 只保存可映射的源归属。保留预编辑与提交的区别、跨格历史恢复、层级表选择和活动格之间的独立性。

先做行为等价提取，每次迁移一个入口；不同时重写导航、解析和保存。使用已有竖线转义、emoji、中文输入、跨格历史、搜索返回和换文件立即输入的实际链验证。系统输入法候选与可信组字提交尚没有完整证据，不能从普通 Unicode 输入通过外推。

## 最后优化已定位的同步扫描

现有数学、行样式、表格和行内标记字段已有普通编辑快路径。触及数学范围或表格结构时仍可能同步全文扫描，Worker 的异步解析不能消除这些主线程成本。

先分解输入准备、各扫描器、语法树发布和布局耗时。优先研究既有公式内部不改定界符、表格单格不改结构时的局部失效，其余范围用 ChangeSet 映射；引用、围栏、HTML 容器和跨块变化保留权威完整扫描。沿现有结构索引扩展，避免再加互不一致的 inside-math/inside-code 标志。

只有分项数据支持时，才在 Worker 内使用对应 revision 链的 TreeFragment。新文档和重置清除旧碎片；实例、revision、Text 身份检查保持不变。优化正确性以当前权威扫描器逐项对照，不能以“少扫描几行”作为正确证明。

## 测量与验收

3.2.12 同一 ASAR 的七条性能臂稳态输入到帧 p95 为 20–36ms，满足该套的 50ms 预算。但数学夹具在文末空白处输入，不代表公式内部或活动格的性能。555008 UTF-16 字符引用 Enter 的独立解析延迟臂首笔 189ms、稳态 p50 / p95 为 125 / 164ms，该臂没有 50ms 预算，不能混为同一个预算的失败或通过。稳态仍偏慢，不能只归因于首次加载。

性能改进需比较同机、同运行产物身份、同文件和真实编辑位置，分别记录首笔与稳态 p50/p95/p99、同步扫描行数、语法 fallback、布局时间、Worker ready 延迟和内存。先测公式内部、活动格、引用 Enter 三类热路径，再按证据决定优先级。

交互验收使用操作链，而非孤立按钮：定位或选中、输入或复制剪切、撤销重做、继续输入、保存重开。核心修改冻结后执行一次完整回归；安装边界重点复验本批目标。实际突变在一次性副本中撤掉对应机制，确认原失败和相邻正对照，再逐字节恢复并重测。

截图、被动事件、完整源码、焦点、方向性选区和磁盘字节分别核对。MenuItem 回调不等于物理操作系统点击；CDP 输入不等于系统输入法候选操作。未确认入口单列，不能加入通过数。
