# MarkPilot 2.0.9

## 这一版让你得到什么

MarkPilot 把 Markdown 编辑区带进 DeepSeek Harness：公式、代码块、表格、图片、Mermaid 和长文稿都在熟悉的编辑界面里完成，保存、恢复和 AI 引用继续按同一套文档模型工作。

这一版把编辑器内核更新到 CM6 3.6.20，并带来一组写作与保存改进：

- **AI 审阅中的保存不再被误报为外部改写**：在「AI 修改待确认」状态下保存后，自己这次保存的通知延迟到达时，仍可「保留并保存」继续确认，审阅状态不会被替换成冲突横幅；真正的外部改写仍然拒绝覆盖，草稿与审阅状态保持原样。
- **协同存储异常时的提示更明确**：协同存储暂不可用时，会区分「本次未写入」与「保存结果未确认」，修改保留在当前窗口，可直接重试或另存。
- **代码围栏两侧一起显形**：光标进入围栏块、或选区触及围栏块时，开头与结尾的围栏符同时显示；围栏内的原生选区在阅读态保持可见。
- **脚注可以顺畅地写和跳**：正文插入脚注引用、文末生成定义；上标与定义之间双向跳转，同一条脚注被多处引用也不会串位，导出的 HTML 保留脚注链接与文末列表。
- **表格列对齐**：表格浮动条提供左、中、右三档对齐按钮，图标与当前列对齐状态同步。
- **公式选区更稳**：非空选区覆盖显示公式边界时公式保持渲染，不再在边界来回塌缩；反向选择与多范围选择沿用同一套落点规则。
- **长文输入更跟手、引用内换行保持引用**等内核修复随本版一并带入。

## 安装

在 DeepSeek Harness 中通过插件市场安装，或使用：

```bash
dsh plugin add dsh-markdown-editor-typora
```

安装后重启宿主。已有文档、会话和设置不会被清除。

## 兼容性

- DeepSeek Harness 0.2.0-rc.2 及以上
- Node.js 20 及以上
- 编辑器内核为 CM6 3.6.20；不修改文档模型、恢复协议或 AI 引用协议

## 已知边界

- 窄窗口会优先保证编辑区和对话都可操作，极窄宽度下可能自动收起挤压布局。
- 存在真实外部改写时，保存仍会按版本守卫拒绝并提示冲突；此时以「重载磁盘版本 / 复制我的内容」处理后再继续。
