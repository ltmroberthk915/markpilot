# 3.2.8：截图粘贴、图片操作与交付校验

2026-10-12。继承 [3.2.7](LOG-3.2.7.md) 的编辑上下文、Worker 和数据保存改动。本版本处理实际图片源、渲染投影、图片插入事务与菜单操作。源码及可重复工具准备在本地，没有推送、发布或升级远程主机。

## 行为与实现

已有文件默认将剪贴板图片存入该文档旁的 `assets/`，只在成功写入且字节数一致后插入真实相对地址；未保存文档或写入失败保留内联图，并说明原因。路径解析按文档目录编码每一段，保留中文、空格、`#`、`%`、括号及带点的目录；复制和另存支持相对路径、file URL、data URI 与 HTTP。PNG/JPEG 可直接转系统位图，WebP 经所属渲染器的有界解码转 PNG；另存保留原格式字节。

CM6 图片扫描把 `![`、`<img` 所在的变化邻域也纳入结构判断，覆盖普通字符删除后才形成图片的情况。光标在短图片源码严格内部时可编辑地址，两端保持图片渲染。Widget 相等性检查完整源地址及已解析地址，避免同长度不同图或切目录后复用旧 DOM。本地和内联图片立即加载，远程图片保持惰性加载。

异步插入先在 StateField 预留位置，由真实 CM6 变化映射。编辑选中区域、文档重载、撤销/重做取消请求；继续打字、移动光标不被迟到结果覆盖。同一点的多次粘贴按请求顺序插入，替换选区仅一次，每张图可独立撤销。图片转换和对话框使用文档身份与 Text 快照，异步返回前重新检查，拒绝把旧区间写入新文本。

粘贴前只预解码本次图片的最终地址，使用与 Widget 同一个解析回调；十秒上限、失败仍提交真实图片源、所有出口清理定时器及临时引用，随后再次核对文档归属。此举通过快速 Ctrl+End→Ctrl+V 的长文档正反臂；没有新增定时补滚、第二次选区事务或全局滚动循环。HTML `decode()` 不保证未来另一个 img 同步有最终高度，结论以实际产物的限定夹具为准。[HTML Standard](https://html.spec.whatwg.org/multipage/embedded-content.html#dom-img-decode)

缩放预设为 25/50/75/100%，100% 以原尺寸适配当前正文宽度为基准。重复选择幂等，选择顺序不累乘；缩放移除旧固定高度，保持比例。自定义范围 5～400%，小图可放大，超宽图受正文宽度限制。菜单通过实际点击 Widget 的 CM6 位置取得范围，正确处理第二张图、带引号的 `>`、配平括号 URL 及支持的 alt/title/width/height/align 属性。

文件创建先写完独占临时文件，再用 COPYFILE_EXCL 提交，晚到的外部同名文件触发重新分配名称；同长度不代表同内容，复用须哈希及字节均相同。此过程保证不覆盖已有资产，不宣称最终复制具有断电原子性。

启动握手只读主会话的完整元信息。引擎尚未就绪时缓存最后一份 authoritative 文档，不从启动空白状态反向重置读取中的文档；显式新建严格检查当前 documentId。删除会晚到覆盖新文档的重复 currentDoc 拉取。

## 测试策略与证据

测试分开核对状态协议、真实键鼠与窗口、文件字节与系统剪贴板像素、可见几何与截图、回退负控、三种安装载荷。用例数存在重叠，不能相加当成功能数或覆盖率。默认图片写入的人为五秒延迟只服务竞争用例，快速长文粘贴另以零延迟测量。

3.2.4 已安装程序的合成图片基线 6 条中 5 条失败：Windows 位图能落盘但显示原 Markdown，四个缩放档位没有生效，复制/另存失败。对照图片在独立 img 中可解码，排除了夹具坏图。源 Markdown 原件只读；其 9 MB 副本的既有图片、即时新图、真实保存/重载及复制/另存均通过，原文档和三个资产 SHA 不变。含私人内容的取证截图查看后删除，不进入公开证据。

真实输入使用 CDP 键鼠，剪贴板装载前后由独立 STA 进程回读核对。PNG/WebP 逐像素比较，JPEG 记录平均字节误差及显式容限。所有测试自取 app-slot，串行运行，无并行构建干扰 GUI。选区/焦点/scrollTop 读数与全图及 2 倍局部图相互核对；红线为按浏览器光标矩形绘制的标记，不冒充捕获原生 caret。

最终 10 万行普通输入的稳态 P95 为 19ms，退格为 18ms；55 万字符引用结构回车为 P50 130ms、P95 180ms，后者保留为性能边界。打包与实装不重复同一份代码的全部七套测试：三个载荷逐个拆解核对 EXE/ASAR/七核心文件，便携与隔离安装各复查 26 个关键回归及真实图片粘贴，正常安装另复查零延迟长文粘贴、四档大小及复制/另存。这些是交付边界复测，不能称安装后的完整 42 场景又跑一遍。

负控只操作带质量工具所有者标记的非 Git 源码副本；on/off 幂等、唯一锚点、修改前完整字节及 SHA、恢复后源与 bundle/asar SHA 全量核对。每类以同一真实 GUI 用例完成红→绿。关闭预解码的视口负控零人为延迟；关闭 COPYFILE_EXCL 的负控要求外部生产者确实赢得路径。

目前仅验证本机 Windows、指定夹具及现有 CM6 方言。原生输入法候选窗口、系统截图工具 UI、远程主机配置及真实 OS 文件选择框没有被这些用例覆盖。纯滚轮但不改变选区时，尚在等待的插入仍可能按原生 commit 的滚动意图回到插入点；本版本没有新增完成后的补滚。图片重写只承诺支持的属性，未知 style/class/data-* 不承诺任意保真。此前长文结构键的同步解析成本仍待优化，没有相同环境的 Typora 对照，不作行业最优结论。
