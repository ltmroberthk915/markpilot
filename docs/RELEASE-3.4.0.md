# MarkPilot 3.4.0

3.4.0 是桌面编辑器的新稳定基线，重点改善打开、编辑、保存和导出的可靠性。

- 打开文件期间继续输入，当前草稿会得到保留；打开失败时，正文、选区和撤销历史一起恢复。
- 文件路径与实际读取的文档保持一致，多个窗口与另存为继续独立管理各自的修改。
- 大表格打开更顺畅，表格菜单和快捷键始终跟随各自的操作目标。
- 图文复制粘贴保留完整 Markdown；搜索框等输入控件中的粘贴不会改动正文，图片下载期间切换文件也能保留当前编辑。
- Windows 保存保留文件权限与附加数据流，遇到磁盘外改会提示处理；组字未完成时关闭窗口会保留编辑面。
- 正常长文件名可直接保存和另存为，连续另存为后仍可继续编辑与保存。
- 单文件 HTML 可带走本地图片；文件夹导出复用相同图片，中文、空格和特殊字符图片路径均可保留，生成新归档时保留已有文件。
- 多张 Mermaid 图表随文档导出，内联图片可直接生成 PDF。
- 导入 CSS 后保存在 MarkPilot 的主题目录中。主题与字体分开设置，正文、各级标题和斜体可分别选择字体；主题明确固定字体时会说明限制。

在“更多”中可直接找到主题、字体、页面、界面和阅读选项。设置面板按用途分组，并保留当前修改位置。

运行 Windows 安装包可升级桌面版，也可使用便携版。升级前保存文档并退出正在运行的 MarkPilot。
