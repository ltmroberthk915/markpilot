# MarkPilot 3.5.4 验证记录

## 范围与实现

基线为 3.5.3，提交 `85534047e1f835bb86376f8aa28ac00b07229bd2`。本批目标为正文右键菜单提供“纯文本粘贴 Ctrl+Shift+V”，以及关闭 SPLIT-S3 源码分屏菜单坐标归属缺陷。S4 保持冻结，旧 56 行台账不等于 56 个未修缺陷。

`extras.js` 的正文菜单复用既有原生 paste 和转换旁路；普通粘贴继续转换 HTML/TSV，新增菜单入口按字面插入。请求绑定 view、document、selection，消费、失败、新指针/键盘意图、失焦或两秒到期时退役。仅等待该请求期间挂载临时监听，不在普通按键热路径增加分支。已经发送的原生粘贴无法撤回，两秒后的迟到事件按普通转换处理；旧快捷键 `plainPasteOnce` 布尔寿命未在本批修改。

源码分屏右键使用被点击 source view 的坐标映射；未知、越界或抛错时不猜测主窗目标。正文格式命令继续作用于原主选区，表格命令锚定点击的源码行。表格、图片专用菜单范围保持既有设计。

## 性能观察及裁定边界

原短预热 ABBA/反序比较的富格式 10k 行尾部存在较高延迟，原始结果全部保留。当前候选八次平衡运行、每侧 240 个样本，beforeinput 至 input 后 microtask 的 p50 为 10.0→10.5 ms，p95 为 16.8→19.0 ms；下一 rAF 的 p95 为 18.2→20.4 ms。此差异不改称噪声或全局性能通过。

限定因果诊断先用相同旧 ASAR 的 A/A 校准，再做 A/B CPU 采样。预热 160 键后，A1/A2 的 p95 在 11.6–11.9 ms，候选两次为 11.6、11.2 ms；采样诊断不与不采样结果合并。静态未发现普通输入 `x` 的新增处理，但闭包布局、JIT、GC 的影响不能据静态分析定量。

随后一次不带采样器的对应 ABBA 确认，预热 160 键、每侧 240 样本：普通 100k 行同步 p50 为 1.1→1.1 ms、p95 为 1.4→1.3 ms；富格式 10k 行同步 p50 为 10.6→10.6 ms、p95 为 17.2→16.8 ms，下一 rAF p95 为 19.7→19.0 ms。该组在选定充分预热工作负载中未见同步耗时退化。早期短预热差异保留为非阻断观察，不作所有启动阶段或所有文档零退化的断言；这些计时也不等同于完整 keydown 耗时或绘制完成延迟。

## 保留的失败与限制

最早剪贴板探针遗漏现有 intent token，宿主拒绝装弹，该轮不作产品结论；修正后重新装弹、独立进程回读、真实输入、再次回读并恢复。空剪贴板在已有选区时原生粘贴会删除选区，最早“不应改变正文”的预期错误；改用真实方向键折叠光标验证空请求的后续隔离。几何限定器漏公式行及菜单关闭后读取 boundingBox 的两处探针错误均保留原始失败，修正后重验相关臂。

本批剪贴板在远端测试 session 0 具备读取资格并完成备份/恢复，不核销历史交互 session 1 的 OpenClipboard access5 缺口。旧混合/三星号/行内代码行解析和旧原生 HTML 机制覆盖缺口仍保留。S4 不变。

私有证据根为 `.mp-verify/v340/edit-r2/resume-gpt/resume-20261023/split-menu/`，包含原始失败、独立方案/对抗、当前冻结清单、功能收据、两项负控及恢复、视觉实际读图证明、性能全部比较、安装及交付对账。用户内容、profile、截图、恢复备份和私有收据不进入仓库或 Release。
