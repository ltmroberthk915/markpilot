# MarkPilot 3.6.1

从后往前拖拽选中行内公式时，显示与从前往后一致：只有光标所在公式展开源码并显示一个预览框，已经划过的公式保持渲染和选中底色；松开鼠标后不再残留多余的预览框，长选区更清爽。其他编辑行为不变。

- 从后往前与从前往后拖拽，行内公式的源码/渲染状态保持一致。
- 鼠标停在公式右边界仍可直接编辑；键盘停在同一位置仍保持渲染。
- 拖拽结束后只保留当前光标所在公式的编辑预览，已划过的公式恢复渲染。
