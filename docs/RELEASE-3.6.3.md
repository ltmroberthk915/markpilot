# MarkPilot 3.6.3

内嵌图片在正文中正常呈现；展开源码或查看双栏源码时，图片数据显示为简短的图片标记。图片说明、尺寸和普通图片地址仍可编辑，内嵌数据受到保护，文档保存时保留完整图片内容。

删除或替换内嵌图片时，可以选择“备份后继续”“直接继续”或“取消”。备份写入文档同目录的 `assets` 图片文件夹；相同图片可复用已有备份，同名但内容不同的文件会另取名称。备份失败时保留原图。尚未保存的文档需要先保存，才能使用同目录备份。

双栏阅读支持含大量内嵌图片的长文档，放大显示和在文末打开源码栏时保持内容可见。表格编辑减少无关行的重新创建，无选区剪切保持文档和剪贴板原样。

大文档中的连续输入、换行和表格编辑更流畅。PDF 导出兼容 Windows 临时目录的长、短路径表示。

关闭 MarkPilot 后运行 Windows 安装包完成升级。已有 Markdown 文档继续使用原格式。
