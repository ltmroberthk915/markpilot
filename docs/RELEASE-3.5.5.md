# MarkPilot 3.5.5

表格阅读与选字更顺手。短内容列会在空间允许时减少不必要的换行，页面缩放后继续按当前空间调整；按下单元格后可以直接拖选，无需重复点击。

- 支持连续正向、反向拖选，以及拖选后用 Shift 配合方向键扩展选区。
- 加粗、斜体与嵌套强调的源码显示和编辑更一致，代码与公式中的符号保持原意。
- 富文本和多张图片粘贴更稳定，多选区、图片上下文和撤销重做配合更可靠。
- 多窗口间的快捷键及偏好设置及时同步。
- 切换阅读模式、调整页面布局时，更稳定地保留阅读位置。

- 页面缩放后，源码分屏与正文、大纲的定位对应更稳定，长行滚动也能保留行内位置。
- 从单元格点击正文可继续编辑；点击当前行旁的空白处时，表格保持完整。
- 修复较深安装目录中的保存失败；取消退出后可继续保存，关闭窗口时会等待已经开始的保存完成。
