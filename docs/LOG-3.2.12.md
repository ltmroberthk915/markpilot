## 性能及结论边界

七条固定性能臂的稳态输入到帧 p95 为 20–36 ms，满足该套 50 ms 预算；这些输入位置是文末空白，不能代表活动公式或单元格。555008 UTF-16 字符引用 Enter 的独立臂首笔为 189 ms，稳态 p50 / p95 为 125 / 164 ms，该臂没有 50 ms 预算。架构改进方向见 [架构记录](LOG-3.2.12-ARCHITECTURE.md)。没有同机 Typora 对照，不能宣称行业性能最优。

实际 MenuItem 回调不等于物理系统菜单点击；可信 Chromium 输入不等于系统输入法候选输入。更广的失焦、屏外滚动返回和组合操作仍需逐项探索。

完整回归后继续探索，发现两条新增实际失败链：活动单元格点击源码窗格后立即输入落到表后；反向格内选区经真实“更多 → 重新加载”后立即输入丢失编辑焦点。它们没有加入上述通过数。前者进入下一批修复，后者保留实际失败证据及未完成状态。
