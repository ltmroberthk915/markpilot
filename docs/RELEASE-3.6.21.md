# MarkPilot 3.6.21

面向 Windows 桌面版的更新，把围栏、脚注、表格列对齐和公式选区这几处日常写作细节补齐，并让协同存储异常时的保存提示更明确。

- **代码围栏两侧一起显形**：光标进入围栏块、或选区触及围栏块时，开头与结尾的围栏符会同时显示；围栏内的原生选区在阅读态也保持可见，不再出现只看见一端围栏的情况。
- **脚注可以顺畅地写和跳**：支持在正文插入脚注引用、在文末生成定义，点击上标跳到对应定义、从定义回到本次触发的那一处引用；同一条脚注被多处引用也不会串位。导出的 HTML/PDF 保留脚注链接与文末列表。
- **表格列对齐更直观**：表格浮动条提供左、中、右三档对齐按钮，图标与当前列对齐状态同步；单元格编辑、键盘操作和撤销行为保持原有语义。
- **公式选区更稳**：当非空选区覆盖显示公式的边界时，公式保持渲染而不是在边界来回塌缩；反向选择和多范围选择沿用同一套落点规则。
- **保存异常提示更精确**：协同存储暂不可用时，会区分“本次尚未写入”和“写入结果未确认”，并保留当前窗口中的修改，方便重试或另存。
- **既有能力保持不变**：文档、主题、字体、自动保存、最近文件、表格与 Mermaid 等设置继续保留；编辑、保存、恢复与 AI 引用协议不因本次更新改变。

Windows 提供安装版和便携版。也可以通过 npm 获取桌面分发包：

```bash
npm install -g markpilot-cm6
markpilot --download
```

配套 DSH Markdown 插件版本为 2.0.9，桌面版与插件共用同一份编辑内核。
