# MarkPilot 3.3.0 内部验证记录

保存策略由宿主与渲染层共用 `shell/save-policy.js`。默认手动保存，自动保存可显式启用，默认间隔 30 秒，范围 1 秒至 1 小时。计时按周期触发，持续输入不会无限延期；关闭后不再发起新的自动写入。

常规打开、拖入和新建保留已有文档及历史，已有路径复用当前窗口；真正干净的空白窗口允许复用。显式 `openPath` 保留调用者文档替换协议。设置面板关闭验证文档 epoch 和实际可见焦点，旧隐藏 cell 不会被恢复。水平分隔线使用中性标记，普通尾部为 48 CSS px，滚动容器保留 24 CSS px。

公式浮层相对原覆盖锚点最多避让 96 个视口 CSS px；找不到附近空位则覆盖显示。滚动、窗口 resize、仅光标和无关 overlay 事件不再请求重定位。定位按视图/lease 合并，宽度与最终高度分阶段测量；过期结果和销毁节点被丢弃。障碍收集限制在附近已挂载区域，并在同一读取阶段复用祖先缩放计算。

## 性能边界

浮层计数样本中：普通输入（浮层不存在）、光标移动、滚动、resize 的新增定位请求均为 0。12 次公式输入的布局读取共 9.4 ms，约 0.78 ms/次；遍历节点 875、文本范围 185，旧基线为 1557、522。两阶段测量增加读取次数，不由此宣称总体输入延迟改善。

完整性能套件既有 p95 ≤ 50 ms 的 7 项预算通过；10000 行公式样本 p95 40 ms，安装基线为 34 ms。首次 56 ms 失败收据保留；该样本没有活动浮层，不能归因于避让。没有引入未经定向验证的宽度缓存优化。
