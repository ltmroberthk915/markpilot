# MarkPilot 3.6.6

MarkPilot 是支持即时渲染、数学公式和源码双栏的 Markdown 编辑器。此稳定版本汇集近期的编辑与大文档体验改进。

- **源码双栏**：含大量内嵌图片的长文档也能同时阅读渲染内容与编辑源码。
- **内嵌图片保护**：正文和源码栏收起图片数据；移除图片前，可选择将图片备份到文档同目录的 `assets` 文件夹。
- **表格编辑**：支持中文组合输入、转义竖线、格式操作与撤销重做。
- **公式选区**：跨越行内公式边界时保留完整公式，便于复制和继续编辑。

适用于 Windows x64。下载并运行 `markpilot-Setup-3.6.6.exe` 安装；无需安装时，可使用 `markpilot-3.6.6-portable.exe`。
