# MarkPilot 3.6.5

本次更新修复一个数学公式选区问题：

- **问题**：在行内公式（如 `$a+b$`）内部点击后按 `Shift+End`，选区会从公式中间开始，复制出来只有半截公式（例如 `+b$ 后`，丢掉开头的 `$a`）。
- **修复**：当选区跨过行内公式边界时，选区端点会吸附到公式边界，复制/剪切/删除会拿到**完整公式**；从公式外部开始、或 Shift+点击公式内部想精确选取源码端点时，行为保持不变。
- 不影响块级公式、表格与 IME。

安装：运行 `markpilot-Setup-3.6.5.exe`，或使用便携版 `markpilot-3.6.5-portable.exe`。
