# MarkPilot 3.6.20

面向 Windows 桌面版的稳定更新，把最近一轮编辑器内核修复带入安装版与便携版，并新增 npm 分发入口。

- **引用里的 Shift+Enter 保持引用**：在引用块内换行会自动带出当前层级的 `>` 前缀，空行不再把引用断开，左侧竖条与引用底色在第一帧就正确显示。
- **列表/引用中的代码块识别更可靠**：在 `>` 或列表前缀后新开围栏、或修改围栏语言，代码块会立即按围栏渲染，不需要重开文档。
- **长文输入更跟手**：只有可能触发补全的字符才扫描上下文；中文、空格、句号等普通输入不再做万字级回扫。
- **连续退格与外部写入并存**：同组退格合并后遇到外部写入，历史映射不再抛异常，撤销/重做与外部字节都保持完整。
- **多窗口协同更稳**：草稿清理只删除与当前内容精确匹配的那一条，旧版本窗口不会误删新草稿；成员能力协商避免丢失尚未确认的编辑。

Windows 提供安装版和便携版，已有文档、主题、字体、自动保存与最近文件设置继续保留。也可以通过 npm 获取桌面分发包：

```bash
npm install -g markpilot-cm6
markpilot --download
```

配套 DSH Markdown 插件版本为 2.0.7（内核 3.6.19），桌面版与插件共用同一份编辑内核。
