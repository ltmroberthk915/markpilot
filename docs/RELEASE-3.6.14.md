# MarkPilot 3.6.14

整理笔记时，可以把带制表符、公式、图片和代码的段落复制或剪切到另一份 Markdown。编辑器保留原始 Markdown，来自电子表格的 TSV 仍会粘成表格。

- **选公式和文字**。按住公式时继续使用键盘，松开鼠标会尊重后来的编辑。Ctrl+点击公式可以保留已有的光标和反向选区。同一行的两个公式之间仍是可编辑的正文。
- **编辑代码示例**。给带反引号的文字设置行内代码，会使用足够长的定界符。示例里的美元符号、HTML 注释和换行不会把后面的笔记意外变成公式或注释。
- **摘录网页和讲义**。有 TeX 注释的公式保留数学源码。上下标、强调、带有方括号的链接、代码行和表格单元格内的分段可以一起保存在笔记里。
- **粘贴混排图文**。其中一张图片读不到时，保留可读说明、正文、链接和其他可读取的图片。表题和来源说明随表保留，稀疏表格按原有单元格保存。

可用 Windows 安装包升级，或使用便携版。配套 DSH Markdown 插件版本为 0.3.9。
