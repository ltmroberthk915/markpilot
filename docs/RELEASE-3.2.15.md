# MarkPilot 3.2.15

图片、公式、代码和 Mermaid 图与正文共用编辑与撤销历史。点击图片后，原始源码显示在图片上方，预览继续保留；修改地址、撤销和继续输入可以连贯完成。

- 图片对齐、缩放和删除后可直接继续输入，撤销与重做保持原始源码。
- 公式源码选区、复制粘贴和表格内编辑更连贯，引用区域的底纹、边线与缩进贯穿特殊内容。
- 公式编辑预览更紧凑，超宽内容可滚动，浮层会避让工具栏和编辑位置。
- 长文档的局部编辑优先更新对应区域，重复渲染任务合并处理。
- KaTeX 更新至 0.19.0，公式与配套字体可离线使用。

Windows 安装版：`markpilot-Setup-3.2.15.exe`。便携版：`markpilot-3.2.15-portable.exe`，无需安装即可运行。
