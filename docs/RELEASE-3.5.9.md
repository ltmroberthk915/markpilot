# MarkPilot 3.5.9

表格编辑、阅读切换与整篇选择更稳。第一次点进单元格就能准确落点，横向滚动、缩放或撤销之后继续输入，表格内容与光标保持在同一处；长文档中的表格也更少出现跳动。

- 在表格里按下单元格后可以直接拖选，支持正向、反向以及 Shift 配合方向键扩展；点击单元格外的正文可继续编辑。
- 从阅读视图回到源码编辑时保留原来的阅读位置与上下文，不再整段跳回开头。
- Windows 下 Ctrl+A 与菜单“全选”统一为同一个动作：正文、表格单元格和搜索框都能一次选中全部内容。
- 重启后恢复缩放比例时，状态栏的比例指示同步更新。
- 文档间拖动文字时，取消或中断拖放不会把内容写进错误的窗口。
- PDF 导出保持文字可搜索、公式与图片完整，长文档导出速度更快，并可随时取消。
