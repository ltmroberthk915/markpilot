# MarkPilot 3.5.4

正文右键菜单新增“纯文本粘贴 Ctrl+Shift+V”。复制网页或表格中的内容后，可直接保留文字、制表符和换行；普通“粘贴”继续保留原有的富文本与表格转换。

源码分屏中的右键菜单按点击内容定位，表格行列操作更准确。
