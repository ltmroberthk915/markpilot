# MarkPilot 3.5.3

普通双星号加粗文本的源码标记显示更稳定。输入后停在行尾时，两侧双星号保持完整；点击正文外部后继续以富文本显示，便于连续编辑和检查格式。

富格式长文档的连续输入更顺畅。大纲公式与 Ctrl+Shift+E/M/Q/K 快捷键继续可用。
